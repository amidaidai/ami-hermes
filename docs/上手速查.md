> 一页版：**怎么用 / 怎么读卡 / 什么算正常 / 坏了怎么查**。深度内容看 `docs/系统总览.md`，
> 指标与裁决口径看 `docs/指标驱动分析与策略合同.md`。
> 本页只需记住一句：**系统只出证据与裁决，下单永远是你手动的事**。

## 1 系统在做什么

TradingView（SVP 主指标 + AggVol 副指标）+ Binance 衍生品 + 多源交叉验证 → Python 决策闭环 →
分析卡。加密主执行周期 **15m**、黄金 **5m**。监控・告警・备份是配套，不是主业。

## 3 怎么读卡（从上往下 5 块）

| 区块 | 看什么 | 关键 |
|---|---|---|
| 首屏 | 品种 · 北京时间 · 现价 · 方向 · 时段 + **唯一主推** | ⭐ 只在真可执行（GO-A）时点亮 |
| ① 周期体温 | D/4h/1h/15m/5m 逐层定位（⭐=主执行周期） | 加密给「方向+BOS/守摆」；**黄金给「位置%·涨跌」**——TVC:GOLD 无成交量，不编 BOS |
| ② 关键位 | 按距现价排序带 ±% | 等待条件引用**具名结构位**，不给裸数字 |
| ③ 多源验证 | SVP/HALDRO/订单流/清算/外部验证/质量 + 「已入 FinalVerdict」行 | 那一行逐源标 `live/cache/stale_cache/unavailable`，**先看它再信数字** |
| ④ 最推荐方案 + 门表 | 主推/备选/禁止 + 8 个闸门 + 完成度 | 只有 **GO-A + executable + R:R≥2** 才给 Entry/Stop/Target |

门表 8 闸：数据新鲜度 · TV现场确认 · R:R底线 · 事件窗口 · 风控保护 · 样本/WFO · 双指标共振 · 组合暴露。
**任一红 = 硬闸门 = 不执行**（红灯不是「反着做」的意思）。

## 4 什么算正常

| 现象 | 判读 |
|---|---|
| 预检 `exit 0`、门表无红 | 正常。可以照卡面执行判断 |
| 完成度 `13/14`（加密）、`7/8`（黄金） | **正常**：`cron_read` 含 3 个**设计性停用**源（dune/deribit/qlib），刻意不计完成 |
| ③ 行标注 `cache` / `stale_cache` | 可见降级 = 合规。按行判断本轮是否仍可用；`unavailable` 不占位 |
| 清算行出现「⚠最新事件N分前(疑似停更)」 | **上游冻结**，不是「市场无强平」；规模口径仍看 OKX 逐笔，币安笔数只是存在性 |
| ⑤ 之外仍出现 `R:R —` | 主推是等待/禁做 → 按合同不给候选价，不是漏算 |
| 预检出现「XAU同步终态: ⚠ 最近一轮未终结」 | 那一轮**有 enter 无 exit = 异常终止**，产物可能没更新；重跑 `xau_tv_sync.py` 并留样本 |
| 黄金 ① 表是「位置%·涨跌」 | 正常（黄金无 SVP 逐层结构），不是缺数据 |

## 5 坏了怎么查（按症状）

| 症状 | 先看 | 处置 |
|---|---|---|
| `TV CDP: DOWN` | `curl -s 127.0.0.1:9222/json/version`；cron「TV Desktop保活」 | 打开/重启 TV Desktop，等保活 cron 或手工 `python scripts/tv_keepalive.py` |
| 门2「TV现场确认」红、提示缓存过期 | 预检的 `数据 tv_live_*.json` 行 | 跑一次完整卡（自带前置刷新）；黄金若仍不过，手工 `python scripts/xau_tv_sync.py` |
| 黄金卡反复红 / 五周期不更新 | `data/xau_tv_sync_runs.jsonl` 尾部标记 | 有 `enter` 无 `exit` → 异常终止；连续 `defer:*` → 有别的任务在占共享图表（等一轮） |
| 某个源一直 `unavailable` | ③ 行 + `python scripts/data_freshness_watchdog.py` | 免费源失败不阻塞分析；429 约 15 分钟熔断后自恢复 |
| cron 报失败 | `cron_incident_watchdog.py`、`cron_incidents` 表 | 按 incident 里的 job 名手工重跑一次；COT/Deribit/清算类 cron 是**有意退役**，别机械恢复 |
| 不知道从哪看起 | `docs/系统总览.md` | 目录入口 + 排查表 |

## 6 铁律（背这几条就够）

1. **授权唯一**：只有 SVP 主指标能授权执行；AggVol 副指标只确认/降级/否决；外部验证层（CoinLobster 等）只作背景与反证。
2. **三件套门槛**：GO-A + executable + R:R ≥ 2 才给 Entry/Stop/Target；WAIT 只留「人工观察候选」，NO-GO/X 清空候选价。
3. **降级必须可见**：`live/cache/stale_cache/unavailable/quota_cooldown` 五态，禁用旧缓存冒充实时，缺失不占位。
4. **口径/身份单点**：换 TV 口径只动 `scripts/tv_symbols.py`；身份归一只允许 `norm_identity` 一份实现（禁止各模块自写副本）。
5. **截图与文字同源**：同一轮同一 TV 现场；`chart_evidence` 非 `verified` 不得 GO-A。
6. **不自动下单**；Telegram 外发需明确授权（普通对话与自动任务不外发）。
