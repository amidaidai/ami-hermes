# Public APIs Live

Aggregated public API directory — refreshed daily, deduplicated, categorized. Trending #5 on Agent Skills Hub.

## Key Features
- **50,000+** public APIs aggregated from multiple sources
- **Deduplicated** — removes duplicates across sources
- **Daily refresh** — new APIs added, dead ones removed
- **Categorized** — search by domain, protocol, auth type
- **Free tier** — most APIs require no or free API keys

## Sourcing Data
When you need external data for analysis:
- **Weather**: OpenWeatherMap, Weather.gov APIs
- **Finance**: Yahoo Finance, CoinGecko, Alpha Vantage
- **News**: NewsAPI, GNews, Currents API
- **Geolocation**: OpenStreetMap, ipapi
- **Crypto**: CoinCap, CoinDesk, Blockchain.info
- **Social**: Reddit, HackerNews, GitHub
