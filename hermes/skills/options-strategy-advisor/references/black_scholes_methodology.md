# Black-Scholes 方法论 · Greeks 与解读

> 本文对应 `scripts/black_scholes.py` 的实现，供人工复核与教学使用。
> 2026-09-13 补齐：SKILL.md 的 Resources 段引用了本文件，但此前从未落地。

## 一、定价公式（欧式，含连续股息率）

```
Call = S·e^(-qT)·N(d1) − K·e^(-rT)·N(d2)
Put  = K·e^(-rT)·N(-d2) − S·e^(-qT)·N(-d1)

d1 = [ln(S/K) + (r − q + σ²/2)·T] / (σ·√T)
d2 = d1 − σ·√T
```

| 符号 | 含义 | 备注 |
|---|---|---|
| S | 标的现价 | |
| K | 行权价 | |
| T | 剩余期限（**年**） | `T = 剩余日历天数 / 365` |
| r | 无风险利率 | 默认 5.3%（SKILL.md 口径） |
| q | 连续股息率 | 缺失时按 0 处理，并在输出里显示 |
| σ | 波动率 | IV 优先；没有 IV 时才用 HV 代理 |
| N(·) | 标准正态累积分布 | scipy 缺失时用 `math.erf` 兜底 |

## 二、Greeks（本脚本的口径）

| Greek | 定义 | 单位口径 |
|---|---|---|
| Delta Δ | 标的价格每 +1 美元，期权价变化 | 每 1 美元 |
| Gamma Γ | 标的每 +1 美元，Delta 的变化量 | 每 1 美元 |
| Theta Θ | **每日**时间价值损耗 | 已除以 365 |
| Vega ν | **IV 每 +1 个百分点**的期权价变化 | 已除以 100 |
| Rho ρ | **利率每 +1 个百分点**的期权价变化 | 已除以 100 |

标准公式：

```
Δ_call = e^(-qT)·N(d1)                 Δ_put = e^(-qT)·(N(d1) − 1)
Γ      = e^(-qT)·φ(d1) / (S·σ·√T)
Θ      = [ −S·e^(-qT)·φ(d1)·σ/(2√T)
           + q·S·e^(-qT)·N(d1)
           + r·K·e^(-rT)·N(d2) ] / 365        （call；put 的符号项相应翻转）
ν      = S·e^(-qT)·φ(d1)·√T / 100
ρ_call = K·T·e^(-rT)·N(d2) / 100       ρ_put = −K·T·e^(-rT)·N(−d2) / 100
```

`φ(·)` 为标准正态密度函数。

**持仓 Greeks**：多腿策略按 `Σ 符号 × 张数 × 100 × 单腿 Greek` 求和
（`strategy_analyzer.py` 的 `position_greeks` 即此口径）。

## 三、Greeks 解读

| Greek | 直觉 | 例子 |
|---|---|---|
| Delta | 方向敞口 | Δ = 0.50 → 标的 +1 美元，期权赚 0.50 美元/股 |
| Gamma | Delta 的加速度 | Γ = 0.05 → 标的 +1 美元后 Delta 增加 0.05 |
| Theta | 时间损耗 | Θ = −0.05 → 每天固定损失 0.05 美元/股 |
| Vega | 波动率敏感度 | ν = 0.11 → IV 升 1 个点，期权赚 0.11 美元/股 |
| Rho | 利率敏感度 | ρ = 0.04 → 利率升 1 个点，期权赚 0.04 美元/股 |

## 四、隐含波动率反解

`scripts/black_scholes.py --market-price <价格>` 用**二分法**在 [0.0001, 5.0] 上求解：
期权价关于 σ 单调递增，故区间内二分必收敛。区间外无解时返回 `null`，不猜。

自检（2026-09-13 实测）：`S=180, K=185, T=30/365, r=5.3%, q=0`，
给定市场价 3.37 → 反解 IV = **24.978%**（正向输入为 25%），往返一致。

## 五、已知局限（必须向前台披露）

1. **欧式假设**：不能提前行权。美式期权（尤其深度 ITM 的 put）真实价值更高。
2. **波动率恒定**：真实 IV 随行权价与到期日形成微笑/偏斜；单一 σ 是对整个曲面取平均。
3. **无摩擦**：未计买卖价差、佣金、滑点；真实成本一定高于理论价。
4. **连续股息**：真实股息是离散除息日事件，连续 q 只是近似。
5. **流动性**：理论价 ≈ 中间价，但盘口宽时中间价本身也不可成交。

结论口径：本工具用于**教学与横向比较**（策略 A 与 B 谁的成本/风险更好），
不作为下单依据。实际下单价必须以券商报价为准。

## 六、波动率：HV 与 IV 的关系

| | 含义 | 获取 |
|---|---|---|
| HV（历史波动率） | 过去实际发生的波动 | 免费：对数收益标准差 × √252 |
| IV（隐含波动率） | 市场对未来波动的定价 | 需实时期权数据，由用户从券商提供 |

判读：

```
IV > HV（≥1.25 倍）：期权偏贵 → 优先卖方结构（铁鹰 / 信用价差）
IV < HV（≤0.85 倍）：期权偏便宜 → 可考虑买方结构（跨式 / 宽跨式）
IV ≈ HV：无明显贵贱 → 按方向观点选结构
```

`earnings_strategy.py` 会自动算 30 日 HV 并给出上述判读（有 FMP key 时）。

## 七、财报期的特殊性与 IV Crush

财报是**事件驱动**的波动率：财报前 IV 被推高，公布后不确定性消失，
**IV 会瞬间塌陷**（IV crush）——即使标的方向走对，买方仍可能亏钱，
因为 vega 损失超过了 delta 收益。

对冲口径：

- 买方结构（跨式/宽跨式）赌的是「**实际波动 > 隐含预期**」。
  先算 expected move = `S · σ · √(DTE/365)`，再问「我真觉得会超过这个幅度吗」。
- 卖方结构（铁鹰/信用价差）赚的就是 IV crush，但尾部风险必须由买入翼封顶。
- `earnings_strategy.py` 在财报 ≤1 天时会给显式警示。
