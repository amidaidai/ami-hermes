# 软件著作权申请材料生成

从实际项目代码生成中国软件著作权登记申请材料。

## 概览

中国软件著作权登记需要提交以下材料：
1. **软件著作权登记申请表** — 在线填写或提交
2. **源程序** — 前30页+后30页（共60页）
3. **文档** — 用户手册/设计文档/操作说明（前30页+后30页）

本skill帮助从实际项目自动生成符合要求的申请材料。

## 一、源程序提取

### 要求
- 提交前30页和后30页（不足60页全部提交）
- 每页不少于50行代码
- 不可包含无关文件（node_modules、build输出等）
- PDF格式，A4纸

### 提取流程

```bash
# 1. 列出项目源文件（排除无关目录）
find src -type f \( -name "*.py" -o -name "*.js" -o -name "*.ts" -o -name "*.java" \) \
  | grep -v node_modules | grep -v __pycache__ > source_files.txt

# 2. 合并代码（带文件名注释）
> combined_source.txt
while IFS= read -r file; do
  echo "// ===== $file =====" >> combined_source.txt
  cat "$file" >> combined_source.txt
  echo "" >> combined_source.txt
done < source_files.txt

# 3. 提取前30页和后30页
# 前30页：head -1500 combined_source.txt
# 后30页：tail -1500 combined_source.txt
# （50行/页 × 30页 = 1500行）
```

### 格式要求
```
// ===== src/main.py =====
// 第一页
// ... 代码 ...
// ===== 第1页结束 =====
```

## 二、用户文档生成

### 要求
- 操作手册、设计说明或用户指南
- 前30页 + 后30页
- 图文并茂（含界面截图标注）
- 连续的、完整的文档

### 文档框架
```
# [软件名称] 用户操作手册

## 1. 软件概述
### 1.1 功能简介
### 1.2 运行环境
### 1.3 技术特点

## 2. 安装与部署
### 2.1 环境要求
### 2.2 安装步骤
### 2.3 配置说明

## 3. 功能操作说明
### 3.1 [功能模块1]
### 3.2 [功能模块2]
### ...

## 4. 常见问题
## 5. 版本信息
```

## 三、填写申请表

### 关键信息
- **软件名称** — 全称 + 简称（可选）
- **版本号** — V1.0（首次登记）
- **开发完成日期** — 实际完成日期
- **首次发表日期** — 可留空（未发表）
- **开发方式** — 单独开发/合作开发/委托开发
- **著作权人** — 公司全称或个人姓名
- **源程序量** — 实际代码行数

### 注意事项
- 名称中不能包含"中国"、"中华"、"国家"等字眼
- 版本号需附带"V"前缀（V1.0）
- 开发完成日期不能晚于申请日
- 合作开发需提交协议

## 四、自检清单

- [ ] 源程序前后页无重复
- [ ] 每页不少于50行
- [ ] 文件名/注释已清理敏感信息
- [ ] PDF格式，A4纸张
- [ ] 文档页码连续
- [ ] 申请表信息准确
- [ ] 著作权人信息与营业执照/身份证一致
- [ ] 签章材料已准备

## 五、常见问题

- **代码量不足60页** — 全部提交即可
- **有敏感信息** — 全局替换（公司名、内部IP、测试数据）
- **框架代码过多** — 只保留核心逻辑，去掉自动生成的样板代码
- **多人开发** — 提交合作协议
- **版本号冲突** — 如果之前登记过，需要做变更或新版本登记
