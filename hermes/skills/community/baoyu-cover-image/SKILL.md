# Baoyu Cover Image Generator

Generate article cover images with 5 dimension presets, 11 color palettes, and 7 rendering styles.

## Overview

Create visually striking cover images for articles, blog posts, and social media content. Comprehensive style system allows matching cover images to content tone and platform requirements.

## Dimensions

| Preset | Size | Aspect | Use Case |
|--------|------|--------|----------|
| **Blog Header** | 1200×630 | ~1.91:1 | Open Graph / blog posts |
| **Square** | 1080×1080 | 1:1 | Instagram, LinkedIn |
| **Mobile Story** | 1080×1920 | 9:16 | Stories, Reels, TikTok |
| **Wide Banner** | 1600×400 | 4:1 | Website hero banners |
| **Thumbnail** | 640×360 | 16:9 | YouTube, video covers |

## Rendering Styles

| # | Style | Description |
|---|-------|-------------|
| 1 | **Typography** | Text-only, beautiful typography as hero |
| 2 | **Gradient Background** | Smooth color gradients with text overlay |
| 3 | **Geometric Pattern** | Abstract geometric shapes as background |
| 4 | **Image + Overlay** | Photo background with colored overlay + text |
| 5 | **Split Layout** | Image and text side by side or diagonal split |
| 6 | **Framed** | Image within a decorative frame/border |
| 7 | **Minimal Line Art** | Simple line drawings as visual element |

## Text Layout

- **Title** — 2-5 words maximum for readability
- **Subtitle** — Optional, 5-10 words
- **Author/Source** — Bottom area, small
- **Font choices** — Bold sans-serif for titles, elegant serif for editorial

## Output

- PNG format with transparent or solid background
- High resolution (2× for retina displays when needed)
- Consistent branding across series

## Pitfalls

- Title text too long — gets cropped or too small
- Low contrast between text and background
- Palette doesn't match article tone
- Too much visual noise — keep it simple
- Missing margin/padding on mobile presets
