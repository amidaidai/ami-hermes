# Canvas Design — Beautiful Visual Art (PNG + PDF)

Create beautiful visual art outputs in .png and .pdf formats, guided by design philosophy principles. Generate everything from abstract compositions to data visualizations with intentional design thinking.

## When to use

- You need to create visual assets for a project
- You want to generate art or illustrations programmatically
- You need a design that follows design principles (not just random output)
- You want to output to both PNG (web) and PDF (print/publishing)

## Design Philosophy Principles

### 1. Hierarchy
Guide the viewer's eye: primary → secondary → detail elements.

### 2. Balance
- **Symmetrical** — formal, stable, traditional
- **Asymmetrical** — dynamic, modern, interesting

### 3. Contrast
Create visual interest through opposing elements:
- Light vs dark
- Large vs small
- Smooth vs textured
- Color vs neutral

### 4. Rhythm
Repeat elements with intentional variation to create visual flow.

### 5. Proportion
Use mathematical ratios (golden ratio 1:1.618, rule of thirds, Fibonacci spiral).

### 6. Unity
All elements should feel like they belong together (consistent palette, style, weight).

## Programmatic Art Generation

### Abstract Geometric Composition (PNG)

```python
from PIL import Image, ImageDraw, ImageFont
import math, random

def create_abstract_composition(width=1200, height=800):
    img = Image.new('RGBA', (width, height), (248, 249, 250, 255))
    draw = ImageDraw.Draw(img)
    
    palette = [
        (26, 26, 46, 255),    # dark navy
        (100, 255, 218, 200), # teal accent
        (255, 107, 107, 180), # coral
        (255, 255, 255, 100), # white
    ]
    
    # Golden ratio spiral elements
    cx, cy = width * 0.382, height * 0.618
    max_r = min(width, height) * 0.9
    
    for i in range(50):
        t = i / 50 * 2 * math.pi * 3
        r = max_r * (1 - i / 50) * 0.5
        x = cx + r * math.cos(t)
        y = cy + r * math.sin(t)
        size = random.randint(8, 40)
        color = palette[i % len(palette)]
        
        if i % 3 == 0:
            draw.ellipse([x-size, y-size, x+size, y+size], fill=color)
        elif i % 3 == 1:
            draw.rectangle([x-size, y-size, x+size, y+size], fill=color, width=0)
        else:
            points = []
            for a in range(6):
                angle = a * math.pi / 3 + t
                px = x + size * math.cos(angle)
                py = y + size * math.sin(angle)
                points.append((px, py))
            draw.polygon(points, fill=color)
    
    # Grid overlay (subtle)
    for x in range(0, width, 80):
        draw.line([(x, 0), (x, height)], fill=(0, 0, 0, 10), width=1)
    for y in range(0, height, 80):
        draw.line([(0, y), (width, y)], fill=(0, 0, 0, 10), width=1)
    
    return img

img = create_abstract_composition()
img.save("abstract_composition.png", "PNG")
```

### Data Visualization with Design (PDF)

```python
from reportlab.lib.pagesizes import A4, landscape
from reportlab.lib.colors import HexColor
from reportlab.graphics.shapes import Drawing
from reportlab.graphics.charts.barcharts import VerticalBarChart
from reportlab.graphics import renderPDF
from reportlab.pdfgen import canvas as pdf_canvas
from reportlab.lib.units import mm

def create_design_pdf(filename, data, title):
    width, height = landscape(A4)
    c = pdf_canvas.Canvas(filename, pagesize=landscape(A4))
    
    # Dark background
    c.setFillColor(HexColor('#1a1a2e'))
    c.rect(0, 0, width, height, fill=1, stroke=0)
    
    # Title
    c.setFillColor(HexColor('#64ffda'))
    c.setFont("Helvetica-Bold", 28)
    c.drawString(50*mm, height - 40*mm, title)
    
    # Subtitle
    c.setFillColor(HexColor('#8899aa'))
    c.setFont("Helvetica", 12)
    c.drawString(50*mm, height - 50*mm, "Generated with design philosophy")
    
    # Bar chart
    drawing = Drawing(500, 300)
    bc = VerticalBarChart()
    bc.x = 50
    bc.y = 50
    bc.width = 400
    bc.height = 200
    bc.data = [data]
    bc.categoryAxis.categoryNames = [str(i) for i in range(1, len(data)+1)]
    bc.valueAxis.valueMin = 0
    bc.valueAxis.valueMax = max(data) * 1.2
    bc.bars[0].fillColor = HexColor('#64ffda')
    bc.bars[0].strokeColor = None
    bc.categoryAxis.labels.fillColor = HexColor('#8899aa')
    bc.valueAxis.labels.fillColor = HexColor('#8899aa')
    drawing.add(bc)
    
    renderPDF.draw(drawing, c, 30*mm, 60*mm)
    
    # Footer note
    c.setFillColor(HexColor('#556677'))
    c.setFont("Helvetica", 8)
    c.drawString(30*mm, 15*mm, f"Generated by Canvas Design | {len(data)} data points")
    
    c.save()
    print(f"PDF saved: {filename}")

# Usage
data = [12, 35, 28, 45, 52, 38, 41, 63, 47, 55]
create_design_pdf("chart_design.pdf", data, "Quarterly Metrics")
```

### Typographic Poster (PNG)

```python
def create_typographic_poster(text, filename="poster.png"):
    width, height = 1080, 1350
    img = Image.new('RGB', (width, height), (26, 26, 46))
    draw = ImageDraw.Draw(img)
    
    # Large letter as background element
    first_char = text[0].upper()
    try:
        font_large = ImageFont.truetype("arial.ttf", 400)
        font_medium = ImageFont.truetype("arial.ttf", 60)
        font_small = ImageFont.truetype("arial.ttf", 24)
    except:
        font_large = ImageFont.load_default()
        font_medium = ImageFont.load_default()
        font_small = ImageFont.load_default()
    
    # Background letter
    draw.text((width//2, height//2), first_char, 
              fill=(40, 40, 80), font=font_large, anchor='mm')
    
    # Main text
    draw.text((width//2, height//3), text, 
              fill=(100, 255, 218), font=font_medium, anchor='mm')
    
    # Decorative line
    for i in range(3):
        y = height//2 + 100 + i*80
        draw.line([(width//4, y), (3*width//4, y)], 
                  fill=(255, 107, 107, 200-i*50), width=3)
    
    # Bottom text
    draw.text((width//2, 3*height//4), "DESIGN PHILOSOPHY", 
              fill=(255, 255, 255, 100), font=font_small, anchor='mm')
    
    img.save(filename)
    print(f"Poster saved: {filename}")

create_typographic_poster("CREATE")
```

## Output Formats

| Format | Use Case | Best For |
|--------|----------|----------|
| PNG | Web, screen sharing, social media | Photographs, complex gradients |
| PDF | Print, publishing, sharing | Documents, multi-page, vector graphics |

## Pitfalls

- PNG files with transparency (RGBA) won't render correctly in all viewers — provide a fallback background
- PDF vector elements (ReportLab) scale infinitely; raster elements (PIL) have fixed resolution
- If using non-standard fonts, they must be embedded in PDF for correct rendering everywhere
- Large PNGs (>10MB) may be rejected by some platforms — use PNG compression (optimize=True) or JPEG
- Color profiles matter for print — use CMYK for professional printing, sRGB for web

## Verification

Open the generated PNG in a viewer and the PDF in a reader. Verify: colors match expectations, text is readable, elements are aligned, and the output file size is appropriate for its intended use.
