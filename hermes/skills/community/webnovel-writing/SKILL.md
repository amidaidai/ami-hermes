# 中文网文写作

用于中文网络小说的规划、起稿、续写、改写。覆盖选材、构思、分卷、章纲、开头、节奏控制等全流程。

## 一、选材与定位

### 热门类型
- 玄幻、仙侠、都市、言情、科幻、游戏、历史、悬疑
- 重生、穿越、系统、无限流、种田、末世、电竞

### 定位分析
- **目标平台** — 起点、番茄、晋江、飞卢（不同平台读者偏好不同）
- **目标读者** — 男频/女频、年龄层、阅读习惯
- **竞争分析** — 同类热门作品的特点和差异化空间

## 二、故事规划

### 核心设定
```
世界观：_____
力量体系：_____
时代背景：_____
主线冲突：_____
核心悬念：_____
```

### 主角人设
- **身份** — 重生者/穿越者/土著
- **金手指** — 系统/功法/天赋/神器
- **性格** — 谨慎/热血/腹黑/搞笑
- **目标** — 复仇/变强/守护/自由

### 分卷大纲
```
第一卷（1-50章）：引子 + 新手期 + 第一次高潮
第二卷（51-120章）：成长 + 势力冲突 + 中期boss
第三卷（121-200章）：转折 + 真相揭露
...
```

## 三、章纲模板

```markdown
## 第X章：章节标题
**字数：** 2500-3000字
**视角：** 主角
**关键词：** [核心情节标签]

### 情节线
1. 引子（200字）—— 承接前文，引入本期冲突
2. 发展（1500字）—— 主要情节推进
3. 悬念（500字）—— 埋下下一章的钩子
4. 收尾（300字）—— 情绪落地

### 对话要点
- [角色A] 说 ...
- [角色B] 反驳 ...

### 环境描写
地点：____
氛围：____
天气/光线：____
```

## 四、开头技巧

### 黄金三章
1. **第一章（开局）** — 3000字内完成：主角身份定位 + 金手指展示 + 第一个冲突
2. **第二章（展开）** — 初步展示世界 + 建立短期目标 + 制造期待
3. **第三章（钩子）** — 第一个小高潮 + 埋设主线伏笔 + 留下强烈阅读期待

### 禁忌
- ❌ 不要大段背景介绍
- ❌ 不要过度描写外表
- ❌ 不要在开头写太多配角
- ✅ 直接进入冲突
- ✅ 展示不要讲述
- ✅ 每章结尾留悬念

## 五、节奏控制

### 爽点分布
| 篇幅 | 爽点类型 | 频次 |
|------|---------|------|
| 1-3章 | 金手指展示、打脸 | 每章1个 |
| 4-10章 | 升级、收获、收小弟 | 2章1个 |
| 10-30章 | 副本、战斗、秘境 | 3章1个 |
| 30章+ | 势力冲突、大事件 | 5章1个高潮 |

### 埋线与收线
- 伏笔：小伏笔3-5章回收，中伏笔10-20章回收，大伏笔一卷回收
- 每卷结束时必须回收该卷的主要伏笔

## 六、常见问题

- **节奏太慢** — 删掉无关描写，增加对话和动作
- **主角太弱/太强** — 保持合理的成长曲线
- **冲突同质化** — 每次冲突的类型和解决方式要不同
- **人物扁平** — 配角也要有独立动机和性格
- **世界观撑不住** — 不要一次性倒出全部设定，随着情节展开自然揭示
