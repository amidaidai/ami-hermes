# 中国专利挖掘与交底书生成

通用中国专利挖掘与专利交底书生成全流程。覆盖：文档扫描、专利点挖掘、查新检索、自检清单。

## 一、专利挖掘流程

### 1. 技术文档阅读
- 阅读技术方案/产品文档/RD文档
- 识别创新点：与现有技术的区别
- 记录发明背景和技术问题

### 2. 专利点识别
从以下维度挖掘可专利点：
- **结构创新** — 新结构、新连接方式、新布局
- **方法创新** — 新流程、新算法、新步骤组合
- **应用创新** — 已知技术的新应用场景
- **组合创新** — 已知技术的非显而易见组合
- **效果创新** — 显著改进的技术效果

### 3. 可专利性判断
```
❓ 是否属于可授权客体？
   └─ 技术方案（是）| 抽象规则（否）
❓ 是否具有新颖性？
   └─ 未被现有技术公开（是）| 已被公开（否）
❓ 是否具有创造性？
   └─ 非显而易见（是）| 本领域技术人员可想到（否）
❓ 是否具有实用性？
   └─ 可制造/可使用（是）| 纯理论（否）
```

## 二、专利交底书模板

```markdown
# 专利交底书

## 发明名称
简洁、准确地反映技术方案，不超过25字

## 技术领域
本发明涉及[具体领域]，尤其涉及[细分方向]。

## 背景技术
- 现有技术方案描述
- 现有技术存在的不足
- 参考文献/专利（如有）

## 发明内容
### 要解决的技术问题
针对现有技术的[具体缺陷]，本发明提供[解决方案]。

### 技术方案
**独立权利要求草案：**
一种[装置/方法/系统]，其特征在于，包括：
1. [技术特征A]
2. [技术特征B]
3. ...

**具体实施方式：**
结合附图详细描述至少一种实施方式。

### 有益效果
与现有技术相比，本发明具有以下优点：
1. [效果1] — 数据/实验验证
2. [效果2]
3. ...

## 附图说明
- 图1：整体架构图
- 图2：流程图
- 图3：实施例示意图

## 具体实施方式
逐步描述技术方案的实现细节：
1. [步骤/组件1]的描述
2. [步骤/组件2]的描述
3. ...

## 发明人信息
- 发明人：姓名、部门
- 联系方式：
- 日期：
```

## 三、查新检索

### 检索平台
- CNIPA (中国专利公布公告)
- WIPO PATENTSCOPE
- Google Patents
- CNKI (知网) — 非专利文献

### 检索策略
1. **关键词** — 中英文同义词、上下位概念
2. **分类号** — IPC、CPC分类号
3. **申请人** — 主要竞争对手
4. **引证/被引** — 核心专利追踪

## 四、自检清单

### 交底书完整性
- [ ] 发明名称≤25字
- [ ] 技术问题清晰明确
- [ ] 技术方案包含必要技术特征
- [ ] 有益效果有数据支持
- [ ] 至少一种具体实施方式

### 可专利性
- [ ] 属于授权客体（技术方案）
- [ ] 未被现有技术公开
- [ ] 具有实质性特点和进步
- [ ] 可产业应用

### 披露充分性
- [ ] 本领域技术人员可实施
- [ ] 公开了最佳实施方式
- [ ] 附图标号一致
- [ ] 术语前后统一
