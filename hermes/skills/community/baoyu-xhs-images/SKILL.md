# Baoyu XHS (小红书) Image Cards

Generate infographic image card series with 12 visual styles, optimized for Chinese social media platform Xiaohongshu (小红书).

## Overview

Create visually appealing image card series for social media posting. Each card presents a key insight, tip, or data point in an easily digestible format. Supports 12 distinct visual styles.

## Visual Styles

| # | Style | Description | Best For |
|---|-------|-------------|----------|
| 1 | **Clean White** | Minimalist, white background, thin borders | Professional/educational |
| 2 | **Warm Pastel** | Soft gradients, rounded corners | Lifestyle, wellness |
| 3 | **Bold Color** | High saturation, geometric shapes | Promotional, eye-catching |
| 4 | **Dark Elegance** | Dark bg, gold/white accents | Premium, luxury |
| 5 | **Neon Pop** | Bright neon on dark bg | Tech, youth culture |
| 6 | **Retro Paper** | Textured bg, vintage colors | Nostalgia, storytelling |
| 7 | **Gradient Bloom** | Large soft gradient areas | Artistic, aspirational |
| 8 | **Flat Illustration** | 2D illustrations as bg | Creative, fun |
| 9 | **Photo Frame** | Image background with text overlay | Travel, food |
| 10 | **Card Deck** | Multiple cards in a grid | Data, comparisons |
| 11 | **Timeline** | Vertical flow with markers | Steps, processes |
| 12 | **Split Screen** | Image + text side by side | Product showcases |

## Card Series Structure

A typical series (4-9 cards):

```
Card 1: Title Card
  - Series title + subtitle
  - Visual style indicator
  - Brand/author logo

Card 2-7: Content Cards
  - One key point per card
  - Supporting visual/icon
  - Short text (≤100 chars)
  - Page number (2/7, 3/7...)

Card N: Summary/CTA Card
  - Key takeaway
  - Call to action
  - Account handle/QR code
```

## Design Guidelines

### Dimensions
- **Square**: 1080×1080px (recommended for most platforms)
- **Vertical**: 1080×1440px (optimized for mobile feeds)
- **Story**: 1080×1920px (for Stories/Reels)

### Typography
- **Title**: Bold, 48-72pt, max 2 lines
- **Subtitle**: Regular, 28-36pt
- **Body**: Regular, 24-28pt, max 4 lines
- **Footnote**: Light, 16-20pt

### Color Usage
- 1 primary + 1-2 accent colors per series
- Text contrast: WCAG AA minimum (4.5:1)
- Consistent palette across all cards in series

## Content Planning

1. **Define topic** — What's the main theme?
2. **Outline key points** — 3-8 points that fit on individual cards
3. **Choose style** — Match to content and target audience
4. **Write card copy** — One clear message per card
5. **Plan transitions** — Visual or thematic flow between cards
6. **Add branding** — Subtle watermark or logo on each card

## Pitfalls

- Too much text per card — social media users scan quickly
- Inconsistent spacing/margins across the series
- Wrong aspect ratio for the target platform
- Overly complex backgrounds that make text unreadable
- Forgetting the CTA on the final card
