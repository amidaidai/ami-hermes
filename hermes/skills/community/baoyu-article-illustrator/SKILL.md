# Baoyu Article Illustrator

Analyze article structure, identify optimal visual positions, and generate matching illustrations for each section.

## Overview

Intelligently analyze written content to determine where visuals would add value, then generate appropriate illustrations for each position. Bridges the gap between text-heavy content and engaging visual storytelling.

## Workflow

### Phase 1: Content Analysis
1. **Read article** — Parse structure, sections, key points
2. **Identify visual opportunities** — Where do readers need visual support?
3. **Classify each opportunity** — What type of visual fits best?

### Phase 2: Visual Planning
For each identified position, determine:
```
Position: [paragraph/section index]
Type: [illustration/diagram/photo/icon/data-vis]
Purpose: [explain/showcase/break/emphasize]
Priority: [essential/recommended/nice-to-have]
Description: [brief visual concept]
```

### Phase 3: Generation
Generate illustrations matching:
- Article's overall tone and topic
- Section-specific content
- Consistent visual style across all images

## Visual Position Types

| Position | Best Visual Type | Purpose |
|----------|-----------------|---------|
| **Opening** | Hero illustration | Set the mood, attract attention |
| **Complex concept** | Diagram/flowchart | Explain visually |
| **Data point** | Chart/graph | Make numbers memorable |
| **Process/steps** | Timeline/flow | Show sequence |
| **Comparison** | Split visual | Highlight differences |
| **Quote/insight** | Quote card | Emphasize key message |
| **Break point** | Decorative divider | Visual breathing room |
| **Closing** | Summary visual | Reinforce main takeaway |

## Visual Style Selection

Match to article:
- **Professional/Technical** — Clean diagrams, infographics
- **Creative/Artistic** — Illustrations, abstract visuals
- **Educational** — Step-by-step diagrams, labeled charts
- **Storytelling** — Scene illustrations, character art
- **Data-heavy** — Charts, graphs, data visualization

## Integration

Each generated illustration includes:
- **Image file** — Rendered visual
- **Alt text** — Accessibility description
- **Placement suggestion** — Where in the article it fits
- **Caption** — Short explanatory text
- **Attribution** — If applicable

## Pitfalls

- Don't illustrate every paragraph — over-visualizing is distracting
- Maintain visual consistency (don't mix 5 different illustration styles)
- Ensure illustrations add information, not just decoration
- Alt text should describe what's shown, not just "an illustration"
- Consider dark mode when choosing colors for illustrations
