用户要对比兔小店(tu-zi.com) Codex 订阅套餐 vs aijws(api.aijws.com) 按量计费中转站，判断哪个便宜。

## 核心概念：倍率兑换公式

中转站计费的核心是「倍率」—— 官方 API 用量的缩放系数：

```
实际消耗余额 = 官方API用量 ÷ (1 / 倍率)
等价：每 $1 官方用量实付 = 倍率 × 充值汇率
```

- aijws：1¥ = $1 余额，0.1 倍率 → 每 $1 官方用量 = ¥0.1
- 兔小店 $220 档：¥48 = $220 余额，0.4 倍率渠道 → $220 × 2.5 = $550 官方用量 → 每 $1 官方 = ¥0.087
- 兔小店 $220 档 4 倍率渠道 → $220 ÷ 4 = $55 官方用量 → 每 $1 官方 = ¥0.873

**关键洞察**：同一套餐不同渠道倍率差异巨大（0.4x→4x = 10倍单价差），必须问清/注明渠道倍率再比价。

## 决策树（按量 vs 包月）

1. **先算盈亏平衡点**：包月月费 ÷ (包月每$官方单价 - 按量每$官方单价) = 月最低消耗
   - 兔小店 $220@0.4x vs aijws 0.1x：¥48 ÷ (¥0.1 - ¥0.087) = $3,692 官方用量/月
   - 但更直观的算法：¥48 月费在 aijws 0.1x 下 = $480 官方用量 → 月消耗 > $480 则包月更划算

2. **轻度/不确定用量 → 按量（aijws）**：零月费，用多少花多少，不用不亏
3. **重度/稳定日用 → 包月（兔小店低倍率渠道）**：单价更低但有月费沉没成本
4. **推荐路径**：先按量白嫖试用跑几天摸清日均消耗 → 超过平衡点切包月

## 抓取技术笔记

- tu-zi.com 商品页是动态渲染，web_extract 只拿到公告文本，需要 browser_vision 截图才能获取完整套餐列表

- linux.do 帖子含 Cloudflare Turnstile 验证，web_extract 能拿到内容但格式较乱
