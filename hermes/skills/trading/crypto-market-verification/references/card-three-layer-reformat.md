# 分析卡重排（`scripts/card_reformat.py`）实现与边界

把自动管线产出的原生卡（`data/auto_card_<SYM>_full.md`）机械重排成可直接交付的卡片。
**重排不产生新事实**：所有价位/角色/裁决都从原生卡搬运，只换呈现。

## 两种渲染模式

| 模式 | 命令 | 形态 | 状态 |
|:--|:--|:--|:--|
| **tables（默认 · 现行交付形态）** | `python scripts/card_reformat.py <卡>` | 首行＋主推，① 盯什么 / ② 关键位 / ③ 多源 三张 ≤3 列窄表，末尾【总结】，最后 `注` 一行 | **现行交付形态**（用户选定：喜欢表格＋末尾要总结） |
| panel | `... --style=panel <卡>` | 等宽面板（每行 ≤44 视觉列，CJK 算 2） | 备用；面板式用户已明确否过 |

无参数运行 `card_reformat.py` 自 **2026-09-16** 起走 **tables**（此前默认 panel，与文档不一致，已统一到文档一侧）。`--style=tables` 仍可显式传，等价。

无原生卡（手写/JSON 数据）时走 `scripts/card_panel.py`。

## 结构定位（tables 模式的 parser 锚点）

| 锚点 | 内容 | 用途 |
|:--|:--|:--|
| 第 1 行 `📊 …` | 品种 · 交易所 · 时间 · 时段 · 徽章 | 首行标题：`**品种 现价 · HH：MM · 时段 · 徽章**` |
| `⚠️…`/`⭐…`/`🔵…` | 主推行 | 首行下一行，原样 |
| `结构：` | 现价 · 上/下最近位 | **只取现价数值**；该行本身不进卡（上与下已由 ② 给出，写两遍＝重复事实） |
| `① …周期体温` | 五周期体温 | 面板式压成一行 ≤44 列；tables 模式不进卡（周期结论由 ③ 与交易层级承担） |
| `远端…` | 高周期 VAH/VAL/POC 等远位 | 三态目标的回退源，并单独成一行注脚；不进 ② 表（② 守 ≤4-5 行） |
| `VWAP/EMA/DO：` | VWAP/EMA/DO 读数 | 卡尾 `注` 一行 |
| `②`/`③`/`④` 分块 | 关键位表／多源表／方案表 | 按行首 `[①-④⓪]` 切；③ 原样成表，④ 与闸门走聊天压缩（见下） |

## 三态推导（机械，不主观判断）

1. **锚点是现价**，不是主观察位：上方最近位＝「收上」触发，下方最近位＝「失守」触发，两者之间＝「○ 不动手」。
   （错法警告：以主观察位为锚会产出「收上 78,336」这种价位已在现价下方的荒谬触发。）
2. **现价落在某个区间带里时，该带既不当触发也不当目标**（它是「现价所在带」⚖）：先把含现价的带从候选里剔除，再取上/下最近位。
   否则会产出「收上 78,085 → 上看 78,044–78,202」这种目标跨在触发之下的自相矛盾行（现价 78,081 落在该带内）。
3. **最近位靠排序，不靠原顺序**：② 表按**距现价**排（2026-09-16 起；更早是 mid 降序，表头注释与实现不一致），而 `above`/`below` 各自显式重排（above 升序取 `[0]`＝最近上方位，below 降序取 `[0]`＝最近下方位），**与 ② 表顺序无关**。
   直接用原列表首元素会把「收上」写成**最远**的那条阻力（现价卡在宽带里时尤其明显）。
3b. **触发价不许留空**：现价已在该侧最外层（无更远相邻位）时，退回「现价所在带」的上下沿（写作 `4,340（现价带上沿）`）；该侧连带都没有时写「上方/下方暂无具名结构位」并把整行改成「不预判；等新结构位生成后再算」。旧实现写 `上沿`/`区间外` 两个占位词，读者拿不到可核对的价，且 ○ 横行与「怎么做」会一起消失。
4. **区间位做触发取边**：上方阻力取 `hi`、下方支撑取 `lo` —— `78,489–78,542` → `收上 78,542`；反之下方 `78,494–78,544` → `失守 78,494`。区间位做**目标**时保留整段。
5. 目标不足时回退「远端」行里更远的结构位，并带层次标签（`79,323（4h·VAH）`）——**不回退就会只剩单边路径**。
6. 远端标签从「数字前的最后一个 token」取（`4h·VAH 79,323` → `4h·VAH`）；「另N带」这类无价格段直接跳过。

## ② 关键位表（tables 模式）

- 保留原生角色/价位/距现价三列，**按距现价排序**（最近的位在最上；同距时高价在前）；现价带行保留 `⚖`，主观察行用**文字**标注（2026-09-16 起不再打 ⭐ —— ⭐ 只代表唯一授权 GO-A）。
- **每张表 ≤3 列**；数字列右对齐（`|:--|--:|--:|`），角色列左对齐。
- 原生 ② 只列最近 6 个位，实测可全部落在现价 0.1% 内（D·VWAP 与 4h·VWAP 夹住现价），此时表会显得「只有一层」——要更多结构补读 `data_get_pine_lines/labels`；但补读来的位仍以原生卡口径为准，不擅自加进表。
- 跨周期 VWAP（`D·VWAP`/`4h·VWAP`）在当前周期 Data Window 里取不到：引用就标周期，别当当前周期值用。

## 【总结】＝三段大白话（这是最容易被做错的一段）

用户点名否过符号串版本（`⚠禁做 — 主线R:R不足(<1:2) · 风控 —（未接账户余额·非真实额度） · Binance 100x`＝「一堆符号」）。
总结必须回答三问，逐条成行：

1. `- **最推荐**：{什么方案}。{为什么 —— 一句人话}{若 ② 有现价带：现价就在 X 这个窄带里，没有优势位置。}`
2. `- **看哪里**：看 {上方触发}（上方）和 {下方触发}（下方）这两个价格。收上 {上方触发} 才谈 {上方目标}；跌回 {下方触发} 以下就看向 {下方目标}。`
3. `- **怎么做**：{下方触发} 到 {上方触发} 之间不动作；等 {卡面主周期} 收线给出方向且{确认条件}后再动；{当前不给入场价，只作人工观察 / 按 ④ 的三件套执行}。`
   - `{卡面主周期}` 取 ① 体温行的 ⭐（黄金 5m / 加密 15m / 股票 1h），**不写死 15 分钟**；`{确认条件}` 加密＝主副指标重新共振、非加密＝结构与来源方向确认。
   - GO-A 且可执行时：③ 之后先出 `**④ 执行方案（GO-A·原生卡原值）**`（原样搬 `d["plan"]`：优先级/条件/动作三列，含入/损/标与 R:R），总结不得再写「当前不给入场价」或「没有优势位置」。
   - 「最推荐」若为 PLAN-B，固定写「这不是授权单」；若为 GO-A，写「执行三件套见 ④（原生卡原值为准）」。

`_plain()` 的符号→人话映射（只换措辞、不改结论方向；数字一律不动）：

| 原生写法 | 人话 |
|:--|:--|
| `⚠️主推 禁做` | 等待，不做单 |
| `🔵主推 等确认` | 等待确认后再动 |
| `副S3冲突` / `副S4降权` | 副指标 S3 冲突（主副方向不一致）／副指标 S4 降权（主副方向不一致） |
| `CVD/OI背离` | CVD 与 OI 背离（量价不一致） |
| `R:R不足(<1:2)` | 盈亏比不足 1:2 |

三段都只用 ①/② 已推出的价格，不引入新价位；结论方向必须与主推行一致。

## 宽度与对齐（只对 panel 模式）

- 视觉宽度＝CJK 算 2 列（`card_panel.visual_width()`）；每行 **≤44**，改完必跑自检：

```bash
python scripts/card_reformat.py --style=panel data/auto_card_BTCUSDT_full.md > outputs/card_check.md
# stderr 应打印 [面板最大宽度 44 列]（或更小）
```

- 阶梯三列：价位（左）／角色（左）／距现价（右对齐），列间距 1 比 2 更省宽。
- 目标价用「累加装得下就加、超 44 就 break」的写法，**不要 `_clip()` 硬切**；硬切产出半截数字（`78,032`→`7`）与半截角色名，属交付事故。

## 角色名压缩表（panel 模式用）

| 原生卡角色 | 面板显示 | 规则 |
|:--|:--|:--|
| `⚖ 现价所在带·D·VWAP–4h·VWAP` | `现价带 VWAP` | 去 ⚖，取首个 `·` 前，补一个结构标签 |
| `上沿阻力簇·15m·阻` | `上沿阻力` | 无 VAH/VAL/VWAP/POC 标签就不补 |
| `近端转撑·1h·VAH` | `近端转撑 VAH` | 只补**一个**标签 |
| `失效/支撑带·D·VAH–5m·支` | `失效带 VAH` | 冗词压缩（`失效/支撑带`→`失效带`） |
| `主观察·1h·VWAP–15m·VWAP` | `主观察 VWAP` | 该行前置 `→` 标记 |

## 聊天交付压缩（两模式共用）

- **不要贴原生卡那张 50 行的附录/闸门表**：markdown 客户端不渲染 `<details>` 折叠，贴全文＝用户最反感的「东西太多」。
- 聊天版压到 ≤6 行关键表（多源质量 4 行足够）＋ 一行源状态（`已入FinalVerdict：… ；仅展示/辅助：…`）＋ 指向 `data/auto_card_<SYM>_full.md` 的链接，写明全文在此。
- 卡面值与现场实测冲突（恐贪这类）**卡后加一行注明，不动卡面**。

## 重排层缺陷：已修复清单（2026-09-16）

下面五条曾是「上游已修、下游没跟」或「重排层自造」的呈现缺陷；现均已修并有回归
（`tests/test_card_presentation_20260916.py`）。留档是为了万一改回去时能对上症状：

| 症状（修复前） | 当时根因 | 现在怎么做 |
|:--|:--|:--|
| 外汇卡被打成 `**EURUSD 1 · …**`、关键位全变 `1` | 重排层自写 `:,.0f`（未复用 `render_v96._num` 的外汇 4 位小数） | 两层共用 `price_format.fmt_price`；**禁在重排层自写格式**（回归里有源码断言） |
| FX 远端（1.14/1.08）被丢 → 三态退化成「上看 区间外」 | `_remote_levels()` 用 `n > 100` 硬过滤（为了滤掉 `4h` 里的 `4`） | 先剔周期标记再取数，不再用价位阈值 |
| NO-GO 卡的「主观察」也带 ⭐ | `render_tables` 里 `mark = "⭐" if r["mark"]` | 主观察用文字；⭐ 只在 GO-A 主推行（panel 模式的 `→` 标记不受影响） |
| 授权卡首行写「可执行」、④ 三件套却消失、总结写「当前不给入场价」 | `d["plan"]` 解析后从不消费 | GO-A 卡零散搬 ④ 执行方案；总结按 executable 分支 |
| 黄金卡写「等 15 分钟收线」「主副指标重新共振」 | 【总结】第三段硬编码 | 主周期取 ① 体温行 ⭐；非加密改「结构与来源方向确认」 |

外加两条同期修的：首屏禁做理由取锚（`render_v96._blocker_headline`，与【裁决】主因行同一函数；黄金卡不再把「非加密不套HALDRO」当拦因），
以及非加密卡的 `HALDRO副驾驶` 行/全「—」`副读` 行不再占正文（末尾补一行「来源说明」，不静默删）。

判据：**上游渲染器（`render_v96`）修过的精度/术语，在同一链路的第二处实现里也要一起核** ——
两层各自实现一份格式化时，下游漏改就是这种「只在部分资产上出现」的缺陷；
改完任一处都要跑一遍另一处的实际输出。


## 坑清单

- 原生卡结构变化（新增行首标记、改分块符）先改 parser 锚点表再重排；渲染前先跑宽度自检（panel）。
- **区间跨度大时「○ 不动手」会宽得没意义**：两线相隔 1%+ 时必须在卡外补一句近端参考（原生卡「结构：」行给的 5m 支/15m POC 这类贴身位，② 表常已并进现价带），说明「两线之间＝决策区，不是可交易波段」。
- 轻量档只有 3 步路由，卡里没有 ④ 方案表的完整闸门；交付时别把轻量卡渲染成完整档的样子（缺的源写 not_run，不写 unavailable）。
- 换版式也算新一轮：重拍 TV 截图、重读行动格，不要复用上一轮的图与读数。
- 版式历史（都已否决，不要重提）：三表长源清单→「东西太多」· 暗号版→「看不懂」· 可读版→「格式有问题」· 决策卡→「好难看」· 面板式→「不喜欢，要表格」· 符号串总结→「一堆符号」。
