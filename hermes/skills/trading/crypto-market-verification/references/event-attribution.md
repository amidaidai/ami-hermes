# 事件归因（「昨天/隔夜发生了什么」「怎么会这样」）

触发：用户问某一波涨跌的**原因**（不是要新分析）。此类回答有固定形状，且**不重跑管线**——以上一轮卡面读数为基准，补现场 K 线与外部证据。

核心纪律：**先还原路径，再找叙事**。顺序反了就会拿一篇新闻去套一段并不存在的行情。

## 步骤

### 1. 先还原实价路径（不猜、不引二手）

```python
# 1h 看骨架、15m 看细节；时间一律换算 BJT；量能按同周期均值倍数判强弱
import json, urllib.request
from datetime import datetime, timezone, timedelta
BJT = timezone(timedelta(hours=8))
ks = json.load(urllib.request.urlopen(
    'https://api.binance.com/api/v3/klines?symbol=BTCUSDT&interval=1h&limit=40', timeout=25))
for r in ks:
    t = datetime.fromtimestamp(r[0]/1000, BJT)
    o, h, l, c = map(float, r[1:5])
    print(f'{t:%m-%d %H:%M} {o:>9.1f} {h:>9.1f} {l:>9.1f} {c:>9.1f} {(c-o)/o*100:+.2f}% vol={float(r[5]):>7.0f}')
```

只讲**实际发生**的事：哪一根起涨/起跌、那根量多大、从高点回撤多少、反弹有没有量。
「有没有量」= 该根 volume 相对同周期均值的倍数，**不要**只看 vol 绝对值（不同周期量纲不同）。

### 2. 拉事件日历（本周 + 未来 2-3 天）

- `mcp__jin10__list_calendar`：当前自然周全部事件，取 `star >= 3` 的与**发布时间（BJT）**，一并给出未公布的未来事件——归因必须带上「接下来还有什么」。
- `mcp__jin10__search_flash` 用中文关键词（比特币/加密货币）实测只回旧条目，**只当日历的补充**，不作为主证据源。

### 3. 找叙事并交叉验证

- `web_search` 中英双查（中文看解读口径、英文看一手报道），再用 `web_extract` 打开 2-3 篇（一手媒体 + 数据站）。
- 至少两类独立来源互证；**只采信能落到数字的叙述**（爆仓金额、ETF 净流入流出、收益率 bp、加息/降息概率）。

### 4. 把叙事对回盘面读数（这是归因的落脚点）

| 盘面读数 | 对应叙事 | 判读 |
|:--|:--|:--|
| OI 4h 下降 + 主「▼多平仓」/副「⚡多平仓」 | 爆仓/去杠杆 | 价跌是**多头被平**推动，不是新空进场 |
| 量能缩、同步放量 0/5 | 承接消失 | 「没人买」的跌，比「有人砸」更弱反弹 |
| ETF 净流入转净流出 | 现货买盘变薄 | 稍有抛压即直线下 |
| 卡面 VAH / 前高「仍阻」 | 长期持有者派发区 | 上行目标先撞成本墙 |
| 宏观：SPX/VIX/DXY/金/10Y | 利率与风险偏好 | `python scripts/macro_probe.py` 一次取齐，逐项 `_src` |

### 5. 源冲突要明写，不要择一当真

实测同一事件两源结论相反：一手媒体报「市场定价 85% 概率加息」，而财经日历 consensus 仍是「维持不变」。
两个都报，并标「两源不一致 → 按方向不可押处理」。**不能**挑一个看起来更专业的当事实。

## 交付形状（用户认可的顺序）

1. **一句话结论** — 谁在动、怎么动（例：不是币出事，是×××）。
2. **实价路径表** — `时间 | 价格动作 | 量能 | 对应事件`（含当日高低点与隔夜高点）。
3. **力量表** — `力量 | 事实（来源） | 作用`，2-4 条，每条带数字。
4. **为什么卡面翻转** — 把上一轮与本轮的指标读数并排（副指标 Composite、OI 行、体温条），说明是「读数变了」而不是「系统改口」。
5. **日程表** — `时间(BJT) | 事件 | 影响`，含未公布的高星事件。
6. **怎么办** — 回到卡里的两条线（收上 X / 失守 Y），并明说「等收线、不追」。

## 坑

- **先路径后叙事**：叙事必须能解释**已经发生的那一段**（哪根 K 线、多大量），解释不了就换一条。
- **量能是判据不是装饰**：无量的新高/新低要直接点成「假突破/无人接」。
- **区分两种跌**：缩量跌（没人买）vs 放量跌（有人砸）——结论与后续路径完全不同，必须给是哪一种。
- **归因不改结论**：即使找到看多叙事（法案投票、ETF 转流入），仍按卡面裁决交付，不因新闻升级方向、不给 Entry/Stop/Target。
- **必须答「为什么不追」**：用户问「怎么会这样」时，只讲原因会被追问；一次把「原因 + 为什么现在不动手」讲完。
- **不重拍图**：归因轮不是新一轮更新，引用（并标注）同轮那张 TV 截图即可；用户要新图＝要新一轮更新，那时才重拍并重读行动格。
