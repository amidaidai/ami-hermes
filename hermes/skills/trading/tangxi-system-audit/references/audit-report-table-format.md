## 铁律

- 对话内回复与 TG 推送用**同一份**管道表文本。
- TG 推送走 `telegram_reliable.send_telegram_reliable(parse_mode="RichMarkdown")`，**不要** `hermes send`（只发 sendMessage 纯文本，表格变裸 `|`）。
- 表格前不写 standalone `表1 · xxx` 标题行（RichMarkdown 会降级成文字）。
- 推 TG 失败/用户说"还是裸表" → 退回图片表：写深色 HTML → browser_navigate → browser_vision 截图 → send_telegram_photo。
