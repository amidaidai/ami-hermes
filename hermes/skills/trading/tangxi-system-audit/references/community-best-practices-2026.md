## 1. 盘前 GO/NO-GO 执行闸门（EdgeFlo 2026-03）

分析卡输出后、真正下单前，加一道 60 秒硬检查闸门。任何一问 NO → 不执行。

| # | 问题 | 检查内容 |
|---|---|---|
| 1 | 高周期趋势是否顺向？ | 入场 TF 的上一级 TF 方向 |
| 2 | 是否匹配策略库中的已知设置？ | 文档化的 setup pattern |
| 3 | 失效位是确切价格（不是区间）？ | stop 的确切数字 |
| 4 | R:R ≥ 1:2？ | entry→stop vs entry→target |
| 5 | 仓位大小是否按公式计算？ | 仓位 = 风险$ ÷ (ATR × 乘数) |
| 6 | 是否有催化剂（时段/事件/动量）？ | Kill Zone / 新闻 / 量能 |
| 7 | 是否在今日计划内？ | if-then 规则覆盖 |

## 2. 交易执行质量评分（Trader's Second Brain 2026）

入场**后**再评一次执行质量（区别于入场前的 A/B/C/X 设置评级）：

| 评级 | 标准 |
|---|---|
| A 级 | 所有入场条件满足才下单 + 仓位正确(±10%) + 止损在计划位 + 无情绪干扰 |
| B 级 | 轻微偏差：入场稍早/晚 + 仓位偏差 10-25% + 止损移动一次 |
| C 级 | 重大违规：冲动下单 + 无止损 + 仓位超 25% + 报复性交易 |

核心理念：**A级亏钱好过 C 级赚钱**——A级是可重复的正确决策，C级赢钱是运气。

预期分布：40-60% A，25-40% B，5-15% C。80%+ A 说明评分通胀。

C 级连击 2 次 → 当日停止交易。

## 3. 仓位公式 + 体制乘数（Quant Checklist + Market Regimes 2026）

```
仓位 = (账户净值 × 单笔风险%) ÷ (ATR × 体制乘数)

体制乘数：
  趋势平静 = 2.0    震荡平静 = 2.5
  趋势波动 = 3.0    震荡波动 = 3.5
  收敛/爆发 = 4.0 或不交易
```

单笔风险：1-2% 账户净值。Fractional Kelly：用 25-50% 的满 Kelly 值。

## 4. 6 体制模型（Market Regimes 2026）

方向(Price vs 200MA) × 波动(ATR比值) = 6 类：

| | 低波动(<0.75) | 正常(0.75-1.25) | 高波动(>1.25) |
|---|---|---|---|
| Price > 200MA | 牛平静 | 牛正常 | 牛波动 |
| Price < 200MA | 熊平静 | 熊正常 | 熊波动 |
| 反复穿越 | 震荡平静 | 震荡正常 | 震荡波动 |

ADX 辅助：ADX<20 = 无趋势(ranging)，25-40 = 可交易趋势，>50 = 极端/可能衰竭。

ADX<20 + 波动扩张(ATR比>1.25) → 减仓 50%。

## 5. 相关性限制 + 组合温度（Quant Diversification 2026）

- 新仓位与持仓相关性 >0.7 → 减仓 50%
- 组合总风险 >15% → 跳过该交易
- 相关性在市场压力下会趋近 1.0（2008/2020 教训）

## 6. 加密 Kill Zone（ICT 2026）

| 时段 (EST) | 特征 | 策略 |
|---|---|---|
| 亚洲 20:00-00:00 | 低波动，积累区间 | 不主做，等区间形成 |
| 伦敦 02:00-05:00 | 扫荡亚洲高低点，80% 反转 | 等扫荡后做反转 |
| 纽约 07:00-10:00 | 主行情派发 | 主执行时段 |
| 纽约下午 | 回吐/震荡 | 不主做 |

Kill Zone 是过滤器，不是信号。非主时段的 A 级 → 自动降 B。

## 7. 亏损冷却（Trade Quality Score 2026）

| 规则 | 触发 | 动作 |
|---|---|---|
| 亏损冷却 | 亏损 >1.5% 账户 | 暂停 5 分钟 |
| C 级连击 | 2 个 C 级 | 当日停止 |
| 日损上限 | 累计 >3% | 当日停止 |
| 连亏上限 | 3 笔连亏 | 仓位减半 + 复盘 |
