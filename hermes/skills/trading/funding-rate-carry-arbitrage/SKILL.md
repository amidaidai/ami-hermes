# 跨场所资金费 carry（delta 中性套利）

触发：「资金费套利 / 基差套利 / 跨所套利怎么做」「有没有好办法套利」「能不能给我自动套利」，或要把某个机会榜/扫描器的输出变成可交易候选时。

核心产出：**候选表（对 / 现价差 / 已实现 / 成本 / 回本天数 / 单腿上限）+ 执行与退出规则 + 不要做清单**。给候选与失效条件，**不给执行三件套**（本用户只手动交易；三件套仅 GO-A + executable + R:R≥2 时给）。

## 铁律（口径先于一切）

1. **只用已实现资金费设门槛，不用年化快照**：`settled_24h/7d/30d` 是真实结算额，与「现价差方向」一起看。年化上千%的榜首 7d 实际常为负 —— 极端小时费率集中在小市值且会翻向。
2. **成本必须按候选对自身的两条腿取**，不能用「最便宜两个场所」替代：前者是你真正要去的场所，后者只是下界，混用会把回本天数算得过于乐观。口径：往返 ≈（买多腿 long_total_bps + 卖空腿 short_total_bps）× 2（taker fee + 订单簿滑点）。
3. **回本天数 = 往返成本% ÷ 日净收益%；门槛 ≤3 天**（小资金 ≤1 天，固定成本占比高）。
4. **单腿名义 ≤ 该场所该币 OI 的 1~2%**：OI 只有 $0.1M 的场所吃不下 $100k，那档滑点/费率数字直接作废。
5. **按投入资金的年化 = 净%/天 × 365 × 杠杆 ÷ 2**（两腿各占一半资金）。1x 只拿到标称年化的一半；杠杆越高，单腿被强平概率越大。
6. **结算区间错配时风险窗口 = 慢腿周期**：优先同 `interval_h` 的两条腿（扫描器用 ⏱ 标的正是这件事）；混搭 1h/8h 时中途翻向你也要付完那一次。
7. **skew 型场所会自我侵蚀**：费率由 skew 驱动时 `dr/dt = c×skew`，你的入场直接推坏自己的费率 → 尺寸按 skewScale/深度定，不按 OI 定。
8. **入场用 post-only 限价，超时（~30s）转双市价 + 半腿对账**：这是把 20~30bp 往返压到接近 0 的唯一杠杆；代价是半腿风险，必须能自动平掉孤腿。
9. **只做有公开 API 的场所 + 主流币**；新场所只投可归零的钱 —— 高年化 = 对手方风险溢价，不是 alpha。
10. **不代客下单、不碰私钥/助记词/API 提款权限**；自动化只做只读扫描 + 落档 + 阈值提示，推 TG 需用户单独授权。

## 执行顺序

1. 拉候选（只读扫描）：排除 RWA/同名不同工具（价差 >5%、缺已实现列、被标 suspect 的直接丢）。
2. 每条候选取「现价差方向 + 该对自身成本」→ 算回本天数 → 标单腿上限（OI 的 1~2%）。
3. 过筛：已实现为正 + 现价差为正 + 回本 ≤3 天 + 双腿 OI 吃得下仓位；不过筛的**写清失效原因**，不硬凑候选。
4. 给执行方案：入场方式、退出规则（阈值见 `references/prior-art-and-thresholds.md`）、单对上限、冷却规则。
5. 纸上跑 30 天：记录「开仓时预期 → 24h/7d 实现」，只把实现/预期 ≥60% 的对放进白名单再上钱。

退出与风控阈值直接用公开实现的生产值（最低净 APR、持有上下限、连续低 APR 读数才平、单腿 SL 早于强平、跨腿 TP = 对手腿 SL、同资产最多一对、连亏冷却、入场要求 24h 与 7d 实现的正负与比值约束）—— **数值与出处见 `references/prior-art-and-thresholds.md`**，不要自己拍。

## 输出格式（本用户）

先一句裁决（做 / 不做 / 只纸面），再窄表：`币 | 多腿 / 空腿 | 净bp/天 | 往返成本 | 回本天`；成本取不到的行标 `?` 或写明「下界」，**不填 0、不猜**；每条候选标场所新旧与 OI；末尾给「不要做」清单。本类分析的主证据是表 + API 实测，不要求 TV 截图。

## Pitfalls

- **按现价差排序 = 把最假的机会排最前**：榜首常见同名不同工具（RWA pre-IPO / 股票永续在不同场所是不同标的，8~16% 价差是结构性错配）或年化快照尖峰；平台自己的 suspect/隐藏阈值之内不等于真机会。
- **成本用「最便宜两个场所」代替候选对自身的腿**：纸面回本天数偏短，按它上钱会长期不赚 —— 这是本类最常见的自欺。
- **忽略固定成本**：提币 $1~5/次 + 过桥 gas + 最低名义额，在小资金上会吃掉全部资金费 → 只配同链同稳定币的场所、一次摆好、别频繁搬砖。
- **把新场所的高年化当 alpha**：多为场所风险 + 空投预期；这类场所的真实收益常来自积分/空投（轮换刷量），资金费只是副产品与安全垫。
- **散户别碰延迟赛道**：纯盘口 / 三角套利是 µs 级托管机房生意（公开实现基准中位 tick-to-trade ~125µs），进去就是对手方的流动性。
- **规模先看 OI 再看成本**：OI 薄的腿会让「$100k 往返成本 30bp」这种数字看起来可行，实际一开就把池子吃光 —— 先算单腿上限，再谈成本。
