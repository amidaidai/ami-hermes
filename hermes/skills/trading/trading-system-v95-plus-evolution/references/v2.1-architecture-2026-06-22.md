# v2.0 → v3.1 架构进化 (2026-06-22)

## v2.0: 动态 TV 引擎
- **问题**: multi_model_engine.py 8处硬编码价位(VWAP=66054/VAH=66692/VAL=65601/POC=65847/EMA固定值)
- **修复**: 全模型改为 `load_tv_data()` 动态读取 · `_compute_dynamic_atr()` 实时波动率
- **新增**: CVD斜率+Taker因子四层过滤 · data["tv"] 子段传递
- **auto_card.py**: 引擎前合并 TV 数据桥输出
- **commit**: `35c295a`

## v2.1: 策略深度 + MCP 集成
### Session 策略引擎 (`session_strategy.py`)
- 4时段动态切换: 亚洲(范围回收) / 伦敦(突破扫荡) / 纽约(Silver Bullet) / 死区(等待)
- 模型优先级过滤: 优先模型+10%权重 / 禁用模型直接跳过
- KillZone 子时段: 伦敦开盘/纽约开盘/Silver Bullet 窗(14-15UTC)/亚洲收盘

### 三层确认模型 (`triple_confirm.py`)
- OB(Order Block) + FVG(公允价值缺口) + Liquidity Sweep 三层确认
- A+信号: 三层同时满足 (conf≥0.75)
- Silver Bullet 检测: 位移确认+CVD背离 (社区标注70-80%胜率)

### Jin10 实时日历 (`event_ban_live.py`)
- 财经日历禁做窗口: 事件前30min + 事件后45min
- 兜底关键词检查 + 1h缓存

### 宏观过滤器 (`macro_filter.py`)
- DXY/VIX/SPX/美债10Y/黄金/白银 5层交叉验证
- Risk On/Off 分类 → 方向压制 (risk_off时做多置信减30%)

### Polymarket 情绪桥 (`polymarket_bridge.py`)
- 预测市场赔率 → 情绪加权 (9场·$1.9M交易量)
- 每15min cron 刷新

**commit**: `d1bf815`

## v3.0: 多因子告警 → cron 自主层
### 核心问题
btc_alert_watch 仅做 "价格接近VWAP/VAH/VAL 18点以内" 检测 → 价格远离时静默。
v2.1的新模块(Session/三层确认/银弹)只在引擎层(LLM触发) → 用户不主动调用时不推送。

### `btc_alert_watch_v3.py` (替代旧方案)
- 14维检测矩阵: ①VWAP Band突破 ②CVD买卖压力 ③Taker极值 ④EMA排列 ⑤KillZone ⑥SilverBullet窗 ⑦多空比极端 ⑧OI背离 ⑨事件禁做 ⑩三层确认 ⑪银弹位移 ⑫VAH磁吸 ⑬VAL磁吸 ⑭宏观风险
- 噪音控制: 30min同模型冷却 + 波动率门槛
- ★A+标记: 2+ A级同方向信号自动标记高胜率

### 推送链路
```
btc_alert_watch_v3 (每1min) → btc_pending.txt → btc_push_cron (每1min) → Telegram 386
```

**commit**: `54e2554`

## v3.1: Confluence 评分 + 决策驾驶舱 + 自愈
### Confluence 综合评分
- 14维信号加权求和 → 5级评级 (A+/A/B/C/D)
- A+条件: 同方向≥2个A级 + 权重倾斜 >2:1
- 输出格式升级为决策驾驶舱

### 告警格式
```
★↑做多 | Confluence A+: 权重8/0·极强共振·多因子一致
  → Silver Bullet窗·波高·待突破
---
★↑做多 | VWAP+B2突破: 价格65538>+B264474·>VWAP64201 (conf:81%)
```

### 自愈能力
- btc_collector.py: 价格API失败→fallback mark price→None标记
- btc_alert_watch_v3: btc_latest缺price→直连Binance API兜底

### 数据修复
- btc_collector 原bug: `except: pass` 静默吞价格异常 → 无price字段 → 告警器拿不到价
- 修复: fallback用 fapi mark price + 显式None标记

**commit**: `bc4f8d5`
