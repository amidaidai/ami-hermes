## 一、用户偏好（契约级，后续默认遵守）

1. **一个视觉元素 = 一个开关。** 不要把两个不同的视觉新增绑在同一个 bool 上 ——
   "要么全开要么全关"是 UX 缺陷，用户会直接说"难看/线多了"。
   落地形态：`SHOW_ANCHOR_MARK`（默认 true）与 `SHOW_ROLL_BG`（默认 false）各自独立。
2. **新增曲线默认 OFF，opt-in。** 默认状态必须是"最干净的可读状态"：
   后加的第二条线、背景线、诊断线一律默认关闭，需要时手动打开。
   默认 ON 的门槛是：它**不是线**（如 `bgcolor` 竖带），或用户明确要求常显。
3. **默认关掉 ≠ 删掉。** 砍的是默认可见性，不是功能。删代码只在用户明确说"不要这个"时做。
4. **别为省槽位牺牲观感**：若省槽手段会改变观感（如价格量纲的 line 撑开窗格），
   宁可多占 1 槽用 `bgcolor`。
5. **给结论不给选项**：用户问"哪一个好看 / 选哪个"时，先给**唯一默认建议 + 一句操作口径**，
   末尾再补"如果你更常切 X，告诉我，我把默认改过去"。不要甩一张对比表让他自己选。

## 二、视图选型判据：看「与表格的信息重叠度」，不是看好不好看

用户常把两件事混在一句里问（好看 vs 选哪个），必须**拆开答**：

- **好看**：按审美如实说。蜡烛/柱状形态（OI Change Candles）天生比"围绕零轴的线"（CVD）好看，
  不要嘴硬辩护。
- **选哪个**：按**表格已经给过什么**决定 pane 的默认视图 —— pane 只该承载文字给不了的东西。

| pane 视图 | 表格已给 | 图形独有价值 | 结论 |
|---|---|---|---|
| CVD（流向） | 只有文字方向（买盘/卖盘占优） | **斜率 + 背离**（价涨而 CVD 走弱这类只能看形状） | **默认视图** |
| OI（持仓） | `▲新多 2.35%·同87%·滚10K`：方向/幅度/共识度全在 | 只剩"逐根节奏" | 切换查看 |

**操作口径（直接给用户的一句话）**：日常 CVD；想知道"仓位在增还是在减、哪一根放量"时切
`OI Change Candles`。两个视图在**同一个 mode 下拉**里 → 切换零成本、不用重复挂指标 →
这才是"选一个默认 + 需要时切"能成立的前提。

> 通用判据：**pane 承载「形状信息」，表格承载「数值信息」。**
> 一个量如果表格已经用文字+数字说全了（方向/幅度/共识度），画进 pane 就是噪声；
> 一个量如果只能靠形状判断（斜率、背离、节奏、形态），表格说不清，才值得占 pane。

## 三、本轮落地（v8，副指标降噪）

| 项 | 改动 | 代价 |
|---|---|---|
| 开关拆分 | `SHOW_ANCHOR_AID` → `SHOW_ANCHOR_MARK`(true) + `SHOW_ROLL_BG`(false) | +1 input（六项和 93→95/254） |
| 连续背景线 | 默认 ON 改默认 OFF（代码保留，需要时手动开） | 0 |
| 锚界竖带 | 保持默认 ON（不是线，零视觉负担） | 0 |
| CVD 主线 | `linewidth=2` 提升单线可读性 | 0（免费参数，不动槽位） |
| 绘图槽位 | 47 声明 / estimate 59 → 预计 TV **63/64** | 只拆开关不动绘图，声明数不变 |

**效果**：CVD 模式默认只剩 **1 条主 CVD + 零线 + 锚界竖带**，从 3 条线降到 1 条。

## 四、诊断「这个模式到底画了几条线」的机械方法

不要凭印象数，也不要在全脚本范围内统计。分两步：

1. **先过滤"真的会上窗格"的绘图**：排除 `display=display.data_window` 与
   `SHOW_BUS_LINES ? display.all : display.data_window` 这两类 —— 它们不进窗格，不构成视觉噪声，
   但**仍占 64 绘图槽**。视觉记账与槽位记账必须分开。
2. **再按当前 mode 收窄**：只有 `mode == '<当前模式>'` 条件成立、或该模式专用 series 的绘图才会画出来。
   其余模式的 plot 求值为 `na`，不产生视觉噪声。

**推论："线多了"必须按模式诊断，不能横向统计整个脚本。**
一个副指标有 12 个模式、20+ 个 plot，用户看到的永远只是当前模式那几条。

```python
# 诊断骨架（本次实跑）
call = re.compile(r'(?<![\w.])(plotcandle|plotshape|plotchar|plot|bgcolor|barcolor|hline|fill)\s*\(')
for i, l in enumerate(code.split('\n'), 1):
    if not call.search(l): continue
    if 'display=display.data_window' in l or 'SHOW_BUS_LINES ? display.all' in l: continue  # 不进窗格
    if "'<当前模式>'" in l or '<该模式专用变量>' in l: print(i, l[:110])
```

## 五、验收口径

- pane 默认视图的线条数应能一句话说清（本次：1 条主线 + 零线 + 竖带）；
- 关掉某个开关后，**表格数字一格不变**（纯显示开关不得触碰任何判定链）；
- 交付说明里写清每个开关的默认值与"为什么默认关"，让用户能自己回退。
