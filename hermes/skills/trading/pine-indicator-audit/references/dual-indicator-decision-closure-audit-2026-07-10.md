# 双指标决策闭环审计（2026-07-10）

用于成熟 Pine 主指标 + 订单流副指标 + TV MCP + Python 出卡/风控系统的深度优化审计。目标不是继续堆功能，而是确认每个字段真正影响最终裁决。

## 一、审计顺序

1. **Pine计算正确性**：计算值是否实际进入 qualified 信号、等级和执行门控。
2. **Data Window契约**：字段是否导出、映射、解码并被消费，不能只“读到了”。
3. **主副指标裁决**：副指标有效性、方向冲突和风险位是否覆盖最终 grade/side/entry。
4. **市场体制一致性**：实盘、回测、仓位必须共用同一分类器和阈值。
5. **回测同构性**：回测必须复现生产SVP/FVG/OB/触发定义，不能用滚动中点近似Volume Profile后声称验证生产指标。
6. **置信度校准**：固定模型分数不是概率；按时间顺序OOS/Walk-Forward检查置信桶是否单调。
7. **死链清理**：单次定义、死文本、只通向死文本的 request.* 物理删除，再新增功能。

## 二、Pine“算了但没用”检查

对关键过滤器运行全词引用计数。若变量只在声明处出现一次，它没有参与决策。

重点检查：

- 背离摆动幅度过滤（如 `swing > 1.5*ATR`）是否进入 qualified；
- 背离 slope 方向是否进入 qualified；
- 熊背离应配上方派发，牛背离应配下方吸收，不能反接；
- 区域质量分是否进入 A/B/C 或模型路由，而非仅显示/导出；
- ADX过热规则是否前后一致：过热本身不应禁掉质量回踩，通常只在“过热+延展”时禁追。

## 三、机器字段“映射不等于消费”

对每个 Data Window 字段检查四层：

| 层 | 必须满足 |
|---|---|
| Pine | plot导出，语义稳定 |
| Bridge | 标题/别名正确映射 |
| Decision | 进入裁决条件或明确只作展示 |
| Renderer | 最终卡片使用裁决后值，而非原始值 |

典型缺口：FVG/OB质量分在Python中只建字段映射却从未参与裁决；Valid Code虽读取但未门控。

## 四、主副指标硬闸门

副指标必须先检查有效性：

- `valid=0`：完全忽略；
- `valid=1`：回退源，只允许弱确认，不能制造硬冲突；
- `valid=2`：聚合有效，可参与硬确认/冲突。

必须生成唯一 `final_verdict`，至少含：

```text
state: GO-A / GO-B / WAIT / NO-GO
side: long / short / neutral
model
entry / stop / target / rr
risk_mult
blockers[]
```

Renderer、警报、仓位只能读取 `final_verdict`。禁止一边显示“主副强冲突”，一边仍用原始 Pine A级输出主推订单。硬冲突应拦截所有可执行等级，不只A级。

## 五、市场体制审计

静态“资产类别自适应”不等于动态“市场体制自适应”。

- 资产类别：加密/黄金/外汇/股票等，决定数据源和基础阈值；
- 实时体制：趋势/平衡/收敛/扩张，决定当前允许哪个模型；
- 耗尽、事件、延展属于风险叠加位，不应混成方向。

检查是否存在多套互不一致的体制实现（如实盘用VIX投票、回测用ADX+EMA）。应合并为单一 canonical classifier，供实盘、回测、仓位共同调用。禁止在实盘入口使用固定VIX/固定波动率伪装实时体制。

## 六、评分与回测校准

- 固定写死的 `confidence_score` 只是标签，不是概率；
- 按置信桶检查样本数、胜率、平均R是否单调；高分桶更差即校准失败；
- 回测若用滚动区间中点近似POC/VAH/VAL，不能宣称验证生产SVP；
- Walk-Forward每段只有个位数交易时不得调权或用于仓位；
- 记录真实闭柱候选：资产/TF/体制/主模型/grade/entry/stop/target/RR/FVG-OB质量/HTF/订单流风险，以及后续MFE、MAE、先止损或先目标；
- 按资产→周期→体制→主模型分层，样本不足时向上回退，不频繁自动调参。

## 七、成熟指标的推荐演进

优先级：

1. 正确性修复；
2. 下游硬裁决；
3. 死代码与死request清理；
4. 影子模式的 Regime/Model/Trigger ContextPack + RR；
5. 真实TV字段回放和Walk-Forward；
6. 校准后才让体制路由参与生产等级；
7. Footprint只做独立Pro分支，不塞入通用主指标。

不建议：继续增加SMC名词、更多箭头、更多行动格行、把副指标合进主指标、把区域质量分直接解释为胜率。
