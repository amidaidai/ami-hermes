# 双指标最终裁决与运行态闭环（2026年9月1日）

## 可复用结论

SVP主指标和AggVol副指标可以各自正确表达冲突、未收线、降级和等待；风险在Python卡片/监控层把不同时间、不同语义字段重新拼接后产生矛盾。因此最终输出必须只消费同一冻结快照的 `FinalVerdict`。

## 不变量

1. SVP行动格含 `⚠冲突`、`未收线`、`等收线`、`等解除`、`观望` 或 `C等待` 时，遗留A等级不得授予执行权：`FinalVerdict=WAIT`，并清空可执行 Entry/Stop/Target。
2. AggVol `S3` 或有效多源强冲突 → `NO-GO`；`S4`、回退、覆盖不足或有效性不足 → `WAIT`。副指标只确认、降级或否决，不能单独授权。
3. 渲染器不得使用原始指标文字覆盖 `FinalVerdict`。WAIT/NO-GO不得输出旧执行价格；仅B/C反可输出明确标为“候选·人工判断”的观察价格。
4. 卡片不得同时出现“主副同向”与`NO-GO/dual_indicator/S3冲突`。渲染前应从最终裁决派生主副文本。
5. Packed Bus用于免费账号下的TV主副连接，但不得成为唯一证据源。生产快照应保留来源、时间、周期、计算方法、覆盖率和语义状态。

## 推荐测试

至少覆盖：A等级+未收线→WAIT且无执行三件套；A等级+冲突/等解除→WAIT；NO-GO+副指标强冲突→卡片不含“主副同向”；WAIT→主推触发价为`—`；S3/S4/无效副指标分别映射NO-GO/WAIT/WAIT。

## 关键位运行态

进程心跳正常不等于监控正常。唯一批准源 `keylevels_config.json` 必须同时满足：显式enabled、未过期、至少一个有效位。候选池为空或TV现场错品种时必须失败闭合，不能覆盖旧候选池或把空配置标为健康。临时使用上次已验证TV缓存时，必须标记短期降级来源、设置明确到期时间，并在到期前重新采集和批准。
