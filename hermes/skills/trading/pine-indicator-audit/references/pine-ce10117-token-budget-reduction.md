# Pine 编译 token 预算减重（CE10117 量法·手段·何时该停）

适用：主/副指标在 Pine 编辑器报 `CE10117：compiled script 超过 100,256 tokens`。

> - CE10013 / CE10163 / CW10018 / CE10271 / CE10198 / CE10272 / 命名常量提取顺序 / 2^53 与值域哨兵 → `references/pine-v6-edit-and-compile-pitfalls-20260910.md`

## 一、先搞清三件事

1. **上限与套餐无关。** 官方 Limitations 文档：IL 形态最多 **100,256 tokens**，编译器硬限。
   升级订阅不解决。（网上 "limit is 72000" 是 2024 年旧值。）
2. **`translate_light` 云编译不查这个数**，只有客户端 Pine 编辑器报。
   所以「云编译 0 错」**不能**证明 CE10117 已解决。
3. **注释与空白不计 token**；删注释、缩进、短标识符全无效。字符数只能当启发式，不是证明。

## 二、先反推基线，别默认「这次改超了」

报错本身会给出**当前 token 数**。拿它除当前字符数，得到**该文件专属**的经验比例：

```
经验比例 = 报错给出的 token 数 ÷ 该版本源码字符数
历史版本 token ≈ 历史版本字符数 × 经验比例
```

2026-09-10 实测：新版报 `100,490 / 100,256`，比例 ≈ **0.438 token/字符**；
新版只比上一版多约 2,900 个非注释字符 → 反推**上一版就已经约 99,100**，余量本来只剩 1.2%。

**结论：这是「撞顶」，不是「这次改多了」。**
修法必须是**腾出可观余量**（目标 ≥500 token margin），而不是只削掉超出的 234 ——
只削 234，下次一改又撞。

## 三、先量预算在哪

分别统计，不要凭感觉：

| 桶 | 量法 | 可动性 |
|---|---|---|
| tooltip | `tooltip="..."` 全部常量 | ✓ 可压 |
| inline / group / options | 具名参数里的字符串 | 部分 |
| plot 标题（DW 名） | `plot(...,"名字")` | ⚠ 见第五节 |
| 面板文本 | **非具名参数**字符串 | ✗ 这是输出本身 |

再找**重复代码**：把连续 3~9 行的归一化文本做指纹，统计出现 ≥2 次的块。
（实测最贵的重复：「删池 + 清 6 个引用」7 行块 ×2、`array<ICTLevel>` 同构清理循环 ×3。）

另：先看字符串**已经被上一轮压过没有**（多数 tooltip 只剩 25 字符时，可挖的比预期少得多）。

## 四、官方指定的两条手段（只有这两条有效）

### 1. 缩短嵌入常量字符串

- 实测 77 条 tooltip：1894 → 988 字符。
- ⚠ **12 字符上限会把中文切碎**（`只想要确认行的FVG✓信`）。**16 字符**才是可用下限。
- ⚠ 全文必须留在 git 历史里；交付时明说「已压短、有损、要哪条可取回」，不要假装无损。

### 2. 减少重复代码 / 封装成函数

实测有效的六种（均声明为零行为变化；带耦合或行为变化的三种已在括号里标注）：

- 重复的全局表达式统一到**已存在**的全局（`timeframe.in_seconds(timeframe.period)` → 已有 `curTfSec`，×11 处）
- 重复的 `color.new(A, B)` 提取成命名常量（⚠ 提取顺序见 pitfalls 文件）
- 内联的重复方法体 → 复用已有的 `method`（⚠ 声明顺序 + 会带入原方法的守卫）
- 完全相同的数组清理块 → UDF
- 每个对象 6 行同构的复位 → UDF
- 相同的绘图标题后缀（纯说明文字）删除（⚠ 需同步 contract，见第五节）

实测合计省 1,800 字符 ≈ 789 token。

### 不要做的事

- ❌ 删面板文本 / 状态码 / 数据源 —— 那是输出本身，不是冗余
- ❌ 把聚合器「优化」成更短的写法（先证明行为等价）
- ❌ 只削掉超出的部分就收工（见第二节）
- ❌ 强上 12 字符 tooltip 换余量（见第七节）

## 五、改 DW 标题 = 改桥接合同（不改会静默坏）

Data Window 的 plot 标题在 `scripts/tv_indicator_contract.py` 里是**精确匹配**别名。
缩短任何 plot 标题必须**同时**改：

1. contract 里的别名（正向 `DW_MAIN`/`DW_SUB` + 反向 `DW_ALIASES_*`）
2. 对应回归测试（例：`test_dw_names_match_indicator_source`）

否则 Data Window 有值、桥接层找不到 → **静默丢字段**（最难查的一类 bug）。改完跑全量 pytest。

> 这是「缩短嵌入常量」里唯一带耦合的一类；tooltip / label / options 改了就改了。

## 六、验收分层

1. 云编译 `translate_light` 0 错 0 警（**只证明语法**）
2. 全量 pytest（含 contract 别名回归）
3. **客户端 Pine 编辑器编译 —— 只有这一步能验 CE10117。**
   必须明确告诉用户：「我验不了，余量是**推算值**」。
4. 绘图槽估算不变（减重不应新增 plot）

## 七、余量做到 <1% 时该停下来

继续削 tooltip 是**牺牲日常可用性换几个百分点余量**。此时应明确告诉用户：

1. 上限是硬限、升级无用；
2. 已经贴着顶（给出推算的 token / 上限）；
3. 真解法是**删一块功能换余量**；
4. 给出按「代码量 ÷ 决策价值」排序的候选清单让用户挑（例：已完成 SVP 多分布图 3→1）。

**不要单方面删功能** —— 那是产品决策，不是优化。
