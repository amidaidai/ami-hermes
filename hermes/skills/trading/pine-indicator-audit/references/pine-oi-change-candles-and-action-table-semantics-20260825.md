# Pine OI 变化K线与行动格语义（2026-08-25）

## 适用场景

优化加密副指标的 OI 可视化，或审计主副行动格是否把规则分数、OI、去杠杆代理说成了它们并不是的东西。

## 核心合同

### 1. OI 不是多空人数差

每张未平仓合约天然同时有一个多方和一个空方。OI 只能表示总未平仓量增加或减少，不能单独回答“多仓比空仓多”。方向必须结合价格：

| 价格 | OI | 解释 |
|---|---|---|
| 涨 | 升 | 新多扩仓占优 |
| 跌 | 升 | 新空扩仓占优 |
| 涨 | 降 | 空头回补/去杠杆 |
| 跌 | 降 | 多头平仓/去杠杆 |

只有 OI 上升才算扩仓方向票；OI 下降只表示平仓/去杠杆，不计方向票。LSR 只描述拥挤度，也不能冒充净多空合约差。

### 2. 多交易所 OI 不直接相加

不同交易所的 OI 合约单位可能不同。绘制聚合 OI K线时：

1. 每所请求同一周期 OI `[open, high, low, close, close[1]]` 元组；
2. 每所先相对自身上一根 OI 收盘归一化为百分比 OHLC；
3. 仅对有效 venue 等权平均；
4. 合成 high/low 时用 `max(rawHigh, open, close)` 与 `min(rawLow, open, close)` 防止 OHLC 几何倒置；
5. 颜色应按相对零轴的收盘变化（OI增加/减少），不是多头绿/空头红。

这一做法复用原有四所 OI request 上下文：把单值表达式扩为元组，不增加 venue 或 unique request context。

### 3. 免费 Basic 的显示取舍

Basic 每图主+副已占满两个指标位，不复制第二个副指标实例。副指标提供 Mode 切换：

- 默认 `Cumulative Delta`，用于日常流向观察；
- 临时切到 `OI Change Candles`，检查新仓扩张与去杠杆；
- 主指标继续通过唯一 Packed Bus 读取 OI 和状态，不因显示模式改变合同。

## 行动格文案铁律

- 规则总分 × 10 不是历史概率：显示“就绪XX%”，不得显示“置信XX%/胜率XX%”。
- Entry/Stop/Target 是同一执行原子：风控行必须给最终目标价；磁吸行负责解释目标质量，不替代最终 Target。
- OI 行颜色表达“支持当前计划/反对当前计划/去杠杆”，不能把所有 OI 上升都画成多头绿色。新空扩仓应使用空头色或按当前计划语义着色。
- 没有真实强平数据时，禁止写“爆仓、踩踏、挤空冲顶”等确定性清算文案；用“多头去杠杆、空头去杠杆、回补冲高、去杠杆下杀”。
- 副指标状态使用 S0-S4 合同码并在信号行、操作行可核对：S0无效、S1支持多、S2支持空、S3冲突、S4降权。
- 结论行已有“等……”动作时，不再追加第二个等待动作。
- 副指标保持确认/降级/否决职责，不独立提供 Entry/Stop/Target，不把 B/C 升为 A。
