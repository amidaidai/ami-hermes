# 免费 Basic 双指标总线与 CE10117 瘦身（2026-08-25）

## 适用场景

TradingView Basic 账号同时运行主执行指标与副确认指标，并出现以下任一问题：

- 主指标报 CE10117（compiled tokens 超限）；
- 主指标需要读取副指标多个字段，但 Basic 只允许一个 indicator-on-indicator source；
- 双指标已占满图表指标数量，不允许增加第三个 Pine 脚本。

## 已验证方案：单一 Packed Bus

把副指标的合同、状态、OI变化、同窗口价格方向和OI共识压入一个数值 `plot()`，主指标只保留一个 `input.source()`。

推荐字段：

- 合同码：版本与市场适用性；
- 状态：0无效、1支持多、2支持空、3冲突、4降权；
- 价格方向：-1/0/1；
- OI方向：-1/0/1；
- OI一致率：0–99；
- OI变化率：定点数编码，并明确裁剪范围。

十进制编码示例：

```text
contract*10^10 + state*10^9 + priceCode*10^8 + oiDirCode*10^7
+ agreement*10^5 + oiPctFixed
```

约束：

1. 总值必须低于 IEEE-754 双精度整数精确区间 `2^53`；
2. 负方向先偏移为非负码，再按位宽解码；
3. OI变化率使用定点数，编码前裁剪，避免进位污染相邻字段；
4. 主指标先验证合同码，再消费状态和OI；合同错误/未接线必须降级，不能授权A级；
5. 至少用一万组随机边界组合做编码→解码往返断言；
6. Basic版只能保留一个 `input.source()`，不能在保留旧五路source的同时另加Packed Bus。

## CE10117减Token顺序

CE10117是客户端compiled-token限制，不是源码语法错误。按决策价值从低到高删：

1. Basic不可消费的技术告警消息链、事件边沿和相关输入；
2. 默认关闭且与现有模块重叠的低价值模块（例如已有FVG时的Liquidity Void展示）；
3. 死输入、死字符串、死Data Window变体；
4. 重复的主副连接与重复解码逻辑；
5. 最后才考虑核心数值、五所成交量或四所OI——不得静默削减核心数据覆盖。

保留铁律：

- 主指标唯一负责Entry/Stop/Target、等级和X硬阻断；
- 副指标只确认、降级、否决，不得把B/C升级为A；
- 加密A级必须通过合同与State；
- 非加密市场不依赖加密副指标；
- 删除展示模块后，同步把对应Packed字段固定为中性，不能留下未定义消费者。

### 减重实操与编译陷阱（2026-09-11 实测）

> 另有**运行时语义陷阱**（编译 0 错但行为错，例如 `str.replace` 只替换第一处、
> 打包总线不能靠位移加字段）：见 `references/pine-runtime-semantics-gotchas.md`。
> 排错原则：字符串变换「只生效一半」先怀疑“只替换第一处”，不要先怀疑数据源。

详见 `references/pine-ce10117-reduction-and-edit-traps-20260911.md`（本目录，未进 SKILL.md 索引，因 SKILL.md 已满）。要点：

- **官方只认两条减重手段**：缩短嵌入常量字符串 + 减少重复代码/封装函数。注释与空白在分词前剥掉，**删注释不省 token**。
- **实测收益排序**：tooltip 字符串（本例 1894→988 字符）> 重复子表达式提升到**已存在的**全局（`timeframe.in_seconds(timeframe.period)` ×11 → 已有 `curTfSec`）> 重复常量表达式提取 > 重复连续块封 UDF > 内联函数体改调用。
- **tooltip 压缩下限 16 字符**。压到 12 会把中文切成半句（“只想要确认行的FVG✓信”），help text 直接失效。压缩前确认原文可从 git 历史取回，并在交付里写明「有损」。
- **反推基线再叙事**：`token/字符 ≈ 0.438`（本例 100,490 / 229,285）。若本次只加 D 字符，则改动前 ≈ 报数 − D×0.438——据此判断是「撞顶」还是「改坏了」，再决定“削一点”还是“必须删功能”。
- **上限 100,256 与套餐无关，升级无效**（网上 72,000 是 2024 旧值）；`translate_light` 不查这一项，**本地无法验收**，交付只能给推算值。
- **打包总线绝不能用位移加字段**：合同号 ×1e10→×1e12 会越 2^53（`22003×1e12 = 2.2e16 > 9.007e15`）。改用**值域哨兵**：编码域 `1..19999` 时 `0` 天然不可达，拿它表示「缺失」；合同号只升不位移，主端同时接受两版。最大合法包必须断言 `< 2^53`。
- **锚点改稿五个编译陷阱**：CE10013（替换串丢缩进打断 `if`）、CE10163（三元不能返回元组 → 改「请求无条件执行、用三元选品种」）、CW10018（函数内局部变量无历史 → 提到全局）、CE10298/CE10198（锚在 type 中间字段 → 把类型切成两半）、CE10271（被调函数定义在调用点之后）。另有自引用常量（先替换用法再插定义）与锚点静默 no-op（必须 `assert count == 1`）。
- **缩短 `plot(..., "<标题>")` 会静默打断 contract 的精确别名** —— 改标题必须同一次同步 `tv_indicator_contract.py` 与回归测试。
- **面板行内容判据**（第二轮被用户回撤修正，以 `pine-ce10117-reduction-and-edit-traps-20260911.md` §7 为准）：行标签算行的一部分；同一行不重复同一个词；满窗计数不每行都挂；但**动作词不是重复、必须保留**（用户明确回撤「原来的也不错」）。保留 方向·事件·守哪个摆动·波动状态·剩余位。

## 验证分层

1. **静态语义断言**：单一source、合同门控、A闸门、B/C不升级、五所量能与四所OI仍在；
2. **Packed Bus往返**：随机＋边界值至少10,000组；
3. **translate_light**：完整源码0错误、0警告，只证明服务器语法接受；
4. **客户端真实编译**：在TradingView Pine Editor点击添加/更新，确认CE10117错误按钮消失并成功挂图；
5. **运行验收**：Data Window合同/状态/OI解码与副指标逐项一致。

禁止把 `translate_light` 0错误称为“CE10117已解决”。字节数低于历史可编译版本只能作为强启发式，不等于compiled-token证明；注释不计token，删注释无效。

## Basic功能取舍

- 保留主＋副两个指标，拒绝第三个脚本；
- 不使用 `request.footprint()`；
- 技术告警交给外部Python/TG管线；
- 真实Taker、L2盘口、清算、事件、净R:R和统计校准放到外部驾驶舱；
- Pine保持结构、计划和多源确认，不继续堆概念模块。

## 双指标决策闭环迭代模式（2026-08-25实测）

### 锚定CVD采用三层记忆

“每天重置”通常只是锚定CVD进入新周期，不代表历史K线、OI或成交量历史被删除。兼顾日内响应与历史背景时：

1. **当前锚CVD**：继续按日/周/月重置，负责当前触发和同锚背离；
2. **固定滚动CVD**：例如最近 `max(ACT_LB×6, 24)` 根Delta之和，跨日界连续；
3. **前锚摘要**：新锚开始时保存上一锚结束方向，不保存无限增长的绝对累计值。

行动格显示可比较状态，例如 `今日卖·滚动卖·前锚买`；新锚样本不足时显示 `今日样本N/M`。永久累计依赖图表历史起点，长期基数会淹没近期变化，不适合作为快进快出主决策源。

### Packed Bus扩展同步升级合同

向唯一总线增加字段时：

- 编码端与解码端同时升级合同号；
- 旧副指标接新主指标必须降为S0，不能按旧位宽静默解码；
- 新字段可放最低位，例如 `packed = oldBase×10 + bgCode`；
- 扩展后重新证明最大整数低于 `2^53`；
- 重跑至少10,000组随机＋边界往返测试；
- 主指标仍只保留一个 `input.source()`。

实测合同由22001升级为22002，在低位加入CVD背景码后仍处于IEEE-754精确整数区间。

### 单边趋势参考位按角色而非纯距离选择

纯按价格上下方选最近VAL/POC/VWAP/日周位，会在缓慢单边行情中把旧位继续显示成现位。修复顺序保持：数值源→生命周期→趋势角色排序→候选计划与几何→行动格/Data Window统一消费。

趋势角色优先级：

1. 同向有效FVG/OB或BOS翻转位；
2. 最近确认摆动低/摆动高；
3. 合理ATR距离内的有效静态结构位。

只有源码真正维护连续摆动分类状态机时，才能把第2项命名为HL/LH。仅有 `ta.pivothigh/ta.pivotlow`、最后摆动高低和BOS/CHoCH时，行动格必须写“摆动低/摆动高”，不得用HL/LH冒充不存在的能力。

生命周期至少区分候选、有效、触及、接受/拒绝、破位、翻转、过期。禁止用“固定N根K后自动换位”充当市场事件。无可靠位时进入价格发现：上涨显示 `等回踩低点·不追`，下跌显示 `等反抽高点·不追`。

前位只解释真实状态：`已破·不参考`、`过远·过期`或`新位替代`；不要把UI缓存更替写成“自动确认”。

### 结构行与协同行职责分离

结构行只回答谁控制、最近结构事件、下一结构动作，并持久化最近BOS/CHoCH：

- `多趋势｜BOS↑延续｜守摆动低`
- `空趋势｜BOS↓延续｜守摆动高`
- `转多｜CHoCH↑预警｜等多BOS`
- `转空｜CHoCH↓预警｜等空BOS`
- `结构震荡｜未破摆动｜等方向`

FVG、OB、扫位、CVD、HTF属于执行确认，不应与波动率、活位计数一起堆进结构行。

主表直接翻译副指标状态：`副S1/S2同向·A确认`或`仍等主触发`、`反向·降级`、`副S3冲突·不执行`、`副S4降权·仅B/C`、`副S0未接·A禁`、`主X·副不覆盖`。副指标同向不得把WAIT变成下单，也不得把B/C升级为A。

### Pine行为变更采用语义断言先行

改源码前先写确定性验证脚本，并确认它因缺少新行为而失败。断言至少覆盖：

- 三层CVD变量和样本不足文本；
- 合同号、字段解码和10,000组往返；
- 生命周期和价格发现降级；
- 固定K数自动换位与伪“自动确认”消失；
- 自然语言结构模板；
- S0–S4协同文案与X优先级；
- 单一source、五所量、四所OI和0技术告警保持。

通过后再做云端编译和客户端验证，避免只改表格文案而数值源与消费者仍走旧变量。

### 客户端完成证据链

`translate_light`之后，必须取得以下证据才能声称CE10117消失和新版已挂图：

1. Pine Editor实际装入完整源码，行数与本地一致；
2. 点击“添加到图表/图表更新”；
3. Pine控制台出现“编译中→完成→已添加到图表”；
4. Monaco markers为0；
5. `chart_get_state`出现新study实体；
6. `data_get_pine_tables`读到新行名和新语义；
7. `data_get_study_values`读到新版合同与Packed Bus。

Basic指标数量已满时，先移除待替换旧study再添加新版，避免把套餐上限弹窗误判为编译失败；测试结束恢复“主＋副”布局。

跨指标 `input.source()` 只有实际选择副指标对应plot才算接线成功；把字符串写进输入值不等于建立真实plot引用。最终以主表从S0切换到S1–S4、OI不再显示未接，且Data Window解码与副指标一致为验收。

## TradingView Desktop大源码客户端验收实操（2026-08-26验证）

### 精确装入源码

复杂脚本必须先证明编辑器源码身份，不能直接编译“看起来像目标版”的现有内容。Windows上已验证的稳健流程：

1. 用原生Windows剪贴板（`CF_UNICODETEXT`）写入完整UTF-8源码对应的Unicode文本；可直接运行 `scripts/copy_pine_to_windows_clipboard.py <源码文件>`，脚本同时输出规范化字符数、行数和SHA-256；
2. 通过页面上下文找到 `textarea[aria-label^='Editor content']` 并显式 `focus()`；
3. 发送 `Ctrl+A`、`Ctrl+V`；
4. 用 `pine_get_source` 读回编辑器内容；
5. 双方统一CRLF/LF后比较全文、行数、字符数和SHA-256；任何一项不一致都不得编译。

超长源码的粘贴和云端保存可能进入几十秒的pending状态。不要在pending时重复点击；轮询按钮 `data-qa-id` 和Pine控制台，等“编译中”结束。`pine_smart_compile`可能先完成保存而未挂图，随后仍要明确点击 `add-script-to-chart` 或更新按钮，并等待控制台出现“完成。已添加到图表”。

### 挂图后的运行清理

1. `chart_get_state`核对study实体，不能只看Monaco markers；
2. `data_get_study_values`确认主指标、Packed Bus、OI/CVD都有实时输出；
3. 若同名副指标出现两个实例，其中一个无Data Window输出且带红色错误标记，按实体ID只删除该异常重复实例，保留有完整五所量、四所OI和Packed Bus输出的实例；
4. 若截图只见CVD、主价格窗格高度为0，检查图表模型panes的 `isMaximized/height`，取消已最大化的CVD pane并确认恢复为上方价格K线＋右侧价格轴、下方CVD；
5. 最终截图必须同时显示价格K线、价格轴、主行动格、CVD副窗格，且无红色错误标记。

该流程解决的是客户端证据链与图表状态恢复，不替代源码合同断言、`translate_light`和Packed Bus重接验收。
