# OI Pack 编解码契约（20260814 修复定稿）

## 背景
AggVol 副指标输出 "HALDRO OI Pack (方向*100+一致%)" 供主指标 OI 行读跨所共识。
20260814 审计发现旧编码-解码有系统性缺陷，两端已同步修复。

## 编码端（副指标 L724）
```
编码 = oiDirCodeA * 100 + math.min(int(oiAgreementPctA), 99)
```
- oiDirCodeA ∈ {-1, 0, +1}（OI升/无向/OI降）
- 一致% 压到 **0-99**（100% 显示 99%，可接受损失）
- 例：185=OI升一致85%、-15=OI降一致85%、-1=OI降一致99%、100=OI升一致0%、0=不可用

## 为什么压到 99（修复的两个旧 bug）
1. **负向一致100% 撞零**：旧编码 -1*100+100 = 0，与"不可用=0"冲突，主指标整行判空
2. **负向镜像**：旧解码 `abs%100` 无方向感知——-15 实为 -100+85（一致85%），abs(-15)%100=15，解出错误值 15%

## 解码端（主指标 f_panel_oi，方向感知）
```
int oiAgreePct = not na(oiPackSource) and oiPackSource != 0
    ? (oiPackSource > 0
        ? int(oiPackSource) % 100                                    // 正向：abs%100 即一致%
        : (100 - int(math.abs(oiPackSource)) % 100) % 100)           // 负向：pack=-100+agree → agree=(100-abs%100)%100
    : na
```

## 验证（11 用例全过）
dir=+1,agree=85→185→85 ✓；dir=-1,agree=85→-15→85 ✓（旧逻辑错解15）
dir=+1,agree=100→199→99 ✓；dir=-1,agree=100→-1→99 ✓（旧逻辑撞零）
dir=+1,agree=0→100→0 ✓；dir=-1,agree=0→-100→0 ✓
dir=0→0→na ✓

## 审计快速判据
审双指标 OI 行时看到 `abs%100` 直接解码（无方向三元）= 旧格式 bug 标志。
两端文件必须**同步替换**（副指标改编码 + 主指标改解码），只换一端会错位。
