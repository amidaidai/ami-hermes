# 双指标审计评分口径（市场适配分 + 辅助决策分）

用户问「市场适配分 / 辅助决策分 / 有充分运用我们的指标吗」时的统一打分口径。源自 2026-08-10 双指标全面联网审计（SVP 主 / AggVol 副），先给数字再给依据表，扣分必须对应具体可修项。

## 市场适配分（0-100）
评估指标对多市场（加密/贵金属/外汇/股票/期货/指数）的适应能力。

| 维度 | 检查项 | 扣分示例 |
|---|---|---|
| 市场识别 | 9 预设+自动；ticker 字符串检测（BINANCE:XAUUSDT.P 陷阱）；主副指标同源 | 只认 syminfo.type |
| 参数自适应 | CVD 权重 / ATR 止损 / ADX / KZ 窗口 / SVP 行数 / 桶宽 / ADR 周期按市调 | 全市场一套参数 |
| 数据护栏 | 无逐笔市场 CVD 归零；薄量/低流动时段降级；周末模式 | 贵金属显示估算 CVD |
| 锚定一致 | market×timeframe 矩阵（<1h / 1h-4h / 4h+ / 1d+）主副逐格 ✓ | 副指标缺市场维度 |
| SMT 配对 | 同流动性池对照；期货/现货分流 | 乱配品种 |

实测基线：主 SVP 92（扣：股票/指数无 SVP 行数专门分支、HVN/LVN 未标）；副 AggVol 85（扣：非加密 OI/LSR/基差 request 未短路、爆仓代理对非加密仍计算）。

## 辅助决策分（0-100）
三原语（多远 / 多久了 / 该不该动）+ 置信 + 路径。逐行问「用户看了这行能立刻做一个动作吗」。

| 原语 | 检查 | 扣分示例 |
|---|---|---|
| 多远 | 入场位距现价 ATR 距离（磁吸行「距离A」先例） | 进场行只有价格无距离 |
| 多久了 | 触发年龄 ·NK；KZ 倒计时 | 信号存活未知 |
| 该不该动 | 就绪度% + 结论行动词 + 解锁路径 + 置信% | 信息多但无收尾动作词 |

实测基线：主 SVP 84（扣：年龄/距离此前不上桌）；副 AggVol 78（扣：无距离原语、无动作收尾 %）。

## 「有充分运用指标吗」检查法
90% 充分 = 计算量和使用率匹配。找「计算了但没上桌」三类：
1. MCP/Data Window 导出但行动格不显示的变量（triggerAge 信号年龄、replayPlanPrice 入场距离——零成本补显示）；
2. TV 内置免费变量（taker_buy_volume 主动买卖比，0 request 0 plot，比影线估算 CVD 更真；注意只对部分所/品种有数据，na 判断必须保留）；
3. 已有数据的二阶导数（ATR percentrank 波动率分位、OI 动量、CVD 斜率）。

## 推荐增强清单结构
按优先级分层给：P0（用户点名修正）→ P1（零配额成本二阶导数）→ P2（小改）→ P3（升级路径 request.footprint Premium+）。每条都标「成本 + 决策价值」，不增行动格行数、不撑宽。
