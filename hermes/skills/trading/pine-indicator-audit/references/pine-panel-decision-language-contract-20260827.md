# 行动格决策语义压缩与白话化

## 适用范围

用于主指标“现位”以及副指标“流向”等盘中高频阅读行。目标不是单纯减少字符，而是在固定宽度内保留人工决策链，并把工程术语改成交易员能立即理解的专业白话。

## 一、现位价格发现态

原始长串可能为：

`多·价格发现·等回踩低点·不追·等MSS↑·16:30定`

用户明确要求保留：方向、价格发现、不追、先形成低点/高点、MSS方向、确认时间。不得以“去重”为由压成仅`多·发现中`。

推荐压缩：

- 多：`多·发现·不追·低点→MSS↑·16:30定`
- 空：`空·发现·不追·高点→MSS↓·16:30定`
- 待定偏多：`待·发现·不追·低点→MSS↑·16:30定`

压缩规则：

- `价格发现`→`发现`；
- `等回踩低点`→`低点→`；
- `等反抽高点`→`高点→`；
- 箭头已表达等待顺序，`等MSS`可压成`MSS`；
- 不删除`不追`、MSS箭头或`HH:MM定`。

## 二、副指标流向行

避免这些工程短语：

- `今日买/卖`
- `滚动买/卖`
- `前锚买/卖`
- `单所1m`
- `聚合K`
- `买背离/卖背离`

改成专业白话三层：

- 当前短窗：`短线买方 / 短线卖方 / 短线均衡`
- 滚动背景：`近期买方 / 近期卖方 / 近期均衡`
- 前锚周期：`前日买方 / 前周卖方 / 前月均衡`
- 方法：`本所1分 / 五所K线`
- 背离：`顶背离 / 底背离`

推荐示例：

- `日·本所1分·短线买方·近期卖方·前日买方`
- `周·五所K线·短线卖方·近期卖方·前周买方`
- `日·本所1分·⚠顶背离·短线卖方·近期买方·前日买方`
- 样本不足：`日·本所1分·样本3/8·近期买方·前日卖方`

语义说明：

- `本所1分`仍是当前图表交易所1分钟估算，不得包装成五所逐笔订单流；
- `五所K线`是五所聚合K线方向估算，不是真实Bid/Ask Footprint；
- 日/周/月锚必须动态匹配前日/前周/前月，不能锚为周或月却仍写“今日/前日”；
- 只改显示层，不改CVD、方向票、S状态或执行授权合同。

## 三、验证

1. 静态确认旧工程术语不再进入可见字符串；
2. 主表13行、副表6行保持不变；
3. 五所成交量、四所OI、Packed Bus不删；
4. 不新增警报、请求或执行授权；
5. 完整源码经TradingView服务端编译0错0警；
6. 客户端真实加载后检查最坏字符串像素宽度；
7. 让用户只看一眼复述方向、等待条件和时间，若不能复述即为可读性失败。
