# TradingView免费版双指标请求路由与决策闭环（2026-08-26）

适用于：一个主指标＋一个副指标、单一`input.source()` Packed Bus、人工决策而非自动交易的免费账号架构。

## 1. 架构合同

- 主指标是唯一执行授权源：方向、结构、位置、Entry/Stop/Target、R:R、A/B/C/X。
- 副指标只做确认、冲突、降权和数据质量，不独立产生交易计划，也不得把B/C升级成A。
- 优先级固定：`X > WAIT > A > B/C`。
- Basic只保留一个`input.source()`，把合同版本、S0–S4、OI方向、价格方向、OI一致率、OI变化和CVD背景压入一条Packed Bus。
- 重加任一脚本后必须在客户端重新核对总线接线；编译通过不等于跨指标连接已恢复。

## 2. Pine v6请求优化的正确做法

### 真短路

把`request.security()`放进函数，并只在真正需要时调用：

- 非加密品种不调用五所加密成交量、四所加密OI、LSR和加密基差。
- 后缀为`None`时，在进入请求函数前返回零/`na`；不要构造`BASE0`之类无效代码再依赖`ignore_invalid_symbol`。
- 关闭或重复的交易所，在请求前短路。
- 汇率只在非USD/COIN单位时调用。
- 基差现货价只在“加密＋永续图＋基差开关开启”时调用。
- 四所OI有效时不调用单源OI回退；只有聚合关闭或四所均失效时才请求回退源。

仅隐藏plot/table结果不会节省请求；Data Window-only plot仍占plot count。调用点数量也不等于实际唯一上下文，最终以实际执行分支和客户端运行验收为准。

### 数据源保护

优化请求不能静默削减核心覆盖。对于棠溪双指标：

- 保留五所成交量：Binance、Bybit、OKX、Coinbase、Bitget。
- 保留四所OI：Binance、Bybit、OKX、Bitget。
- 优先短路“不该执行的上下文”，再压缩低价值Data Window导出和重复视觉对象。

## 3. 汇率失败合同

- 默认USD/COIN路径不请求汇率。
- EUR/RUB需要汇率时，缺失不得用`nz(rate, 1.0)`伪装换算成功。
- 可暂保留USD基准数值供观察，但必须：
  1. 进入S4；
  2. 覆盖/风险行显示“汇率缺·暂按USD”；
  3. 操作行提示“改USD或等汇率恢复”；
  4. 不允许升级主指标。

## 4. 行动格应回答的四个问题

主指标必须直接回答：

1. 现在做不做；
2. 偏哪边；
3. 当前缺哪个条件；
4. 什么条件解除阻断。

推荐缺项链：

- 未接总线：`A级禁·接副指标Basic Bus`；
- 合同版本不匹配：`A级禁·副指标合同不匹配`；
- S3：`不执行·等副CVD/OI转同向`；
- S4：`仅人工·等覆盖/OI恢复`；
- 高周逆：`等高周同向→触发路径`；
- CVD冲突：`不执行·等CVD转同向`；
- 位移缺：`已到位·等位移→收线`；
- 未收线：`盘中候选·等收线`；
- 触发过期：`等新扫位/位移`；
- R:R不足：`不做·等更好价`。

风控行用“主阻断＋解除条件”，如`阻:CVD冲突·解:CVD同向`。

副指标操作行的S3必须优先于S4，避免CVD/OI冲突被泛化的“数据降权”吞掉；S4则指出具体恢复条件，如覆盖阈值、数据源恢复、至少两所OI同向或汇率恢复。

## 5. 市场状态与周期职责

市场状态只映射执行模型，不新增第二套授权逻辑：

- 趋势：只做回踩；
- 平衡：只做VAH/VAL边界；
- 收缩：等放量位移；
- 扩张：等首次回踩；
- 耗尽：等扫位反转。

周期职责：5m精确触发、15m执行准备、1h交易区域、4h核心结构、1D及以上背景方向。

贵金属/外汇现货的CVD和volume须标记为tick量/单图估算，不计A级票；`BINANCE:XAUUSDT.P`虽可能被TV归类为crypto，也要用ticker字符串识别为贵金属。

## 6. 统一人工警报

免费版只创建一个`Any alert() function call`警报。脚本内按收线后的状态边沿提醒：

- 新A级；
- X禁做；
- S3冲突；
- 与当前计划相关的S4降权；
- 触发过期。

警报只提醒，不自动交易。边沿应使用`state and not state[1]`，避免持续状态每根K重复推送。

## 7. 验证方法

完成后至少验证：

1. 静态/语义合同断言；
2. TradingView完整源码服务端编译0错0警告；
3. 五所成交量和四所OI未被削减；
4. 只有一个`input.source()`；
5. S0–S4、A级唯一许可、B/C人工候选、X优先；
6. 非加密、None后缀、汇率、OI回退、基差分支均在请求前短路；
7. 客户端保存、图表加载、Data Window、Packed Bus、实时K/收线K、刷新重载与回放。

自动断言统计`alert()`时，不要直接对全文正则计数，因为注释和tooltip里的`alert()`也会命中；只统计去除注释/字符串后的语法，或至少统计去除前导空白后以`alert(`开头的可执行行。

网络编译端点偶发超时若随后重试成功，只记录“带退避重试并以最终回执为准”的通用验证模式，不把瞬时超时固化成工具不可用结论。
