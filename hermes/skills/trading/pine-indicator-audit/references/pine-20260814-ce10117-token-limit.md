# CE10117 编译 token 上限——修正终版（20260814 晚段）

> ⚠ 本文件第二版（注释计 token 论）为**错误结论**，已被本版推翻。以本版为准。

## 现象与真因

- TV 桌面真实编译报 **CE10117："Compiled code contains too many tokens: 101085. The limit is 100256"**。
- 免费档编译产物 token 上限 **100,256**（仅 TV 客户端校验；pine-facade translate_light 服务端只验语法、**不验 token/配额**）。
- 真因：第三批新增 RTH DO + Air Pocket（约 70 行代码）使主指标代码 token 从贴线内推到 101,085（超 829）。

## 关键实证（推翻"注释计入 token"）

- **注释不计入 token**。铁证：第二批完成版（242,240 字节，含 13KB 全中文注释）在 TV 桌面编译通过且行动格表格实际运行读出（22:43 实测）。
- 用户用"删注释版"仍报完全相同的 101,085 → 删注释对 token 零影响。
- 之前"删注释后 markers 空=通过"是**假阴性**：当时图表实例槽错位（编辑器脚本与图表脚本身份不一致），点击"图表更新"后编译未真正执行。

## 教训链（三级）

1. **markers 空 ≠ 编译通过**。验证 TV 客户端编译必须看编译错误按钮（title 形如 `编译错误: CE10117 · 在Pine编辑器打开`）是否出现/消失；仅查 Monaco markers 会被假阴性骗过。图表实例槽错位时"图表更新"点击无效。
2. **全量编译双端点**：translate_light 只验语法；配额类错误（token CE10117、外部元素 CE10116）只有 TV 客户端编译才报。交付前两种都要过。
3. **回滚验证用字节数**：回滚第三批后文件精确回到 242,240 字节 = 与 22:43 实测通过版字节级一致 → 无需再冒注入风险实测，字节一致即证据。
