# TV 云端脚本、编辑器缓冲区与图表实例三层部署闭环

## 适用场景

完成 Pine 修复后，需要保证以下三层不是“看似更新、实际仍旧版”：

1. **编辑器缓冲区**：`pine set` 写入的当前 Monaco 内容。
2. **TradingView 云端脚本**：脚本列表中保存的原生产脚本。
3. **图表 study 实例**：当前图表真正执行并向 Data Window 导出值的实例。

仅有编译成功不代表三层都已更新。

## 本轮发现的关键陷阱

- `pine set` 只改编辑器缓冲区；必须显式保存。
- `pine get` 在编辑器打开时可能读当前缓冲区，不能单凭它证明云端脚本已持久化。
- `pine open <name>` 的内部 API 返回标题/脚本 ID 时，UI 编辑器可能仍停在另一个脚本；应以 Pine 编辑器标题按钮和实际源码共同确认。
- “添加到图表/图表更新”会操作编辑器当前绑定的脚本实例。若脚本身份未切换成功，可能把副指标实例替换成主指标，或反之。
- 保存云端脚本后，已挂载的旧 study 实例不一定自动获得新增 Data Window plot。必须重载实例并检查新字段。

## 稳健部署步骤

### 1. 编辑器层

1. 通过 Pine 编辑器的“打开脚本…”菜单明确选择目标脚本。
2. 确认编辑器标题等于目标云端脚本名。
3. 写入完整源码。
4. 等待 Monaco 更新后运行 errors/compile；必须 `0 errors`。
5. 点击 Pine 编辑器自己的“保存脚本”按钮，等待状态变为“已保存”。

### 2. 云端持久化层

不要在同一缓冲区内立即 `pine get` 就宣称云端已保存。应：

1. 切换到另一个已保存脚本；
2. 再从“打开脚本…”菜单重新打开目标脚本；
3. 读取完整源码；
4. 统一 `CRLF/LF` 后与本地交付文件做字节比较或 SHA256；
5. 源码一致才算云端保存完成。

TradingView 返回源码常为 CRLF；比较前统一：

```python
normalized = source.replace("\r\n", "\n").replace("\r", "\n")
```

### 3. 图表实例层

1. `chart_get_state` 记录主、副指标 entity ID。
2. 若新增 Data Window 字段，优先移除旧 entity，再从已确认的原生产脚本点击“添加到图表”。
3. 再次 `chart_get_state`，确认主指标、副指标各只有一个实例。
4. 调用 `data_get_study_values`，必须看到新增字段：
   - 主指标：`MCP CVD Method Code...`
   - 副指标：`OI Change % (Normalized)`、`HALDRO Risk Code`、`HALDRO Valid Code`
5. 在 5m/15m/1h/4h/D 五周期逐一读取，确认不是只在单周期可用。

## 临时副本策略

若原脚本身份切换受未保存缓冲区干扰，可先“复制…”为临时优化副本，完成编译与挂图验证；但最终必须：

1. 回到原生产脚本；
2. 保存同一份优化源码；
3. 重开并比对云端源码；
4. 移除临时副本的图表实例；
5. 从原生产脚本重新添加图表实例。

临时副本只能作为安全中转，不能长期冒充生产权威。

## 双指标本轮新增审计准则

### 跨交易所 OI

不同交易所及 USDⓈ-M/COIN-M 合约的原始 OI 单位可能不一致，不能直接把 raw OI 相加后用于方向和背离。生产建议：

1. 每个交易所先算 OI 百分比变化；
2. 对有效交易所变化做等权或显式权重聚合；
3. 方向、背离、Confirm Score 使用归一变化；
4. `OI Total` 仅保留兼容展示，不参与跨所方向裁决；
5. Data Window 导出 `OI Change % (Normalized)`。

### HALDRO 真实高周期

用 `ACT_LB * 6` 回看当前周期不是高周期。必须使用真实 `request.security()` 请求下一层周期，并采用已确认 HTF 值。推荐映射：

- 5m → 15m
- 15m → 1h
- 1h → 4h
- 4h → D
- D → W

### 风险位图

HALDRO Risk Code 建议统一：

- `1` 低覆盖
- `2` 单所主导
- `4` 上级冲突
- `8` OI 背离
- `16` CVD 背离
- `32` 非加密
- `64` LSR 拥挤

下游必须按位解码；A 级遇到 `4/8/16/64` 应降级为等待，主副强冲突时转 X 禁做观察。
