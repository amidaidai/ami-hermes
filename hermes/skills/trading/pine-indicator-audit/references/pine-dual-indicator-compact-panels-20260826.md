# 双指标行动格压宽与六行副表（2026-08-26）

适用于成熟的 SVP 主指标 + AggVol 副指标，目标是缩窄表格但不删除决策合同、五所成交量、四所 OI 或唯一 Packed Bus。

## 主指标压宽规则

1. **结构行只留三件事**：方向、已确认事件、下一步。例如：`转空·CHoCH↓·等BOS·收缩·等放量`。不要再追加周期角色、重复波动解释或伪 HH/HL/LH/LL。
2. **进场行只留许可与下一步**：如 `接副总线·A禁`、`S3冲突·等CVD/OI同向`、`到位·等位移收线`、`A执行 78720·扫低收回`。信号年龄放结论，距离放磁吸，避免重复。
3. **协同行不重复 CVD/OI**：CVD、OI 已有独立行时，协同只显示 S0–S4、高周和必要时机。
4. **风控行**：止损、目标、最高优先阻断；解除动作由进场行表达，避免同一阻断写两次。
5. **前位/现位**：前位只留名称、价格、生命周期；现位只留位置、触发、定时刻。
6. 磁吸↑/↓保持独立两行，保留身份、价格、ATR距离、评分、HTF和命中率；不要为压宽牺牲目标身份。

## 状态与方向一致性

- 统一优先级：`X > S0/S3/S4/WAIT > A > B/C`。
- S0、S3、S4必须覆盖普通趋势文字，禁止在结论写“等多”而协同写“S3不执行”。
- 结构方向优先；只有结构中性时才回退趋势分，防止 `结构转空` 与 `等MSS↑` 同时出现。
- `manualBcCandidate` 至少使用：`bcDirectOk and priceGeometryOk and not setupX`。低于 1.5R 不显示 B/C 候选价格；A 仍需至少 2R 和完整硬闸门。

## AggVol 固定六行

固定顺序：

1. `信号`：S状态、共振票、最高优先风险；
2. `结论`：价量/OI环境；
3. `流向`：估算CVD；
4. `持仓`：价格×OI四象限、共识、LSR；
5. `量能`：放缩量、永续占比、同步放量；
6. `操作`：下一步及对主指标的影响。

覆盖率和完整风险列表不再另起宽行，保留在 Data Window；行动格只显示最高优先风险。五所成交量、四所 OI、Packed Bus 不得因压宽被删除。

## 验收

- 静态：确认唯一 `input.source()`、B/C R:R 门槛、S0–S4、五所量、四所 OI、Packed Bus 均存在。
- 语法：`translate_light` 两份均 0 错误、0 警告。
- 客户端：必须分别保存到正确的脚本名称；同名 `scriptTitle` 可能让 `pine_open` 匹配错脚本，保存前用脚本列表核对 `scriptName/title/version`，必要时从 Pine 编辑器脚本菜单明确选择目标脚本。
- 运行态：读取 Pine tables，副表必须恰好 6 行；主表不得出现多空方向冲突。
- 最终完成声明前，图表必须同时存在主、副两个 study，并验证 Packed Bus 从 S0 变为真实 S1/S2/S3/S4。只完成编译或曾短暂读到六行，不等于最终双指标安装验收完成。
