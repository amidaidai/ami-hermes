## 规则

1. 「现在盯什么」只给一个主观察位（通常是最近的结构位或反抽目标），三态＝↑收上作废线／↓遇阻+结构确认／○横盘等收线；不要并列多套方案。
2. 关键位表：上行位由近到远、下行位由近到远，每行 ±% 由脚本算（禁止手算），★标 HTF 磁吸。
3. 多源表固定行序：主 SVP → 副 AggVol → OI → 费率 → 多空 → Taker → 深度；深度多采样翻转时标 × 弃用，不写方向。
4. 首屏 3 行：品种·现价·方向·时段·时间；⭐主推；结构摘要（VA 位置/结构状态/未扫）。
5. 脚注一行：Binance 状态＋价差、24h 涨跌高低额、档位与继承备注。
6. 无「多周期定位」表（轻量档）；标准档补邻居周期结论行；完整档按 router full。
7. 同一事实只写一遍：盯什么表写动作，关键位表写地图，多源表写证据。
