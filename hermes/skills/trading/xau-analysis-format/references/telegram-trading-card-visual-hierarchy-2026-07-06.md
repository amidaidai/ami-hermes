# Telegram 交易卡视觉层级与结构位优先排版（2026-07-06 BTC会话沉淀）

## 背景

棠溪连续纠正 BTC RichMarkdown 交易卡首屏：

- 普通聊天 Markdown 表格会降级，不算真表格；正式卡必须 `sendRichMessage` + `RichMarkdown`。
- 首屏不能是大段文字；手机上必须一眼能扫。
- 开头要用“一、二、三”中文序号和标题，但不能写成纯文字堆叠。
- 标题和表格标题要加粗；Telegram 富文本支持加粗。
- 价位前必须带结构位名称，例如 `15m VAL 61,334`、`M VWAP 61,302`、`15m POC 61,985`，不要只写价格。
- 下方表格的“侧重点”必须准确标注，不要泛泛写【重点】。

## 正确首屏形态

正式交易卡首屏采用“标题 + 小表格 + 两段短表”的视觉层级，不要使用 4 段以上连续文字。

```markdown
## **2026年7月6日21：37 · BTC**

| **结论** | **↓偏空等反抽，不追空** |
|:---|:---|
| **现价结构** | `15m VAL 61,334` 上方 · `M VWAP 61,302` 上方 |
| **当前区间** | `61,400-61,600` |
| **上方磁吸** | `15m POC 61,985` → `周日低 62,410` |
| **主空区** | `15m POC 61,985` 到 `周日低 62,410` 失败空 |
| **禁做** | `15m VAL 61,334` / `M VWAP 61,302` 上方追空 |

## **一、现在在哪：VAL与月VWAP上方的深折价区**

| **标签** | **重点** |
|:---|:---|
| **刚发生** | `63,900` 连续下杀到 `61,297-61,364` |
| **当前脚下** | `M VWAP 61,302` · `15m VAL 61,334` |
| **当前上方** | `15m POC 61,985` · `周日低 62,410` |
| **结构性质** | 深折价，不是追空点 |

## **二、现在怎么做：看POC/VAL回收关系**

| **标签** | **重点** |
|:---|:---|
| **空头触发** | 反抽 `15m POC 61,985` 到 `62,410` 失败 |
| **短多触发** | 守 `15m VAL 61,334` 并收回 `62,023` |
| **风控失效** | 15m 收上 `62,760`，空头方案取消 |
```

## 结构位优先规则

凡是交易卡里出现关键价格，优先写成：

- `周期/来源 + 结构位 + 价格`：`15m VAL 61,334`、`4h POC 62,700`、`M VWAP 61,302`。
- 如果是会话高低点：`周日低 62,410`、`周一亚高 63,900`。
- 如果是盘口：`Depth买墙 61,325-61,350`。
- 禁止只写裸价位列表；用户会觉得“看不出是什么”。

## 侧重点标记词库

按表格语义选择精确标签：

| 场景 | 推荐侧重点 |
|:---|:---|
| 当前脚下/不能跌破 | **【防守】M VWAP**、**【防守】15m VAL** |
| 主要入场 | **【核心】主空区**、**【执行】15m POC** |
| 趋势背景 | **【方向】主趋势**、**【背景】日线** |
| 节奏/反弹风险 | **【节奏】反弹风险**、**【触发】短线确认** |
| 风险控制 | **【风控】止损上沿**、**【失效】空头取消** |
| 外部验证 | **【反指】多头拥挤**、**【盘口】上方压制**、**【情绪】极度恐惧** |
| 禁止动作 | **【禁区】现价位置**、**【禁做】追空** |

避免笼统的【重点】刷屏。每个表最多 1-2 个【核心】，其余用功能性标签。

## 发送与验证

- 仍使用 `scripts/telegram_reliable.py::send_telegram_reliable(..., parse_mode="RichMarkdown")`。
- 发送回执必须为 `True rich_sent`。
- 普通 assistant 文本只做回执说明，正式内容发 RichMarkdown 真表格。
