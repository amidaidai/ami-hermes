# Telegram RichMarkdown 分析卡：结论 + 人话 + 真表格

## 本次纠正

用户确认：Telegram 里必须是真表格，但**不是全篇只有表格**。纯表格会缺标题、缺结论、读起来像数据 dump。正确形态是：

1. 首行自然语言结论：方向箭头 + 品种 + 现价 + 明确动作 + 中文时间。
2. 一小段人话解释：用 1-3 句说明为什么这么做、当前禁做什么。
3. 3-4 张 RichMarkdown 真表格：承载流程、多周期、关键位、方案等结构化数据。
4. 末尾最终裁决：主方向、当前动作、失效条件。

## 发送路径

- 必须用 `sendRichMessage` + `rich_message.markdown` / `parse_mode='RichMarkdown'`。
- 普通 Hermes 回复、普通 `sendMessage`、MarkdownV2 管道表会在 Telegram 端降级成 bullet/纯文本，不算真表格。
- 发送后回执至少要返回 `rich_sent`；关键报告最好检查 rich message blocks 是否含 table。

## 标题规则

- 可以有简短标题，如 `流程完成度`、`多周期定位`、`关键位`、`交易方案`。
- 标题和表格之间保留空行。
- 不要把 `表1 · xxx` 紧贴在表格前一行；这会让 RichMarkdown 在部分客户端降级。
- 标题不是替代结论；首行必须直接给交易结论。

## 常见错误

| 错误 | 后果 | 修正 |
|:----|:----|:----|
| 全文只有表格 | 用户看不到标题/结论 | 加首行结论+人话解释+末尾裁决 |
| 普通回复通道发管道表 | Telegram降级成bullet | 走 RichMarkdown 直发 |
| 表格前紧贴`表1 · xxx` | 可能不解析成表格 | 标题独立且空行后再表格 |
| 表太多太宽 | 手机难读 | 3-4张表，每表≤3列 |
