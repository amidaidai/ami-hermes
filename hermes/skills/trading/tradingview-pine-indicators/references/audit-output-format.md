# Audit Output Format for 棠溪

## Rule
When the user requests "审计这个指标", "问题", or any Pine indicator audit/review:

- First response must be **一段话直接问题**: one concise paragraph that directly states the main problems (P0 first, with decisive line numbers or patterns only when essential).
- Do **not** lead with overall evaluation, long tables, multi-section reports, detailed background, or verbose explanations.
- Only expand into full analysis, evidence, or fix recommendations if the user says "展开", "详细", or asks follow-up questions.
- This was explicitly reinforced when a full structured audit was followed by the direct request "一段话直接问题".

Embed this as the default first deliverable for any audit task on indicators. Detailed sections come second.

## Why
User strongly prefers direct, low-verbosity problem statements for decision-making. Long reports after the fact waste time when the core issues can be stated in one paragraph.
