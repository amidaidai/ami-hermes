# 双指标运行态验收与决策一致性（2026-08-26）

适用于：SVP 主指标 + AggVol 副指标的 TradingView 客户端验收、运行态审计和人工决策质量复核。

## 1. 验收顺序

1. `chart_get_state`：确认标的、周期、study 实体；不要只看编辑器“已保存”。
2. `data_get_study_values`：确认主指标的 MCP 输出、AggVol 的覆盖/CVD/OI/Packed Bus 输出。
3. `data_get_pine_tables(study_filter=...)`：读取行动格的真实最终文字。
4. `capture_screenshot`：确认价格K线/价格轴/行动格/CVD窗格和视觉错误标记。
5. 如果运行态和截图不一致，以 Data Window/表格的实际值为准，并继续查 pane/source 状态。

## 2. Packed Bus 接线判定

副指标有 `Basic Packed Bus` 数值，不等于主指标已经接线。必须同时满足：

- 主指标不显示 `副S0未接` 或 `OI未接`；
- 主指标能够读出合同码 22002；
- 主指标状态变为真实 S1/S2/S3/S4；
- 主副 Data Window 的合同、状态和方向字段一致。

重新添加主指标后，`input.source()` 可能回到默认 `close`，必须重新选择 AggVol 的 `Basic Packed Bus（唯一主副连接）`。

## 3. 冲突状态的裁决

若副指标为 S3：

- 主指标不得授权 A 级；
- 不得把 B/C 候选解释成可执行订单；
- 操作应明确为“副指标冲突·不执行”，并指出等待条件；
- 只要 OI 分歧、CVD 背离或数据合同未接，不能因主图单一结构信号强行开仓。

副指标的 `OI一致率`、`OI Breadth`、`Confirm Score`、`同步放量`和 CVD 样本数应一并读取；覆盖 5/5 不代表方向共识成立。

## 4. 行动格一致性检查

同一根K上，以下字段必须不互相打架：

- 结论；
- 方向；
- 结构；
- CVD/OI 协同；
- 现位动作。

禁止出现类似：`等多` + `结构转空` + `等空BOS` + `MSS↑`。实现上应先生成一个统一的最终方向状态（多/空/中性/X/S3），再由所有行动格文本消费它，而不是让趋势评分、结构状态和计划方向各自独立选边。

## 5. B/C 价格候选边界

`manualBcCandidate` 必须同时满足 B/C 直接候选门槛、几何有效、非 X；推荐使用：

```pine
bool manualBcCandidate = bcDirectOk and priceGeometryOk and not setupX
```

否则可能在 R:R 不足 1.5 时仍显示 B/C 入场/止损/目标价格。边界应保持：A 需 R:R≥2.0；B/C 人工候选至少 R:R≥1.5；低于 1.5 只显示等更好价。

## 6. 图表清理陷阱

同名 AggVol 可能有多个实体，其中一个没有有效 Data Window 输出并带错误标记。按 entity ID 识别后，只删除异常重复实例，保留能输出五所覆盖、四所 OI、CVD 和 Packed Bus 的实例。

如果截图只显示 CVD 而看不到价格K线，检查 pane 的 `isMaximized` 和高度。取消 CVD pane 最大化后，应恢复上方价格窗格、右侧价格轴和下方 CVD 窗格。

## 7. 设置面板可用性

大型 Pine 指标即使没有 CE10117，也要审计输入数量和高级开关：

- 统计主/副 `input.*()` 数量；
- 检查 `SHOW_ADVANCED` 是否真的控制高级输入，而不是只控制少数两个参数；
- 区分日常设置、偶尔调整和审计参数；
- 不要因为“输入很多”就盲删核心合同、五所成交量、四所 OI 或唯一总线。

## 8. 风险包语义

如果 Data Window 的风险包是固定常量（例如 `Risk10% + 日损3% + 周损6%`），只能命名为风险配置包，不能称为当前账户风险、仓位计算或爆仓风险。账户余额、仓位、杠杆和真实亏损金额应由外部风控模块计算。

## 9. 证据原则

- `translate_light` 只证明服务器语法接受；
- Monaco markers=0 只证明编辑器没有当前语法标记；
- 客户端“编译完成/已添加到图表”证明 CE10117 通过；
- Data Window/行动格/Pane/Study 实体共同证明运行态；
- 截图只做视觉确认，不替代数值和表格验收。
