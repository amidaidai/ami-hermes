# 表格驱动分析卡格式（2026-06-28 用户确认）

## 来源
本会话确认。用户说"我不是说以前会有表格的形式吗？" → 全表格驱动格式。要求加时间 → 头行 `HH:MM BJT`。

## 适用场景
手动分析卡 / 完整卡。不替代 v4.2 推送格式（推送仍用 ↑↓○×+①②③编号）。

## 标准模板

### 首行
```
## ↓/↑ BTC $price · 方向概括 · HH:MM BJT
```

```

|:----:|:----:|:---------|
```

每个周期必须有状态描述（过热/深折价/走弱/等反抽），不单列名。

## 排版规则
- 表头用 `|:----:|` 居中或 `|:-----|` 左对齐
- 价格全反引号 `$price`
- 首行 `##` 标题含方向箭头 + 价格 + 时间
- 时间用 BJT（北京时间 UTC+8）
- 不嵌套表，每表 ≤5 列
- 失效条件和总评放在表外底部
