# 告警推送格式规范

## Telegram 推送格式

每次告警必须包含以下 6 个部分：

```
{emoji} {品种} {事件类型}
价格：`{price}`
  {level1} `{lvl1}` {arrow}{dist}%
  {level2} `{lvl2}` {arrow}{dist}%

上次周期：{last_cycle}

{urgency}
→ 说「分析 {品种}」
```

## 规则

1. **中文上下文 + 标准英文术语** — 保持 DO/VWAP/POC/CVD 不改，其余中文化
2. **每行一个级别** — 用缩进 `  ` + 名称 + 反引号价格 + 方向箭头 + 百分比
3. **箭头含义** — ↑ 价格高于该位（在上方），↓ 价格低于该位（在下方）
4. **带上次分析周期** — 从 monitor_levels.json 的 analysis_cycle 字段读取
5. **带操作建议** — 突破=⚡需立即分析，接近=📊可分析确认
6. **无多余字符** — 不用 · 连接多级别，不用 — 破折号堆砌
