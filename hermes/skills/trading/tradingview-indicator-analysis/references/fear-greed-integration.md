# 恐慌贪婪指数接入

## API

```
GET https://api.alternative.me/fng/?limit=5
```

返回：
```json
{
  "name": "Fear and Greed Index",
  "data": [
    {"value": "22", "value_classification": "Extreme Fear", "timestamp": "1781654400"},
    ...
  ]
}
```

免费·无需认证·每日更新一次。

## 信号解读

| 区间 | 分类 | 含义 | 操作暗示 |
|------|------|------|---------|
| 0-25 | 极度恐惧 | 市场过度恐慌 | 历史底部区域·潜在大底 |
| 25-45 | 恐惧 | 偏空情绪 | 可轻仓试探 |
| 45-55 | 中性 | 平衡 | 等方向 |
| 55-75 | 贪婪 | 偏多情绪 | 注意回调风险 |
| 75-100 | 极度贪婪 | 市场过热 | 顶部区域·减仓信号 |

## 趋势分析

取最近5-7天的值排序列，判断情绪是在恶化还是修复：
- 22→23→20→18→13：持续极度恐惧 → 情绪未修复·等拐点
- 13→18→22→35：恐惧值回升 → 情绪修复中·利好

## 引擎耦合

恐慌贪婪 < 25 + 引擎判偏空 → 极度恐惧叠加·大底概率升高
恐慌贪婪 > 75 + 引擎判偏多 → 极度贪婪叠加·顶部概率升高
恐慌贪婪 25-45 + 引擎判偏多 → 恐惧中做多·谨慎乐观（加分0.1到衍生品维度）
