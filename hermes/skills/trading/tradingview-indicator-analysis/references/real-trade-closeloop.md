# 真实成交闭环速查（解锁权重调整的唯一路径）

> 目的：策略治理要求 **≥20 笔真实复盘样本** 才允许升权/调阈值。
> 在此之前，所有回测胜率、模型强弱**只能定方向，不能定仓位**。
> 这份文档是每笔手动单的固定流程，照走就能稳定累积合规样本。

## 为什么必须走闭环

- 回测数字有趋势偏差（VWAP反抽 31天单边下跌 94% 胜率是趋势送的，震荡月会翻车）。
- `regime_backtest.py` 已能分趋势/震荡分栏，但分栏后每态样本仍 <10，标注"不用于权重"。
- 真实成交是唯一不带前视偏差的样本来源。没有 20 笔真实复盘，权重调整就是拍脑袋。

## 每笔交易三步闭环

### ① 开仓时 — 立即标记

```bash
python scripts/成交记录.py --symbol BTCUSDT --model VWAP反抽 \
  --side 空 --entry 62719 --stop 67255 --target 61519 \
  --qty 0.0041 --risk 2.03
```

- `--model` 必须是五类固定模型标准中文名（`VWAP反抽`/`VAH回收`/`VAL回收`/`POC拒绝`/`扫流动性回收`/`突破接受`），无空格。
- 写入 `data/trade_reviews.jsonl`，状态 `open`。
- 开仓即记，不要事后补——事后补会丢失当时的真实入场理由。

### ② 平仓后 — 当天复盘

```bash
python scripts/成交复盘.py --model VWAP反抽 \
  --result win --exit 61519 --pnl_r 2.0 \
  --error 无 --discipline 良好
```

- `--result`：`win`/`loss`/`breakeven`。
- `--pnl_r`：实际盈亏 R 倍数（不是百分比）。
- `--error`：错误标签（追价/止损过窄/逆势/无）。
- `--discipline`：纪律状态（良好/破纪律/情绪化）。
- 更新 `data/trade_reviews.jsonl` 对应记录为闭环，同步更新 `risk_state.json`。

### ③ 每满 5 笔 — 跑分市态分栏

```bash
python scripts/regime_backtest.py --source reviews   # 用真实复盘而非回测K线
python scripts/策略治理.py                            # 看样本数/胜率/平均R/连亏
```

- 样本 <20：只看方向稳健性，**不动权重**。
- 样本 ≥20 且分市态期望都为正：可向棠溪申请升权（仍需手动批准）。
- 任一市态期望为负：该模型在该市态降权或停用。

## 铁律

- 每笔必须有 `model` 字段，否则样本作废（无法归因到模型）。
- 100U 本金阶段，单笔风险默认轻仓（2-3U），`10U` 是上限不是常态。
- 真实样本 <20 前，回测高胜率**禁止**用于放大仓位。
- 趋势月样本和震荡月样本必须分开统计（regime_backtest 已支持）。
- 存在未复盘的真实成交时，下一笔最高轻仓（策略治理强制）。

## 当前状态锚点（2026-06-19）

- 真实复盘样本：极少（多为 B等待/分析刷新，非真实执行）。
- 解锁权重调整还需累积约 20 笔闭环成交。
- 在此之前系统只定方向，仓位走固定轻仓 + 风控闸门。
