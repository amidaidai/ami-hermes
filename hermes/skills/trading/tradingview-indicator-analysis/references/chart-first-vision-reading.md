# 图表优先读图铁律（2026-08-29 · 用户纠正P0）

> 用户明确纠正：「不能单单只靠我表格的内容啊，你要看一下图表的信息。」
> **核心原则**：判方向/结构不能只看指标行动格表格（文本），必须真实读取 TradingView 图表上的可视化信息。表格文字常把「收敛/承接」误判成「单纯空/多」。

## 为什么必须读图
主指标行动格（SVP+ICT+VWAP+CVD）把行情压缩成 13 行表格文字，副指标（Volume Aggregated）压成 7 行。文字是**机器对行情的概括**，但会丢失：
- K线真实形态（长下影=承接、十字星=无方向、收敛小实体=盘整）
- 收敛/承接区 vs 持续趋势的区分（文字只说"偏空"，图上是"下跌后收敛横盘"）
- CVD 窗格是否创新低（CVD不创新低=卖压衰竭，这是空头减弱的强信号，表格文字反映不出来）
- 价格相对关键横线的真实夹缝位置

## 读图层级（从强到弱，强者优先）
1. **真实K线结构**（vision 读全屏截图 + OHLCV summary）
   - 整体：上涨/下跌/震荡/收敛
   - 最近3-5根：实体大小/颜色/影线
   - 摆动高低点在实际哪
2. **CVD/量能窗格形态**（底部窗格，vision 读）
   - CVD 是否创新低 → 不创新低 = 卖压衰竭（空减)
   - CVD 是否创新高 → 不创新高 = 买压衰竭（多减）
   - 量能：放量/缩量（放量突破=确认，缩量反抽=存疑）
   - 买卖占优（青色=买，红=卖）
3. **关键位横线相对位置**（pine_lines + pine_labels）
   - 现价夹在最近阻力/支撑线多少点之间
   - 关键位：VAH/VAL/POC + 会话高低（周五高/低/伦高/伦低/纽高/纽低）+ 上周高
4. **FVG/OB 框**（data_get_pine_boxes）
   - study_count=0 → 该周期未渲染框，标注"15m未渲染SVP框"不硬凑
5. **指标行动格表格**（辅助，不主导）—— 作为机器总结交叉验证

## 判读规则
- **图表形态 > 表格文字**：表格说"偏空·空趋势BOS↓"，但图上是收敛横盘+CVD不创新低 → 空头须**放量才确认**，否则存疑。
- **收敛/承接区**：下跌后 77,210-77,860 收敛横盘 + CVD 低位不创新低 → 这是**卖压衰竭的承接区**，不是单纯持续空头。空头预案要收紧确认（反抽放量才空）。
- **进场必须有量能确认**：缩量介入=赌博。反抽到关键位那一根**放量**才确认；**缩量**反抽 → 先看中间 VAL/低点承接。
- 关键位重复核对：同一价位在 pine_lines 和 pine_labels 都出现 → 高置信；只在一个出现 → 标注置信较低。

## 逐周期读图顺序（完整模式）
1. **1D**：OHLCV summary（宏观背景），vision 读日线大结构
2. **4h**：pine_tables + study_values + labels（趋势骨架 + 磁吸）
3. **1h**：同上（结构确认 + 现位路径）
4. **15m**（主执行）：全量 + pine_lines/labels + **vision 读结构收敛/承接**
5. **5m**：pine_tables（触发细节 + FVG承压）
6. 每周期截图优先 vision 读图，文字表格作辅助交叉。

## MCP Data Window 编码解读（15m 主执行）
- `MCP Side Code`（-1空/1多/0无）、`MCP Grade Code`（3=A/2=B/1=C/-1=X）
- `MCP Entry Valid Code`（1=可执行）、`MCP RR Ratio`（止损到目标的倍数）
- `MCP NoTrade Reason Code` → 不交易时读它
