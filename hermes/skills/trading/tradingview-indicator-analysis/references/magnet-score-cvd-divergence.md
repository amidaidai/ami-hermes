# Magnet Score & CVD Slope Divergence — 定量信号解读

SVP+ICT+VWAP+EMA+CVD 指标输出多个复合字段，其中 Magnet Score 和 CVD Slope 是关键的定量信号，需与价格行为交叉验证。

## Magnet Score (0-100)

**来源：** `study_values` 的 `Magnet Score 0-100` 字段

**含义：** 磁性吸力评分，衡量价格被吸引到某个关键位的强度。综合了：
- 价格与目标位的距离（ATR加权）
- 多周期结构对齐度
- 订单流（CVD）方向一致性
- ICT锚定（周四/周五高低点、亚/伦/纽KillZone）

**解读规则：**

| 分值 | 强度 | 信号含义 |
|------|------|----------|
| 80-100 | 🔴 极强 | 价格被磁性吸引，大概率触及目标位 |
| 60-79 | 🟠 强 | 有吸引力，但需CVD配合确认 |
| 40-59 | 🟡 中 | 方向参考，不单独做为进场依据 |
| 0-39 | ⚪ 弱 | 无明显磁吸，价格随机波动 |

**实战用法：**
- Magnet 80+ 且方向与高周期一致 → 高概率目标位测试
- Magnet < 40 时即使价格接近关键位也不追求 → 概率不够

**本次BTC案例（2026-06-26）：**
- 4h Magnet = 80（强磁吸指向周五低 `58,030`）
- 1h Magnet = 71（配合B空偏空）
- 15m Magnet = 47（短周期中性，执行层需要确认而非追）

## CVD Slope Divergence

**含义：** CVD（累计成交量差）的大小和方向变化构成的背离信号。

### 标准背离形态

| 模式 | CVD值 | CVD斜率 | 解读 |
|------|-------|---------|------|
| 卖压减速 | 大额负数 | **转正**向上 | 卖盘正在被吸收（absorption）→ 潜在反弹 |
| 买压减速 | 大额正数 | **转负**向下 | 买盘追高意愿消退 → 潜在回调 |
| 卖压加速 | 负数且更负 | 负斜率增大 | 空头持续施压 → 趋势延续 |
| 买压加速 | 正数且更正 | 正斜率增大 | 多头持续涌入 → 趋势延续 |

### CVD Slope 方向独立于 CVD Value

**关键洞察：** CVD Value 反映历史累积，CVD Slope 反映**当前变化速率**。两者方向不一致 = 分歧信号。

### 本次BTC案例

```
4h: CVD Value = -88,958（大额卖压）· CVD Slope = +14,615（斜率转正）
```

- CVD 极端负值（-88,958）→ 过去几天持续的大额卖盘
- CVD Slope 转正（+14,615）→ **当前卖压正在减速**，部分买盘在低位吸收
- 这是典型的 **CVD 底背离**：价格在低位（VAL测试），卖压斜率收窄 → 反弹可能随时触发

### 在分析中的应用

1. **优先检查 CVD Slope 方向** — 比 CVD 绝对值更具前瞻性
2. **Slope 转正但价格新低** → 潜在反转信号，不做激进空头
3. **Slope 转负但价格新高** → 潜在回调信号，不做激进多头
4. **Slope 与 CVD 同向** → 趋势健康，追方向

## 配合使用

最佳实践：
1. 看 Magnet Score 判断目标位是否能到（概率）
2. 看 CVD Slope 判断当前是否在吸收/派发（时机）
3. 两者方向一致 → 高置信交易
4. 两者方向矛盾 → 等确认，不做激进入场
