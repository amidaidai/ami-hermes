# Telegram 分析卡显示格式（棠溪定稿 · 2026-06-18）

棠溪对发到 Telegram 的分析卡视觉要求很高，经过多轮迭代收敛出以下定稿格式。
**出卡推 Telegram 时直接按这个排版，不要每次重新试错。** 这些是用户明确认可
的最终形态，偏离会被立刻要求重排。

## 收敛过程中被否决的做法（不要再犯）

- ❌ 把机器字段（setup_id/model_id/entry_tag/exit_tag…）显示在卡片正文里 — 用户要求**隐藏**，机器字段只写进 `trade_plans.jsonl` / `monitor_levels.json`，不出现在推送文本。
- ❌ 每条信号之间都空一行 — 显得空、难看。同段内①②③**不空行**，只在大段之间留一个空行。
- ❌ 分隔线 `━━━` / `———` — 用户明确说难看，**去掉**，用空行分段即可。
- ❌ 「模拟开单版 · 非真实信号」之类的水印字样 — 用户要求去掉。即便是演示开单场景也不要加水印。
- ❌ 二级中文括号标题（一）（二）（三）夹在结构/操作里 — 用户觉得「层级太多、难看」，**去掉这一层**。结构段直接按周期排，操作段直接进预案。
- ❌ 顶部卡名「棠溪分析卡 · BTCUSDT.P:BINANCE」整行 — 用户要求去掉这一行（改用速读区开头标题代替）。
- ❌ 居中或缩进 — 全部**左对齐顶格**，序号和内容都顶最左。

## 定稿结构（从上到下）

### 1. 开头：标题 + 带序号速读区

开头要有一个加粗标题（一句话点明品种 + 主基调），紧跟带序号的速读区。
速读区每行都有序号①②③…，左对齐顶格。固定 8 项：

```
**BTC 日内分析卡 · 做空为主**

①品种：`BTCUSDT.P:BINANCE`
②时间：`2026-06-18 22:24 CST`
③市场：极端恐慌下的慢熊弱反弹，趋势偏空
④现价：`63,900` · 24h `-2.0%`
⑤状态：B等待
⑥方向：做空为主 · 等反抽失败
⑦置信：`3/5`
⑧数据：A级 · 多源有效
```

- ③市场 = 一句话概括当前盘面，让人一眼定调。
- 价格全部反引号。状态/方向加粗突出。

### 2. 五段正文：大标题用加粗中文数字

一级标题用「**一、 二、 三、 四、 五、**」加粗加黑：

```
**一、环境**
**二、结构**
**三、博弈**
**四、操作**
**五、风控**
```

- 结构段直接按 4h / 1h / 15m / 5m 周期排，**不要**再套（一）（二）子标题。
- 段内信号用①②③，左对齐，相邻不空行。

### 3. 操作段：双预案 + 优先级（铁律）

操作段**必须**给两个预案并标明优先级，缺一不可（用户专门纠正过「预案呢，你要给一个优先级哦」）。格式是「**预案X**：名称 — 优先级标记」一行式，A/B 加粗加黑，冒号后直接跟预案名，详情在下面展开：

```
**预案A**：反抽失败做空 — ⚠ 四源一致 · 优先
①触发：…
②确认：…
③入场 / 止损：…
④止盈：…
⑤仓位：…
⑥失效：…

**预案B**：站回转多 — 备选 · 次优
①触发：…
…
```

- 三源/四源一致的方向标 `⚠ … · 优先`，另一个标 `备选 · 次优`。
- 风控段要写明「当前优先预案A」让权重清晰。

### 4. 结尾：截图 MEDIA

末尾必带 TradingView 截图（BTC 15m full · XAU 5m full，含右侧价格栏+底部CVD）。
发卡前先取最新价 `mcp_binance_get_price` 和最新截图，价格要刷新成当前价再发，不要用旧价。

## 可选增强（用户认可方向，未强制）

出卡那一眼的决策速度可加：
- 操作段上方「当前动作」一行：如 `当前动作：空仓等待 · 盯 63,520 反抽失败`。
- 风控段「盯盘三线」集中：失效线 / 触发线 / 禁追线 各一行。
- 时间行加「有效期：23:30 前 · 过期重跑」。

不要加表格、不要加图表、不要再加层级 — 这些都会让卡变乱（用户反复确认手机看）。

## 工程化建议

把这套格式固化进 `hermes/scripts/auto_card.py` 的输出渲染，机器字段写文件但不进推送文本，
这样 `python hermes/scripts/auto_card.py BTCUSDT --push` 直接出定稿排版，免去每次手调。
