# 社区审计补充（2026-06-22）

## 审计发现

### ✅ 对的
- VWAP为核心参考 — 机构足迹，社区黄金标准
- CVD过滤 — 订单流+价格=高确认组合
- MTF分层 — HTF定方向，LTF找入场
- 量能识别 — 放量=真突破，缩量=试探/假动
- 双路计划(A/B) — 预案思维
- VAL/POC/VAH — 体积轮廓是机构足迹

### ⚠️ 多的（冗余/噪音）
- 独立评分系统 vs SVP指标评级 — 指标已有完整评分，另建会打架
- 1h中间层 — 多数情况下和4h一致或过渡，信息增益有限
- 每次10段卡信息量过大 — 核心决策来自VWAP+HTF+放量3条

### ❌ 缺的
- **复盘闭环** — 分析、计划、等市场走完、回头看判断的准确率
- **入场核对清单** — 一个简单的5项核对表
- **时间过滤(KillZone)** — 亚盘/伦敦/纽约不同策略
- **事件日历** — 重大数据/决议前禁做
- **策略历史表现** — VWAP反抽的胜率？平均R？不知道=盲打

## 建议的简化模板

```
① 方向+关键位+数据 — 30秒看
② 入场条件 — 明确说什么情况下进
③ 核对清单 — 5项检查
④ 预案 — 对了怎么走，错了怎么撤
⑤ 复盘挂钩 — 记住这次判断，下次验证
```

## 入场5项核对清单

每次入场前核对：
1. HTF方向一致？4h/日线方向和本次操作同向
2. 放量确认BOS？突破/跌破时量≥1.8x均量
3. CVD顺向确认？CVD方向和本次操作同向
4. R:R≥1:2？至少一个止盈满足底线
5. 数据等级≥B？Taker/CVD/价格多源≥B级

缺1项 → 降级至半仓/观望
缺2项 → 跳过
