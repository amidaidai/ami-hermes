# DMI 行动格「核对」行解码（从 Pine Script 源码参数反推）

## 背景

棠溪的 SVP v10 主指标（SVP+ICT+VWAP+EMA+CVD）右上角行动格有「核对」行，格式如：

```
HTF✓ EMA✗ CVD- 位置✓ 位移✗ 溢折✓ ADR✗ OI- 扫★HTF 薄量✗
```

这行是 DMI 决策引擎的**降级标记摘要**——每个符号对应一个 DMI 输入参数，✗ 表示该条件**不满足**，引擎据此将信号降级。

## 符号参数对照表

| 核对符号 | 对应源码参数 | 默认值(加密) | 含义 |
|:--:|:--|:--:|:--|
| HTF✓/✗ | `USE_HTF_FILTER` + `HTF_MODE` | true / 自动 | 高周期过滤——价格方向是否与 HTF 一致 |
| EMA✓/✗ | `SHOW_EMA_FILTER` + EMA排列 | 9/21/34/55 | EMA 是否顺向——9>21>34>55=多头 或反=空头 |
| CVD+/CVD-/CVD· | `SHOW_CVD_CONFIRM` + `effCvdWeight` | true / 加密1.5 | CVD 方向是否支持当前方向——+/买 /-/卖 ·=中性 |
| 位置✓/✗ | `A_ONLY_NEAR_KEY_LEVEL` + `effAKeyLevelAtr` | true / 0.75 | 价格是否靠近关键位(VA/VWAP/扫点)——远离时降级 |
| 位移✓/✗ | `REQUIRE_DISPLACEMENT_FOR_A` + `DISP_ATR_MULT` | true / 1.0 | 有否带量位移K确认——连续小K无位移=信号不可信 |
| 溢折✓/✗ | `USE_PD_FILTER` + `PD_LONG_MAX/PD_SHORT_MIN` | true / 70%/30% | 溢价折价过滤——深溢价禁多、深折价禁空 |
| ADR✓/✗ | `ADR_AS_FILTER` + `effAdrExhaustPct` | true / 加密120% | ADR日内幅度——同向剩余空间不足时禁A级追单 |
| OI+/OI-/OI· | `SHOW_OI_AGG`(副指标) | true | OI 变化方向——增+/减-/·持平 |
| 扫★HTF | `REQUIRE_SWEEP_OR_ACCEPT_FOR_A` | true | 已扫HTF流动性——★=已扫且未被回收，是好信号 |
| 薄量✓/✗ | `LIQ_GATE_ENABLE` + `MIN_DAILY_DVOL_M` | true / $10M | 薄量过滤——山寨日成交<$10M降级，假信号少 |

## 如何用「核对」行解读行动格结论

### 示例：4h 行动格分析 GASUSDT

```
结论 | 禁追·高周冲突
核对 | HTF✓ EMA✗ CVD- 位置✓ 位移✗ 溢折✓ ADR✗ OI- 扫★HTF 薄量✗
```

**降级原因（✗ 项）**：
1. **EMA✗** — EMA排列不支持当前方向（15m/5m EMA 9>21>34>55 多头，但 4h/1D 34>55 仍偏空 → 周期冲突）
2. **CVD-** — CVD 为负/不支持买入方向
3. **位移✗** — 巨量上攻(5.67M)后无后续位移确认——虽然涨了但无确认K
4. **ADR✗** — 日内已走幅度超过 ADR 120%，空间耗尽
5. **OI-** — OI 持平，无新资金确认
6. **薄量✗** — GAS 山寨日成交估算<$10M，薄量自动降级

**正确项（✓ 标）**：
- HTF✓ — 高周期(D/4h)方向支持偏空判断
- 位置✓ — 价格在关键位(周一高1.183)阻力附近
- 溢折✓ — 处于溢价区，做空方向正确

**结论**：引擎判「禁追」不是因为方向错了，而是 6 个降级条件都指出**此时入场为高风险**（ADR耗尽+无量确认+薄量+周期冲突）。

## 实战工作流

1. 从 `pine_tables` 拿到 action grid 的「核对」行
2. 拆出每个符号（用空格分隔）
3. 对每个 ✗ 项,回查源码对应参数值
4. 用参数值解释为什么降级（见上表）
5. 将 ✗ 项按严重程度排序：**位移✗+ADR✗+薄量✗** 三个同时出现 = 绝对禁追
6. 将解释写入分析卡「结构解读」段

## 快速判定表（不看源码也能用）

| 同时出现的 ✗ 项 | 含义 | 行动 |
|:--|:--|:--|
| 位移✗+ADR✗ | 无确认+空间耗尽 | 禁追，等回调 |
| 位移✗+薄量✗ | 无量+低价股 | 不碰小市值假突破 |
| EMA✗+CVD- | 周期冲突+卖压 | 偏空观望 |
| 扫★HTF(✓)+位置✓ | 已扫高受阻+关键位 | 做空信号强 |
| EMA✓+CVD+ | 排列顺+买盘 | 如果非禁追，可做多 |
