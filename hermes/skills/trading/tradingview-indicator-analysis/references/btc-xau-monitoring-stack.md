# BTC/XAU 监控与数据源稳定版

## 适用场景
- 用户要求检查或维护 BTCUSDT、XAUUSD 分析模板、监控任务、推送规则、数据源分层。
- 目标是交易辅助驾驶，不是自动交易；优先稳定、可解释、可复盘。

## 当前稳定范围
- 主动监控只保留 `BTCUSDT` 与 `XAUUSD`。
- `行情守望.py`：10s 主监控，负责查价、位信、推送准入、降噪、心跳、单实例锁。
- `信号巡检.py`：1m 守护，负责心跳巡检、异常检查、正常状态卡、定时刷新宏观/模型/体检/审计。

## XAU 数据分层
- 主价：金十Quote现货价。
- 校验：Yahoo `GC=F`、`MGC=F`，作为跨市场验证，不替代现货主价。
- 宏观层：DXY、EURUSD、USDJPY、US10Y、US02Y、TIP、TLT、GC=F、MGC=F、SI=F、GLD、GDX、MOVE。
- 金十单源可降级推送，但必须标注“金十单源/单源金十降级”。
- 金十 + Yahoo 只能标为 `B级 · 跨市场验证`；不要因为期货/现货差异禁做，也不要伪装成 A 级同市场一致。

## BTC 数据分层
- 主源/校验：Binance现货、Binance合约Mark、Binance合约Index、CoinGecko、Yahoo `BTC-USD`。
- BTC/ETH 天然可多源验证，C级单源不应触发交易提醒。

## 推送原则
- 10s 查价不等于 10s 推送。
- 保留严格降噪、分级冷却、同位去重和小时预算。
- `warning` 默认需要强触发、高优先级、位信>=75；XAU 金十单源允许降级推送，BTC 等加密仍要求非 C 级。
- 正常巡检应周期性说明系统在线，避免用户误以为没有监控。

## 阶段重点
- 暂时不要继续堆功能或扩品种。
- 下一阶段重点是真实交易小样本、每笔复盘、模型统计和降权/升权治理。
