# 轻量卡 vs 完整卡双档 (2026-08-28)

用户纠偏：默认分析太重繁琐。用户说「看下XAU/BTC」走轻量，说「分析/深度」才跑完整。
**触发是关键词，不是时间间隔**——完整卡即便刚出过也走完整（沿用既有三档规则）。

## 轻量卡（日常跟踪 · ~5次调用）
| 保留 | 说明 |
|------|------|
| 主指标行动格 table | 最浓缩：位置/结论/方向/结构/磁吸↑/磁吸↓/现位 全在里面 |
| OHLCV summary + 实时 quote | 拿现价，裁决跨周期 close 漂移 |
| 一张主周期全屏截图 | 含价格轴+CVD 窗格 |
| [仅加密] Binance 衍生品 | OI/资金费率/多空比/Taker（加密的方向票，绝不能砍） |

## 可砍
- 其他周期(1D/4h/1h)逐层 lines/labels——只在新关键位或用户问「为啥」时读，
  平时**继承已落地结构结论**，不逐层重拉
- 1D/4h 主指标五层重拉——只保留 1D OHLCV 背景一句
- 宏观（DXY/热榜）顺手扫一眼，不单独开表

## 加密 vs 黄金 轻量卡差异
| 项 | 加密(BTC) | 黄金(XAU) |
|----|----------|-----------|
| 副指标 | 5所+4所OI聚合，**必保留** | 罢工(HALDRO Valid=0)，只读主指标 |
| Binance OI/费率/多空 | 必读 | — |
| CVD | 副指标准确 | 日tick估算·参考级 |

## 落地要点
- 说「看下XAU/BTC」= 轻量；说「分析/深度」= 完整。一次配置，以后不用再解释。
- 建议配关键位监控：到价才拉轻量卡，平时不打扰。
