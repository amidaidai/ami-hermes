# v8.0 叙事分析卡格式（棠溪 · 2026-06-23 锁定）

## 定位

深度分析使用的完整卡格式。区别于快速告警（对话式自然语言），此格式用于替代cron推送、手动分析请求等场景。

## 关键规则

1. **方向来自多因子(5票)，不是DMI表** — DMI显示在①行作参考
2. **X级仍渲染双方案** — 标注⚠X级参考而非×禁做
3. **EMA云必显示** — `9`xxxx`<21`yyyy` · 34`zzzz`<55`wwww``
4. **4h+1h上下文** — 4h EMA方向 + CVD + 1h VWAP偏差
5. **③量价分析写⚠X级=仅供参考** — 用户明确要求DMI不作为决策
6. **⑤综合评分用✅/⚠/❌** — CVD、EMA对齐、关键位接近、恐慌指数四项
7. **MEDIA截图附最后一行**

## 与v4.2压缩卡的区别

| 方面 | v4.2 压缩 | v8.0 叙事 |
|------|-----------|-----------|
| 行数 | 8-10行 | 22-28行 |
| 结构 | ①②③④⑤单行 | 5段 + 子行 |
| 适用 | 快速推送 | 完整分析 |
| 方向 | DMI等级直接映射 | 多因子投票 |
| EMA | 单行简要 | 多行详细(含数值) |
| ① | VWAP+EMA+CVD合并一行 | 结构分析+EMA云+4h/1h上下文 |
