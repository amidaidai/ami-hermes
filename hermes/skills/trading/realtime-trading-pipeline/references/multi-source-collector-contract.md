# 多源采集器与聚合契约

适用：把多个外部源（多所行情/衍生品/情绪/链上…）汇成一个缓存、再供卡面与看门狗消费的采集器。每条都是踩过坑的规则——违反其中任一条，症状通常是「卡面某行莫名消失」「cron incident 刷屏」或「数字静默偏低」，而不是明确报错。

## 1. 每源独立状态，禁止把单源失败折叠成全局状态

- 每个源（每个品种、每家交易所）在缓存里写**自己的** `status`；顶层状态只做聚合展示：任一源 live → 顶层 live 并记 `live_sources`，全部失败才降级。
- 为什么：消费方粒度不同——卡面只需要「我要的那个品种」OK，看门狗只看整体在不在跑。把单源失败写成顶层 `stale_cache`，会让**另一个健康品种的卡面行整行消失**，而它的数据其实是新鲜的。
- 降级仍要可见：失败源保留上一轮数据并标 `stale: true`，卡面追加「沿用上轮」；不静默、不伪造。

## 2. 跨所聚合先归一单位，再相加

- 各交易所的「数量」口径不同：合约张数（× 合约面值 × 价格）、币数（× 价格）、USD 名义。先统一折成同一种量再进统计函数。
- 合约面值别写死：从交易所 instruments 端点取（如 `ctVal`），取不到再用内置兜底表。
- 同一统计函数只接受一种口径（如「已是 USD，不再乘面值」），避免二重换算。

## 3. 采样源不得并入全量源的规模合计

- 有的流是**快照采样**（如“每秒最多 1 条”），有的是一段时间的**全量明细**。把采样源与全量源相加 = 系统性低估，比不给数字更糟。
- 处理：规模口径只认全量源并在标签里写清源名；采样源降级为**存在性附注**（“X所快照 N 笔/1h”）。
- 「相对刻度/加权强度」类字段（热力图强度等）不是金额：卡面必须标口径，不得当 USD 引用；写测试断言字段名里没有 `usd`/`notional`，防止后人改回。

## 4. 覆盖不足必须标真实窗口

- 单页有条数上限（常见 100 笔）→ 必须翻页；覆盖窗靠**增量合并 + 滚动窗口**累积。采集断档会丢事件，缓存里要如实记 `coverage_from`。
- 标签按真实覆盖动态生成：不足 95% 目标窗口时写「窗4.0h」「窗毎30m」，不把 4 小时的数据标成「近24h」。
- 这一条要落成测试（断言覆盖不足时标签不含目标窗口字样），否则改代码时会被悄悄回退。

## 5. 降级 ≠ 故障：退出码只表达「还能不能供数」

- no_agent cron 脚本：只要**任一源仍能供数**（live 或带「沿用上轮」的缓存）就 `exit 0`，降级明细写进 stdout 供排查；只有全部源不可用才 `exit 1`。
- 为什么：把降级写成失败 → cron 记 incident → 几次之后就是报警疲劳，真事故被噪声淹掉。
- 同理看门狗：被守护进程「活着但安静」属正常，exit 0；只有重启失败才非零。

## 6. 瞬态网络错误先重试，再判失败

- SSL/连接抖动（`UNEXPECTED_EOF_WHILE_READING` 一类）是偶发，单次失败不足以判定数据源故障。给 2 次重试（递增间隔）再记失败；重试成功的轮次按 live 处理。
- 重试次数要写进理由注释，否则后人会以为多余而删掉。

## 7. 缓存时间戳要用看门狗认的键

- 数据新鲜度看门狗只认固定键名（`updated_epoch` / `updated_at` / `ts` / `time` / `updated`）；自建缓存只写 `fetched_at` 会被判成「无显式时间戳」并误报。两个都写，成本为零。
- 新缓存要注册进看门狗清单（阈值 = 刷新节奏 × 4），否则「采集器停摆」没有任何信号。

## 8. 消费方各拿各的粒度

- 卡面/报告读**单源**状态，看门狗读**顶层**状态；两者都不得依赖对方需要的粒度。
- 状态词表统一：live / cache / stale_cache / unavailable / quota_cooldown；禁止把旧缓存写成 live。

## 9. 上线最后一公里：先自检，再收工

多源管线的问题只在真实 cron 条件下才暴露。交付前跑一遍：
1. `skill_view`/`read` 看两个 job 的 runs 与 **cron incidents**（特别是自己新增的 job id），别只看 cron list 的 active 字样。
2. 逐源读缓存里的 `status` 与 `live_sources`，确认不是「一个源失败拉低全部」。
3. 手动跑一次刷新脚本并查退出码（`echo $?`），再等一次真实 cron tick 确认它不被记成 failed。
4. 进程看门狗：列实例数（应 == 1）与心跳年龄。
5. 最后跑全量回归；新增规则要有对应测试用例，否则下次重构会回退。
