# 社区基准 · 交易信号格式（2026-06 多源确认）

## X/Twitter 社区共识（Grok 4.20 聚合）

**信号卡最佳格式：**
- 方向 + Entry区间（非单价格）
- 2个目标（TP1 + TP2）
- R:R 必含（最重要指标）
- 有效期（防信号过期）
- 最多8-10行

**最简快报格式：**
```
🚨 BTC Long
Entry: 91,400
TP1: 93,200 | TP2: 95,800
SL: 89,800
RR 1:2.8 | 4H
```

## Telegram 信号频道基准

**主流频道格式：**
- 4-6行（移动端不折行）
- 入场区间 + SL + TP + RR
- 🚨 仅首行用情头

**示例：**
```
🚨 BTC LONG — 15min
Entry: 91,200-91,600
SL: 90,800
TP: 93,200 / 95,800
RR: 1:3.1
```

## TradingView Alert 格式

- 3-5行推送
- 品种·价格·信号·TF
- 不展开分析（分析在图表上）

## 机构 Dashboard

- 8-12行（桌面端）
- 入场区间 + SL + TP1/TP2 + 仓位 + 失效
- 每行1个信息维度

## 社区关键发现

1. **R:R 是最高频被提及的指标** — 无论平台，RR必含
2. **入场区间 > 入场单点** — 更实际，交易者自己选
3. **2目标制是标准** — 超过2个目标 = 噪音
4. **有效期 = 防止过时信号** — 社区共识刚需
5. **手机优先** — Telegram移动端约38字符/行
6. **分析 ≠ 信号** — 分析卡可以长，信号/警报必须短
