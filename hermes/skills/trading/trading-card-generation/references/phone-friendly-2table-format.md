# 手机端精简分析卡格式

棠溪系统有两个独立卡版本，各有其渲染器和推送场景。用户 2026-07-08 确认以下两种版式替代旧密集 7 表卡。

---

## 一、完整版（3 表 + emoji 叙述）

**渲染器**：`render_v96_card()`（`scripts/render_v96.py`）——改造后目标格式  
**推送时机**：`auto_card.py --push`（手动调全分析）  
**通道**：`telegram_reliable.send_telegram_reliable(parse_mode='RichMarkdown')` → `sendRichMessage` → 真表格

## 二、快速版（1 表 + 3 行）

**渲染器**：`_render_push()`（`scripts/render_tv_card.py`）——改造后目标格式  
**推送时机**：cron 自动推（BTC 关键位同步、行情守望等），每日多次  
**通道**：cron 脚本自行调用 `telegram_reliable.send_telegram_reliable(parse_mode='RichMarkdown')`，设 `deliver: local` 阻止纯文本投递

```
📊 BTC · 2026年7月8日09：11

🔵 等 · VWAP下(63,163) · 63,213–63,746 窄震

| 方案 | 触发价 | 操作 |
|:---|:---:|:---|
| 🟢A 回踩多 | 63,300 | 多 损62,630 标63,800→64,298 |
| 🔴B 破位空 | 62,638 | 空 损63,150 标61,976→61,297 |
| ⚠️X 禁追 | 63,600 | 夹击 + 去杠杆 |

恐贪20 · 主动买卖转卖 · 多空拥挤1.60 · 净流出1.56亿🟢
```

→ 1 个表 + 3 行小字，~10 行，手机半屏。扫一眼就知道「做什么 + 在哪做」。

## 三、规则汇总

| 要素 | 完整版 | 快速版 |
|:----|:-----|:------|
| 表数量 | 3 张 | 1 张 |
| 行数 | ~35-40 | ~7-10 |
| 首行 | 品种 · 交易所 · 状态 · 中文时间 | 品种 · 中文时间 |
| 【在哪】 | ✅ 一句话描述当前位置 | 融合到首行 |
| 【怎么做】 | ✅ emoji + 直接操作 | 🔵/🟢/🔴 前置方向 |
| ① 周期体温 | 5 周期 emoji 单行 + 箭头总结 | — |
| ② 关键位 | **1 张结构表** ≤6 行 | 融合在操作表里 |
| ③ 多源一句话 | emoji 锚点 + 顿号串联 | 一行小字 |
| ④ 执行 | **1 张执行表** 3 行 | **1 张操作表** 3 行 |
| 【裁决】 | 一句话结论 + 评分 | — |
| 发送触发 | 手动 `--push` | cron 定时 |
| 当前渲染器 | `render_v96_card()` | `_render_push()` |

## 四、视觉原则

- **emoji 前缀**作为视觉分类锚点：🟢多/涨/有利 · 🔴空/跌/不利 · 🔵等/观望 · ⚖中性/夹击 · ⚠️警告/禁做
- **表只给必要数量**：完整版 3 张（周期/关键位/执行），快速版 1 张（操作）
- **多源验证合为一行**：顿号串联，emoji 前置
- **周期定位合为一行**（完整版）：5 周期 emoji 单行，不用 5 行表
- 完整版手机一屏半（~35 行），快速版手机半屏（~10 行）
- 价格用反引号包裹：\`63,163\`
