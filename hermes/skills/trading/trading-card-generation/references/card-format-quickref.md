# 卡片格式速查

## 极简卡模板（价在关键位±0.4%内时输出）

```
◷ MM-DD HH:MM · SYMBOL · 平台 · 模型 · 方向
③ `价格` · 高 `高` · 低 `低`
关键位 价格 ← 价踩在这 · X.X% / ← 距XXX点
CVD 方向 · Taker 方向 X.XX · Funding X.XX%
→ 破关键位：空 止损`止` 止盈`盈` R:R 1:X.X
→ 守关键位：多 止损`止` 止盈`盈` R:R 1:X.X
风控：⚠周末 X.XXU上限 · 杠杆 · 🛡 · 社区F&G XX
—— 决策：你来选方向——
```

## 完整卡操作段 AB模板

```
—— 预案A · 方向描述（优先·等触发）——
**① 方向：空头/多头**
**② 入场：等待触发 — 价格 `入场价` 附近**
   触发：触发条件描述
   确认：15m收线 + 确认条件
③ 风控：平台 杠杆
   规则：资产规则
   **止损：`止损价` — 止损理由**
   **止盈：`止盈价` — 止盈理由**（R:R 1:X.X）
**④ 仓位：数量 单位**
   **风险：`X.XXU` · X%宪法上限**
**⑤ 失效：失效条件**
⑥ 复查：15m×3根，不顺就撤
⑦ 轨迹：等确认 → 入场 → 移损/止盈

—— 预案B · 反向描述（备选·等反向确认）——
**① 方向：多头/空头**（与A相反）
**② 入场：等待触发 — 价格 `入场价` 附近**
   触发：反向触发条件
   确认：反向收线 + 确认条件
③ 风控：平台 杠杆
   规则：资产规则
   **止损：`止损价` — 止损理由**
   **止盈：`止盈价` — 止盈理由**（R:R 1:X.X）
**④ 仓位：数量 单位**（与A相同）
   **风险：`X.XXU`**
**⑤ 失效：反向失效条件**
⑥ 复查：15m×3根，不顺就撤
⑦ 轨迹：反向确认 → 入场 → 移损/止盈
```

## R:R 标注规则

- R:R ≥ 2.0: 正常显示 `R:R 1:2.5`
- R:R < 2.0: 标注 `R:R 1:1.8 ⚠R:R不足`
- 绝不伪造数字让R:R达标

## 文件输出

- 极简卡: `data/auto_card_{symbol}.md`
- 完整卡: `data/auto_card_{symbol}_full.md`
- 两者同时生成，`_full` 始终是完整78行卡
