## Audit Dimensions (beyond the standard 11)

### D1: Skill Matrix Audit
- List ALL installed skills (235 total)
- Filter by trading-relevant categories: trading (12), research (5), community-stars (30+)
- Check which skills are actively used by cron/pipeline
- Identify unused skills with high potential: polymarket, multi-symbol-screener, agentless-monitoring, finance-sentiment
- Output: utilization percentage + top 5 recommended integrations

### D2: MCP Capability Audit
- List ALL MCP servers (8 total in this system)
- For each, check: which tools are called by pipeline scripts? Which are never used?
- Key findings in this session: FinanceKit (0%), Jin10 calendar (0%), Stock API (0%), Hermes Studio LAN (0%)
- Output: MCP utilization heatmap + recommended integrations

### D3: Strategy Depth Audit
- Load TV chart state → check which indicators are active
- Compare against community-standard indicators: FVG detector, Order Block, Silver Bullet timer, DMI/ADX
- Check Pine Script for missing features: session labels, sweep detection, displacement detection
- Check if engine models match active indicators (data shows CVD but no CVD model in engine = gap)

### D4: Community Benchmarking
Sources in priority order:
1. X/Twitter ICT/SMC practitioners (2025-2026 consensus)
2. Reddit r/algotrading (proven patterns)
3. Freqtrade documentation (architecture patterns)
4. TradingView Pine Script community (indicator patterns)
5. LLM-TradeBot (multi-agent architecture reference)
6. Hermes Agent community (deployment patterns)

Consensus extraction method:
- Parallel search across all sources
- Extract recurring patterns (e.g., "three-layer confirmation", "KillZone session filter")
- Build checklist: 🟢 aligned / 🟡 partial / 🔴 missing
- Prioritize: P1 (strategy gap affecting win rate) / P2 (enhancement)

### D5: Implementation Priority
When user says "全方位优化" = implement ALL P0+P1+P2, not just P0.
Parallel implementation: create modules → wire into engine → update pipeline → verify.
