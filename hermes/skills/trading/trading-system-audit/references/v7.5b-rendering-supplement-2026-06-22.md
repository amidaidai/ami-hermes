# v7.5b Rendering Supplement (2026-06-22)

## Critical Session Lessons

### 1. Static Audit Blindness → Runtime Crash

**Scenario**: Full static audit (compile, lint, pytest 101/101) passed. System stopped alerting.

**Root Cause**: `auto_card.py` had two undefined names:
- `_near_key_level()` — function never existed
- `qty_unit` — variable undefined (should be `_qty_unit(symbol)`)

**Chain**: Monitor detects expired levels → calls auto_card to refresh → auto_card NameError crash → levels never refreshed → all alerts die silently.

**Prevention**: Static scan MUST be followed by live pipeline run:
```
python hermes/scripts/auto_card.py BTCUSDT
python hermes/scripts/auto_card.py XAUUSD
```

### 2. "你来选方向" Removal (User Directive)

棠溪 explicitly requested removal of all "—— 你来选方向 ——" lines from cards and alerts.

**Locations patched**:
- `hermes/scripts/auto_card.py` ×2 (full card + compact card)
- `scripts/行情守望.py` ×1 (render_message)

Cards/alert end naturally without appended decision prompt.

### 3. display_name vs name Priority

`monitor_levels.json` stores two name fields per level:
- `name`: Internal ID (`R1_reclaim_accept`)
- `display_name`: Human-readable Chinese (`阻1·近端收复接受位`)

Rendering must always prioritize `display_name`. Fixed in both `render_message()` (行情守望.py) and `_find_nearest_key_level()` (auto_card.py).

### 4. Taker Direction Chinese-ification

Taker data uses English values internally: `buy`/`sell`/`neutral`
Rendering now translates: buy→买 · sell→卖 · neutral→平
