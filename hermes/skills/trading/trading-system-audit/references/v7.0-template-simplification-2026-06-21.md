# v7.0 模板精简 — 社区驱动·信息密度翻倍

日期: 2026-06-21
触发: 用户"模板和警报精简一下，太长了。全面联网社区看我们的要怎么做比较好。"

## 社区信号格式基准（多源确认）

| 来源 | 格式 | 行数 | 必含要素 |
|------|------|------|---------|
| Telegram信号频道 | 快报 | 4-6行 | 方向·入场·SL·TP1·TP2·RR |
| TradingView Alert | 推送 | 3-5行 | 品种·价格·信号·TF |
| X/Twitter社区 | 标准 | 6-8行 | 入场区间·2目标·有效期·RR |
| 机构Dashboard | 桌面 | 8-12行 | 入场区间·SL·TP·仓位·失效 |

## 核心设计决策

1. **三合一指标行**: VWAP/EMA/CVD/Taker/Funding/FG 压缩为单行（③行）
2. **多周期合并**: 4h·1h·15m·5m 连续一行
3. **预案B精简为1行**: 入场·止损·止盈·RR — 对称不再逐段展开
4. **风控十行合并为一行闸门**: 数据·风控·执行·心态 四个维度
5. **五段标题删除**: "一、环境"等章标题→序列直接编号
6. **重复字段消除**: 数据线不重复（原⑥⑩重复）、风控规则不重复（Protections自动运行）
