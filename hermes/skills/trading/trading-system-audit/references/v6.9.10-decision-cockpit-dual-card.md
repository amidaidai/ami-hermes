## 极简决策卡设计铁律

### 格式（8-9行固定）
```
◷ 时间 · 品种 · 模型 · 方向

关键位名 价格 ← 距离标注
CVD方向 · Taker方向 · Funding
→ 破位：方向 止损 止盈 R:R
→ 守位：方向 止损 止盈 R:R
风控：周末标签 金额上限 · 杠杆 · 保护 · 社区共识
—— 决策：你来选方向——
```

### 关键实现函数
- `_compact_card()` — 位于 `hermes/scripts/auto_card.py` 约L2005
- `_find_nearest_key_level()` — 位于同文件约L2055
- 触发逻辑：`render_card_locked()` 中检查 `_near_key_level()` + status B等待/X禁做
- force_full 参数：设为 True 时跳过极简逻辑，始终输出完整卡

### R:R 计算
```python
rr = abs(tp - price) / abs(stop - price)
# 每条预案独立计算
# 破位方向：tp 用 0.97×level, stop 用 1.005×level（空头偏）
# 守位方向：tp 用 1.03×level, stop 用 0.995×level（空头偏）
```

## 双卡输出模式

### 文件分离
- `auto_card_{symbol}.md` → 极简卡（锚定时）或完整卡（未锚定时）
- `auto_card_{symbol}_full.md` → 始终完整卡（force_full=True）

### auto_card() 调用顺序
```python
# 1. 先渲染完整卡（force_full=True）
full_card = render_card_locked(..., force_full=True)
full_card = sanitize_card_format(full_card)

# 2. 再渲染决策卡（force_full=False，自动判断是否极简）
card = render_card_locked(..., force_full=False)
card = sanitize_card_format(card)

# 3. 双写文件
full_path.write_text(full_card)
compact_path.write_text(card)

# 4. 判断是否极简
is_compact = len(card.strip().split('\n')) <= 10
```

## 决策驾驶舱哲学嵌入

- **系统角色**：整理信息 + 呈现两种走法 → 用户做判断
- **B等待不是卡住**：当价格锚定时，B等待 = 两种方向待突破
- **全面性是基础**：完整卡始终保存，供深度研究
- **速度是关键**：极简卡8行30秒读完，做决策不拖沓
- **你控制开单**：系统永远不自动执行，只提供方案
