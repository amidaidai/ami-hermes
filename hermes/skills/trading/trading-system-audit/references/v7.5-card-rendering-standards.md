# v7.5 卡片渲染标准（2026-06-21 实战审计固化）

## 核心原则

**用户看到的必须是中文，内部ID绝不泄漏到渲染层。**

## 渲染铁律（5条）

### 1. display_name 优先 —— 永不用 `name` 渲染

`monitor_levels.json` 每层有两个字段：
- `name`: 内部标识（如 `R1_reclaim_accept`）→ 给程序用
- `display_name`: 人读中文（如 `阻1·近端收复接受位`）→ 给用户看

**所有渲染路径**（行情守望.py·auto_card.py·TV桥·话题路由）必须：
```python
display = item.get("display_name") or item.get("name", "?")
#            ^^^^^^^^^^^^^^^^^^^^ 优先           ^^^^^^^^ 兜底
```

### 2. 禁止双层前缀

当数据源已含前缀时，渲染器不得再加前缀：
```python
# ❌ 错误：model_dir_text="引擎判多·位信一致✓" → 前缀"引擎" → "引擎引擎判多"
ind_parts.append(f"引擎{model_dir_text}")

# ✅ 正确：直接使用
ind_parts.append(model_dir_text)
```

### 3. Taker方向中文化

Binance API返回 `buy`/`sell`，渲染必须转中文：
```python
dir_map = {"buy": "买", "sell": "卖", "neutral": "平"}
taker_text = f"{dir_map[tk['dir']]} {tk['ratio']:.2f}·{tk.get('q','B')}级"
```

### 4. N/A → 中文兜底

所有工具函数的默认返回值必须中文：
- `_sr_level`: `N/A` → `待确认`
- `_chase_ok`: `N/A` → `—`
- `_exec_line`: `N/A` → `待确认`
- `_find_nearest_key_level`: `VAH/VAL/POC/VWAP` → `价值上沿/价值下沿/控制点/量价均值`

### 5. 禁止硬编码分析

`_tf_verdict` 等函数不得返回固定文本（假分析）。必须基于实际数据动态生成：
```python
# ❌ 错误：永远输出同一句话
def _tf_verdict(tf, k, merged):
    if tf == "4h": return "4h下降结构完整，空头压制明显但延伸已远"

# ✅ 正确：基于EMA21动态判语
def _tf_verdict(tf, k, merged):
    if ema21 and close > ema21:
        parts.append(f"{tf}价上EMA21·偏多")
```

## 审计检查点

渲染审计时必须逐行检查：
1. `grep -rn '\.get("name")' --include="*.py" .` → 零命中（渲染路径）
2. `grep -rn 'N/A' --include="*.py" .` → 零命中（工具函数返回值）
3. 检查 `render_message()` 内无额外前缀添加
4. 检查 `_find_nearest_key_level()` 内级别名为中文
5. 检查 `taker_text` 构建路径有中文方向映射
