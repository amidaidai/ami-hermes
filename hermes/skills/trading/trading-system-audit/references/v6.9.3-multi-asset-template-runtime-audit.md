# v6.9.3 Multi-Asset Template + Runtime Audit Pattern

Use this reference when the user asks for a full trading-system audit that includes strategy templates, monitor templates, scripts, alerts, cron logic, auto-updated levels, and community-quality optimization.

## Trigger

- 用户说：全面审计我的系统、分析策略模板监控策略模板、脚本警报、任务逻辑、自动更新位置有没有作用。
- 用户同时要求：模板正文高质量精简，但操作段详细；覆盖贵金属、外汇、加密货币、股票、期权。

## Required workflow

1. **先验运行态，不先改文档**
   - `hermes cron list && hermes cron status`
   - `git status --short && git branch --show-current`
   - `data/monitor_heartbeat.json`
   - `data/monitor_state.json`
   - `data/monitor.log` and `data/watchdog.log`
   - `data/monitor_levels.json`
   - Auto-card smoke for BTC/XAU before edits.

2. **双渲染链路都审**
   - 权威分析卡：`references/master-template-v68.md` + `hermes/scripts/auto_card.py`
   - 实时监控卡：`scripts/行情守望.py::render_message()`
   - Pitfall: 改 `auto_card.py` 不等于改实时监控警报格式。

3. **模板优化原则**
   - 环境/结构/博弈/风控：高质量精简，保留关键判断，不堆长段落。
   - 操作段：必须详细，覆盖 A/B 计划、确认条件、入场、止损、目标、仓位、复查、失效条件。
   - 禁止：表格、引用块、竖线、机器字段泄漏、重复铁律堆叠。
   - 保留社区铁律：Liquidity Sweep 是灵魂，CVD 背离/吸收必须锚定结构，Displacement 才能确认，XAU 看 Kill Zone，Confluence 8/8 比孤立信号重要。

4. **多资产操作段映射**
   - BTC/ETH：Binance 100x，单位币种，关注 funding/LS/OI/Taker/CVD。
   - 其他加密：Binance 20x，降低杠杆和仓位。
   - 黄金：Exness 1000x，单位 oz，止损用美元距离，关注 London/NY sweep + spot source consensus。
   - 外汇：按点值/点差/交易时段，优先 macro session + liquidity sweep。
   - 股票：按股数/缺口/财报事件/成交量确认，禁用期货式杠杆话术。
   - 期权：必须写方向、期限、strike、最大亏损、IV/Greeks、事件风险；不能只写现货止损。

5. **自动更新关键位是否有效的实测标准**
   - 不能只看脚本存在。必须检查 `monitor_levels.json` 是否有新时间戳、symbol 是否 enabled、每个 symbol 是否有 active levels。
   - 交叉读 `scripts/信号巡检.py` / `scripts/智能更新结构.py` / `scripts/system_data_bridge.py` 的写入路径。
   - 若 heartbeat stopped 但 levels 有旧数据，判为运行态问题，不判“自动更新有效”。

6. **watchdog / monitor 恢复模式**
   - 旧冷却可能卡死：先清 `data/watchdog_guard.json` 的 restart_times，再启动 watchdog。
   - 判断历史错误与当前错误：旧日志中的 XAU Binance 400 或 timeout 不等于当前仍发生；必须看新进程启动后日志。
   - 验证 XAU 价格守卫：直调 `get_price('XAUUSD')` 应走专用源/返回 None，绝不能请求 Binance ticker。

7. **验证 bundle**
   - `python -m py_compile` 覆盖改动脚本。
   - `python hermes/scripts/auto_card.py BTCUSDT` and `XAUUSD`。
   - `grep -E "setup_id|model_id|entry_tag|exit_tag|critical|warning|info" data/auto_card_*.md` should be empty or explicitly filtered for metadata-only files.
   - `pytest` full when available.
   - `python scripts/安全审计.py` and `python scripts/系统体检.py`.
   - Heartbeat age fresh, watchdog running, cron gateway active.
   - `git status --short`; if user asked for locking or full optimization, commit + push.

## Community research routing

Use web/community research to validate direction before large template changes:
- Freqtrade / QuantConnect / NautilusTrader for systematic strategy discipline.
- ICT/SMC + CVD/Volume Profile sources for structure-anchored execution.
- Options references for Greeks/IV/max-loss language.
- For this user, DDGS/web_extract/X search are preferred; do not keep retrying a depleted Firecrawl path.

## Report pattern

Keep final report concise and evidence-backed:
- What changed
- What was found
- What real commands returned
- Remaining non-blocking issues
- Commit hash if locked

Avoid long narrative. For 棠溪 use vertical Chinese style with numbered sections, `—` dashes, backticked prices/IDs, and no tables.
