## 格式铁律

- 无 `━━━` 分隔线（用户明确删除）
- 无 `—— 你来选方向 ——`（已从3处删除）
- 预案AB完全对称：方向/入场/止损/止盈 四行一致

- 五段结构：①今日结构 ②关键位 ③量价分析+TV DMI ④交易方案 ⑤综合评分

## 渲染引擎

`scripts/render_v8.py` — `render_v8_card()` 函数
`hermes/scripts/auto_card.py` — 调用 render_v8_card，保留极简卡路径

## 关键技术点

- K线数据从 `klines` dict 读取（4h/1h/15m的open/close/high/low）
- 关键位优先用 `monitor_levels.levels[].display_name`，回退到 K线 VAH/VAL/高低
- TV DMI 从 `tv_dmi_rows` dict 注入（需 auto_card 先解析TV数据）
- 截图通过 `tv_screenshot.py` 异步采集，推送时附 MEDIA: 路径
- 话题路由通过 `topic_router.get_target(symbol)` → BTC 386 / XAU 385

## 崩溃→静默管线（P0经验）

