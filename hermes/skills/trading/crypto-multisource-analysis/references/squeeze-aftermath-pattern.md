# Short Squeeze Aftermath Pattern（轧空冲顶裁决路径）

> 2026-06-30 实战产出，基于 GASUSDT $1.089→$1.271 轧空案例
> 用于「主指标说禁追 / 副指标说偏多共振 / 两路不同说同一结论」的裁决场景

## 模式特征

| 阶段 | 信号 | 指标读数 |
|:--|:--|:--|
| 积累期 | Funding 持续深度负（< -0.10%） | 空头拥挤，卖空成本高 |
| 爆发期 | 单根 4h 放量 10x+ 均量，价格穿透所有近端阻力 | 主指标：放量冲顶，ADR 耗尽 |
| 爆发期 | OI 增 + 价格飙升 | 主指标：结构偏空·禁追 |
| 爆发期 | Taker 买 > 卖 | 副指标：🟢偏多 N/4共振 |
| 回落期 | Taker 转卖偏（0.6-0.9），价格回撤至 VWAP | 副指标：买盘仍在但缩量⚠ |
| 落地期 | 两路指标均收敛为「等待」 | 最终裁决：B等待 |

## 主副指标在轧空后的典型信号对

| 周期 | 主指标（SVP行动格） | 副指标（Volume Aggregated） | 含义 |
|:--:|:--|:--|:--|
| 4h | 禁追·高周冲突 | 🟢偏多4/4 · 轧空冲顶·警惕反转 | 结构禁追但资金流真实→等回踩 |
| 1h | SVP 可能不渲染 | 涨但缩量·动能弱 | 动能衰减中 |
| 15m | 等多回踩 | 🟢偏多3/4 · 新多进场✅ | 回落至 VWAP 可关注 |
| 5m | 等多回踩 | 🟡偏多·缩量⚠ | 短线过热+缩量=等放量确认 |

## 裁决逻辑

**核心矛盾**：主指标说「结构上不能追」——副指标说「资金流是真实的」。

然而两者并非对立 —— 它们指向**不同时间尺度的同一结论**：

| 指标 | 理由 | 结论 |
|:--|:--|:--:|
| 主指标 | ADR耗尽+深溢价+扫高受阻→结构不支持直接追 | 等多回踩 |
| 副指标 | OI真实增加+买盘真实→但缩量+轧空冲顶→动量衰竭 | 等放量再做 |

**裁决标准**：两路都说了「等」，那就等。不因一方看多就追，也不因一方看空就空。

## 追问清单（回到这个场景时必查）

- [ ] Funding 正在从负转正吗？→ 空头回补结束，驱动因素消退
- [ ] OI 在价格回落时如何？→ OI 下降 = 多空都在平仓（衰竭）；OI 稳 = 等待下一波
- [ ] Taker 是否持续卖偏？→ 获利了结正常；Taker>1.2 卖偏+放量=结构反转
- [ ] 15m VWAP 守住了吗？→ 守住=健康回踩；跌破=冲顶结束
- [ ] 恐惧贪婪指数如何？→ 极度恐惧(<20)时轧空通常有延续性

## Phase 2 — 轧空后衰减（Post-Squeeze Decay）

> 2026-06-30 追加，基于 GASUSDT $1.271 冲顶回落至 $1.167 后的二次分析

当轧空爆发期结束、价格进入冷却阶段，出现第二组信号特征：

### 衰减期信号对比（与爆发期的关键差异）

| 维度 | 爆发期 | 衰减期（新） |
|:--|:--|:--|
| 价格vsVAH | 刚穿透VAH，向上磁吸 | 回落到VAH下方，测试VAH反向 |
| 15m价格vsVWAP | 远高于VWAP（溢价） | 跌破VWAP（折价） |
| 15m EMA9vsEMA21 | 9>21 多头 | 9<21 微叉或接近交叉 |
| 副指标持仓行 | 新多进场（真） | 多头平仓（去杠杆） |
| 副指标量能 | 放量·爆仓 | 缩量·合90%+⚠ |
| Taker | 买>卖持续 | 卖偏或混和，买不能持续 |
| 主力结论 | 等回踩（不追） | 等空反抽（准备空） |
| 副结论 | 轧空冲顶·警惕反转 | 去杠杆·别追空等反弹 ⚠ |

### 衰减期的关键陷阱

**不要因为4h副指标说"可做"就追多。** 衰减期最大的陷阱是结构-TF(4h)的副指标仍显示🟢偏多，但执行-TF(15m)的副指标已转为🔴偏空或强烈警告。

| 指标 | 4h（结构TF） | 15m（执行TF） | 裁决 |
|:--|:--|:--|:--:|
| 主指标结论 | 禁追·高周冲突 | 等空 反抽 ⚠冲突 | ✅ 一致 |
| 副指标信号 | 🟢偏多·4/4共振 | 🟡偏多·2/4共振（弱） | ⚠ 降级 |
| 副指标操作 | A多/扫★HTF = 可做 | 主指标降级/放弃 | ❌ **执行TF覆盖** |
| 副指标流向 | 买盘占优 | 卖盘占优 | ❌ 背驰 |
| 副指标量能 | 放量·合83%⚠ | 缩量·合86%⚠ | ❌ 量不配 |
| 最终裁决 | — | — | **等空反抽，不做多** |

### 衰减期核验清单（Phase 2）

- [ ] 15m价格是否在VWAP下方？→ 是=弱，否=回踩健康
- [ ] 15m副指标流向是买还是卖？→ 卖=持续衰减
- [ ] 15m副指标操作行是否包含"降级/放弃/别追"？→ 是=执行TF否决
- [ ] Taker量卖/买比最近3period出现<0.9？→ 是=卖压
- [ ] 多空比>2.0且价格跌？→ 极糟（多头拥挤+价格下行=踩踏风险）
- [ ] 4h VAH是否从支撑变阻力？→ 价格摸VAH后回落到下方=阻力确认

### 实战示例（GASUSDT 2026-06-30）

价格从轧空高点$1.271回落至$1.167附近（实时）：
- 4h显示🟢偏多+新多进场+空头爆仓 → 但价格已触及VAH(1.182)后回撤
- 15m跌破VWAP(1.176) → EMA9(1.171)接近EMA21(1.156)
- 15m副指标流向卖盘占优、量能缩量、结论"涨势存疑·CVD不配"
- 多空比2.2x（极度偏多反指）+ 费率-0.039%（空头仍付钱）
- 深度墙买卖均衡（比1.06），F&G 15极度恐惧

**裁决**：等空反抽。4h的看多信号被执行-TF(15m)的走弱信号否决。等反抽到1.175-1.180受阻做空，目标1.142→1.089。

### 实战示例续（GASUSDT 2026-06-30 30分钟后衰减加速）

30分钟后价格从$1.167加速跌至$1.113（-4.6%），副指标Composite从+31暴跌至-11：

| 指标 | 衰减前(T+0) | 衰减后(T+30min) | 变化 |
|:---|:---:|:---:|:---:|
| 价格 | 1.167 | 1.113 | −4.6% |
| 15m副信号 | 🟢偏多3/4 | 🔴偏空1/4 | 翻转 🔴 |
| 15m Composite | +31 | −11 | 翻转 |
| 副结论 | 轧空冲顶 | 去杠杆·或超跌反弹 | 阶段演进 |
| 持仓 | ▲新多进场 | ▼多头平仓 | 翻转 |
| 流向 | ▲买盘占优 | ▼卖盘占优 | 翻转 |
| 资金费率 | −0.336% | −0.350% | 更负 |
| OI | ~1.87M | ~1.85M | ↓续降 |
| 多空比 | 2.26 | 2.23 | 几乎未变(警惕) |

**教训**：轧空衰减不是线性的——当15m副指标从🟢翻🔴、Composite从正翻负时，衰减进入加速阶段。多空比在高位(>2.0)不随价格下跌而改善，是极度危险的信号（多头死扛→最终踩踏）。
