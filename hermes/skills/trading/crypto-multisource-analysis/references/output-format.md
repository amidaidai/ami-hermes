# Cron报告输出格式标准 v2.1 (2026-06-29)

## 铁律：表格优先

所有 no_agent cron 脚本的输出**必须使用 Markdown 表格**，不允许单行文本作为主要输出格式。

## 通用风格规则

### 语言
- 尽量中文，只保留通用英文缩写：API、OI、PID、cron、job、error、OK
- 不使用 `══════════`、`━━━`、`---` 等装饰性分隔符

### Emoji 符号必须跟中文标签
所有信号/状态类 emoji 后面**必须加中文说明**，不允许只有符号没有文字：
- ❌ `🟢+19.61%` → ✅ `🟢OI涨+19.61%`
- ❌ `🚀+55.79%`  → ✅ `🚀价涨+55.79%`
- ❌ `🟢 7.5`      → ✅ `🟢高 7.5`
- ❌ `✅`          → ✅ `✅HL通`

标准标签映射：
| Emoji | 中文标签 | 说明 |
|---|---|---|
| 🟢 / 🔴 | OI涨 / OI跌 | OI方向 |
| 🚀 / 💥 | 价涨 / 价跌 | 价格变动 |
| 📊 | 量变 | 成交量变化 |
| 🌪️ | 波变 | 波动率变化 |
| 🔥 / 💰 | 负费 / 正费 | 资金费率 |
| 🟢 / 🟡 / ⚪ | 高 / 中 / 低 | 置信度等级 |
| ✅ / ❌ / ⏳ | HL通 / 无 / 待验 | 跨所验证 |
| 📈 | 真突破 | OI价同步涨 |
| 💨 | 空平反弹 | OI跌价涨 |
| ⚠️ | 接盘预警 | OI涨但价跌 |
| 📉 | 趋势跌 | OI价同步跌 |

### 方向箭头
- `↑` / `↑` 看多
- `↓` / `↓` 看空
- `→` / `→` 中性

## 标准模板

### 单指标报告（如 X情绪）
```
标题 timestamp

| 指标 | 数值 | 解读 |
|------|------|------|
| 指标A | 值 | 方向/信号 |
| 指标B | 值 | 方向/信号 |

| 明细列 | 列2 | 列3 |
|--------|-----|-----|
| ... | ... | ... |
```

### 多品种报告（如清算压力、Orion雷达）
```
标题 timestamp

| 品种 | 现价 | 关键指标 | 变化 | 信号 |
|------|------|----------|------|------|
| BTCUSDT | $xx,xxx | OI $xM | +x% | 正常/爆仓 |
| ETHUSDT | $x,xxx | OI $xM | +x% | 正常/爆仓 |
```

Orion 雷达专用 7 列表（2026-06-29 用户确认）：
```
| # | 品种 | 价格 | 信号 | 置信度 | HL验证 | 关键指标 |
|---|---|---|---|---|---|---|
```

### 数据过期告警
```
## 数据过期告警 — timestamp

| 文件 | 过期时间 | 阈值 | 落后幅度 |
|---|---|---|---|
| xxx.json | Nh | Th | 💀 +N% |

正常文件: N 个 · 过期文件: N 个
```

### 分类因子报告（如 QLib因子）
```
标题 timestamp | $现价

| 类别 | 因子 | 数值 | 方向 |
|------|------|------|------|
| 动量 | RSI(14) | 55 | → |
| 趋势 | MA5偏离 | -0.03% | ↓ |
| 波动 | ATR(14) | 421 | - |
| 成交量 | VRATIO | 0.83 | → |

综合信号: → 观望 (评分0/5)
```

## 注意事项
- Telegram MarkdownV2 不支持 `|` 管道表格语法 → 适配器降级纯文本 → 可能乱码
- 优先输出表格格式，Telegram端显示问题由网关层处理
- 表格列数 ≤4（Orion 雷达除外可用 7 列）
- no_agent cron 脚本退出码必须为 `0`（非零会被 cron 标记为 error，stdout 被压缩为单行）
