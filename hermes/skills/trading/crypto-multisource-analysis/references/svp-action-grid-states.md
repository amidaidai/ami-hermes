# SVP 行动格状态速查

> SVP 主指标 Pine 表格 (`data_get_pine_tables(study_filter="SVP+ICT+VWAP+CVD")`) 返回的「行动格」(action grid) 是**方向判断的第一数据源**。本文件记录各状态的实际输出示例与解读。

## 状态速查

| 行动格结论 | 对应等级 | 是否可执行 | 场合适例 |
|-----------|---------|-----------|---------|
| 做多 / 做空 | A | ✅ 可出执行卡 + 具体入场价 | 主+副双指标共振 |
| 等待 / 偏多等待 | B | 🔶 可写倾向 + 触发条件 | 结构顺向但缺确认 |
| 观望 ⚠冲突 / 观望 · 走弱 | C | ❌ 不推送，冲突不明确 | 信号矛盾，多周期不共振 |
| 等待禁做 / 过热禁追 | X | ❌ 静默 | 极端状态、结构过热 |

## C/冲突态 — 实盘示例（2026-06-28）

**场景：** BTCUSDT.P 15m 周期，价格 ~60,119，4h 空头排列

### 原始 Pine Table 输出
```
结论 | 观望 ⚠冲突
方向 | 观望 · 走弱 ⚡伦 扫3/2
进场 | 等触发
止损 | —
目标 | ↑周六 纽 高 60924.7
核对 | —
磁吸↑ | 周六 高 60924.7 分70★HTF 距7.1ATR

```

### 关键信号解读

| 字段 | 值 | 含义 |
|------|-----|------|
| 结论 | 观望 ⚠冲突 | 指标自身冲突，不做方向判定 |
| 方向 | 观望 · 走弱 | 无方向——⚠冲突下的走弱"倾向"不可信 |
| 进场 | 等触发 | 无入场信号 |
| 磁吸↑ | 距7.1ATR | 上方磁吸位极远，短期不可达 |
| 磁吸↓ | -- | 下方无磁吸 |

## A/可执行态 — 应然特征

当行动格输出与此相反时，才是可执行信号：

```
结论 | 做多                           # ← 明确单向
方向 | 看涨 · 强 ⚡东 0/0              # ← 方向明确+强度标记
进场 | 64,500(限价+确认)               # ← 有具体入场价
止损 | 64,000                          # ← 有止损
目标 | 65,200(1R) / 65,900(2R)         # ← 多目标+R:R
磁吸↑ | 65,200 分85 ★HTF 距1.2ATR     # ← 有近期可达磁吸
```

## B/等待态 — 应然特征

```
结论 | 等待                            # ← 无冲突标记
方向 | 偏空 · 等反抽确认                # ← 有倾向性
进场 | 反抽S VWAP + CVD转卖确认         # ← 有触发条件
止损 | —                              # ← 不给具体价
目标 | 破VAL                          # ← 方向性目标
磁吸↓ | VAL 分65 ★ 距0.8ATR           # ← 有近期位
```

## 判断规则

1. **结论含 ⚠冲突** → 不论方向字段写什么 → C级 → 不推送、不出卡
2. **结论为"观望" + 进场="等触发" + 止损="—"** → 三字段合一确认C级
3. **磁吸↑↓均为"--"** → 价格在无磁吸区间，短期无指向
4. **方向 = "观望 · X"** → 连方向字段都写"观望"表示无倾向，不同于"偏多/偏空等待"
5. **价格临近关键位 + 行动格冲突** → 可以给出破/守两种走法的推理（不推卡），但多因子评分必<7
