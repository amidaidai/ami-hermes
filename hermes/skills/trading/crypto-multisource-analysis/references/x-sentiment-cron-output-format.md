# X情绪LLM分析 cron 输出格式 v2.0

> 2026-07-03 · Telegram RichMarkdown 真表格同步版
> 用于 X 情绪/市场概况/Orion 简报等非完整交易卡场景。

## 核心原则

- **全表格驱动** — 零散文本全部收入表格，禁止表格外长段落。
- **恰好 3 张表** — 行情全景 → 多源交叉验证 → 关键位预案。
- **每表 ≤3 列** — 手机优先，禁止 4 列以上宽表。
- **Telegram 真表格** — 必须走 Bot API 10.1 `sendRichMessage` + `rich_message.markdown`。
- **RichMarkdown 坑点** — 表格前不要紧贴 standalone `表1 · xxx` 标题行；表格必须直接从 `| 表头 |` 开始。
- **方向标注** — 首行 `↑ 看多 / ↓ 看空 / ○ 观望 / × 禁做` + 情绪标签 + 价格 + 中文时间。
- **时间格式** — `2026年07月01日08：38`，全角冒号，无 UTC/BJT。

## 完整格式模板

```markdown
↓ 极端恐惧 · BTC `58,472` · 2026年07月01日08：38

| 品种 | 数据 | 状态 |
|:----|:----|:----|
| BTC | 价`58,472`·24h`−2.2%`·量`$1.16B` | 测试`58K`支撑 |
| ETH | 价`1,572`·24h`−1.4%`·量`$342M` | 跟跌偏弱 |
| SOL | 价`73.66`·24h`−0.8%`·量`$194M` | `70-76`整理 |

| 来源 | 方向 | 证据 |
|:----|:---:|:----|
| 恐惧贪婪 | 🐻极恐 | `11/100`·历史底部区 |
| X·短线 | 🐻偏空 | `$58K`支撑测试·ETF月流出`$4.1B` |
| X·中期 | 🐂看涨 | 机构目标`$240K-$300K`·结构性持仓 |
| 衍生品 | 🐻偏空 | 持仓高位+多头清算集中`58-59K` |
| 宏观 | 🐻承压 | FOMC偏鹰·避险波动 |

| 方向 | 触发 | 动作 |
|:---:|:----|:----|
| ↓空 | BTC破`58,000`+放量 | 观望等`55K`以下抄底信号 |

| ×禁做 | F&G<10+ETF加速流出 | 清多头仓位，等`50K`下 |
```

## 数据填充规则

| 表 | 内容 | 要求 |
|:--|:----|:----|
| 第一张 | 品种/价格/24h/成交量/状态 | 数据列压缩，禁止 5-6 列行情宽表 |
| 第二张 | X、Web、F&G、Binance、CG 等验证 | 每行必须有具体数值/事件，不写空话 |
| 第三张 | 多/空/禁做/风控预案 | 必须有触发、动作、目标或禁做原因 |

## 数据采集时序

1. 脚本 `x_sentiment_context.py` 先跑 → 输出结构化 JSON（价格/F&G/CG热搜/Orion候选）。
2. LLM cron 用 JSON 上下文判断品种和方向。
3. LLM 用 x_search 采集 X 实时情绪 → 填充第二张表。
4. web_search 补充宏观/新闻源 → 合并到第二张表。
5. 只输出首行 + 3 张表，不追加“分析完成”或尾注。

## 通用规则

| 规则 | 说明 |
|:----|:-----|
| 表格数量 | 恰好 3 张 |
| 表格列数 | 每表 ≤3 列 |
| 表格标题 | 不使用 standalone `表1 · xxx` 紧贴表格 |
| 价格格式 | 全部反引号 `58,472` |
| 方向emoji | 🐻空 🐂多 ⚖中性 ⚡异动 ❌陷阱 |
| 禁止 | 假表格 / 文字对齐 / 4列以上 / 表格外长段落 / 尾注总结 |
| 验证 | Telegram 回执应有 `rich_message.blocks[type=table]` |
