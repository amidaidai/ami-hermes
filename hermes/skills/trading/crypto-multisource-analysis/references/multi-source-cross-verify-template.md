## 交叉验证判据矩阵

### 衍生品一致性检查

| 信号组合 | 解读 | 置信 |
|:---|:---|:---:|
| OI↑+价格↑ | 新资金进场，健康上涨 | 高 |
| OI↑+价格↓ | 新空头建仓(跌势确认)或多空分歧 | 中 |
| OI↓+价格↑ | 空头平仓(轧空) | 中 |
| OI↓+价格↓ | 多头平仓(去杠杆/踩踏) | 高 |
| 费率极负+价格跌 | 空头加仓压制，但空头拥挤可能反转 | 中 |
| 费率极负+价格横盘 | 空头日耗0.8%+，3-4天后空头平仓反弹 | 高 |
| 多空比>2.0+价格跌 | 多头踩踏风险极高 | 高(反指) |
| 多空比>2.0+价格横/涨 | 多头拥挤，警惕反转 | 中 |

### Taker主动买卖模式

| 模式 | 含义 |
|:---|:---|
| 持续买偏(>1.2多周期) | 买方主导，趋势可靠 |
| 持续卖偏(<0.8多周期) | 卖方主导，跌势确认 |
| 买夹卖(0.5→2.5→0.6) | 抄底尝试失败，卖压卷土重来 |
| 卖夹买(2.0→0.5→1.8) | 空头获利平仓，买盘开始承接 |

### 多周期EMA方向一致性

| 4h EMA | 1h EMA | 15m EMA | 裁决 |
|:---:|:---:|:---:|:---|
| 🟢多头 | 🟢多头 | 🟢多头 | 趋势一致，可操作 |
| 🟢多头 | 🟢多头 | 🔴空头 | **冲突**：HTF看多，LTF回调中——等LTF改善 |
| 🔴空头 | 🔴空头 | 🔴空头 | 趋势一致，可操作 |
| 🔴空头 | 🔴空头 | 🟢多头 | **冲突**：HTF看空，LTF反弹中——等反弹做空 |
| 🟢多头 | 🔴空头 | 🔴空头 | 4h强于1h，以4h为准但降级 |
| 🔴空头 | 🟢多头 | 🟢多头 | 1h/15m反弹但4h压制约=反弹做空 |

**关键价格水平检验**：当LTF(15m)与HTF(4h/1h)冲突时，检查价格是否在HTF的关键位附近。例如价格在4h EMA34支撑处=趋势测试点，价格远离HTF关键位=趋势已破。

## 「矛盾点」段写作规则

当多源交叉验证发现矛盾时，在分析卡中输出独立段落，格式：

```
**核心矛盾**: {一句话定位矛盾}
- 支持↑的源: {源1}·{源2}·{源3} → 强度
- 支持↓的源: {源1}·{源2}·{源3} → 强度
- ○观望的源: {源1}·{源2} → 强度
**综合裁定**: {明确结论}。关键分水岭={价位}({理由})
- 守{价位} → {路径A}
- 破{价位} → {路径B}
```
