# 驾驶舱角色速查（2026-06-29 用户确认）

当用户问「我驾驶舱流程是什么」「多元验证怎么走」「所有市场都是吗」时，用以下三层框架回答。

## ① 数据采集层 — 全源执行（加密7步）

| 步骤 | 工具 | 看什么 |
|:----:|:----|:------|
| ① TV主分析 | TV MCP | 4h→1h→15m 三周期读指标+截图 |
| ② Binance | Binance MCP | 价格/OI/多空比/费率/主动买卖 |
| ③ 市值 | CoinGecko | 24h/7d变动、市值排名 |
| ④ 日历 | 金十MCP | 本周财经事件 |
| ⑤ 情绪 | alternative.me | 恐惧贪婪指数 |
| ⑥ 市场情绪 | web_search/x_search | X/Web上大V观点 |
| ⑦ 深度/链上 | 可选 | 选做 |

## ② 分层裁决 — 各司其职

| 角色 | 对应数据 | 管什么 |
|:----|:---------|:-------|
| 🚗 主驾驶 | TV双指标(SVP+副驾驶) | 结构·方向·入场·止损·目标 |
| 🚙 副驾驶 | Volume Aggregated | 运动真假·能否追单 |
| 📊 仪表盘 | OI/多空比/费率/主动买卖 | 燃料够不够·拥挤反指 |
| 📡 雷达 | 金十日历 | 能不能交易（事件前后禁做） |
| 🌤️ 天气 | 恐惧贪婪/X情绪 | 极端情绪=拐点信号 |

## ③ 输出收敛 — 全源采集只写可交易信息

一句话方向 → 关键位矩阵 → 多源交叉验证表 → 预案A/B（破/守两路）→ 失效条件
