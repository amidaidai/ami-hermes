# Stakeholder Map

Create a power/interest stakeholder grid with targeted communication plans.

## Stakeholder Mapping Framework

### The Power/Interest Grid

Map stakeholders on two axes:

```
                    Interest
              Low             High
      +--------------------+--------------------+
High  | Keep Satisfied     | Manage Closely    |
      | (Monitor, don't    | (Active engagement |
      |  over-communicate) |  weekly updates)   |
Power |                    |                    |
      +--------------------+--------------------+
Low   | Monitor (Minimal   | Keep Informed     |
      | effort, check-ins) | (Regular updates, |
      |                    |  newsletters)      |
      +--------------------+--------------------+
```

### Quadrant Strategies

**Manage Closely (High Power, High Interest)**
- Frequency: Weekly 1:1 meetings
- Detail: Full transparency, strategic context
- Goal: Keep them as active sponsors

**Keep Satisfied (High Power, Low Interest)**
- Frequency: Monthly status updates
- Detail: Key milestones, risks, decisions needed
- Goal: Avoid surprises, don't waste their time

**Keep Informed (Low Power, High Interest)**
- Frequency: Bi-weekly digest
- Detail: Progress updates, how to help
- Goal: Leverage their enthusiasm

**Monitor (Low Power, Low Interest)**
- Frequency: Quarterly check-in
- Detail: Major milestones only
- Goal: Minimal effort, watch for shifts

## Stakeholder Analysis Fields

For each stakeholder, capture:
1. **Name / Role**
2. **Level of interest** in the project (1-5)
3. **Level of power/influence** (1-5)
4. **Current stance**: Supporter / Neutral / Detractor / Unknown
5. **Key concerns**: What they care about most
6. **Communication preference**: Email, meetings, Slack, dashboard
7. **Engagement goal**: What you want from them (approval, input, resources)
8. **Risk**: What happens if they become unsupportive

## Output Format

1. Power/Interest grid (visual or table)
2. Stakeholder profiles (one per stakeholder)
3. Communication plan schedule
4. Risk register for stakeholder-related risks
