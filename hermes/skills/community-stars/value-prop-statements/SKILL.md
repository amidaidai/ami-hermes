# Value Proposition Statements

Craft clear, compelling value proposition statements tailored to different contexts.

## Value Proposition Formula

### The Classic Structure
"We help [target customer] achieve [desired outcome] by [our solution], unlike [competitor alternative] because [our differentiator]."

### The "Jobs-to-be-Done" Structure
"When [triggering event], our [solution] helps [customer] do [job] so they can [desired outcome], unlike [alternative] which [limitation]."

## Statement Types by Context

### Elevator Pitch (15 seconds)
- Single sentence
- Who you help + what you do + why it matters
- Use concrete numbers when possible

### Landing Page Hero
- Headline: The single most important benefit
- Subheadline: Explanation + social proof
- Format: Benefit-first, feature-second

### Sales Conversation Opener
- Problem statement → Implication → Solution
- "You mentioned [pain point]. Here's how we've helped similar companies..."

### Onboarding Message
- First activation milestone
- What success looks like after 5 minutes
- Remove friction, set expectations

### Email Subject Line / Hook
- Curiosity gap or direct benefit
- Personalize when possible
- Under 50 characters

## Testing Framework

After drafting, evaluate against:
- **Clarity**: Could a 12-year-old understand it?
- **Specificity**: Are there vague words ("enterprise-grade", "best-in-class")?
- **Differentiation**: Does this apply to competitors too?
- **Memorability**: Will they remember it tomorrow?

## Output Format

Provide 3-5 variations for each context. Label each with a "vibe" (e.g., direct/emotive/technical/aspirational). Include a recommendation on which to test first.
