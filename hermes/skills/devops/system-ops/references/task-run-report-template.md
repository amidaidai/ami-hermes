## Freerouter 推送策略

修改 `freerouter.py` 后，Telegram 推送行为：

- **changes > 0**（有新模型上榜/分数重排）→ 发送 🌅 通知
- **changes = 0**（日常运行无变化）→ 静默，仅写日志到 `~/AppData/Local/hermes/logs/freerouter.log`
- 脚本自带的 `send_telegram()` 通过 Telegram Bot API 直接发送，**不受** cron 的 `deliver` 设置限制

**每次运行后需生成任务运行报告**（本模板）推送到 Telegram 话题 846。
