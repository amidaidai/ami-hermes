# Post-Radar 深度分析流程

> 2026-07-01 实战定型。用户从 Orion 雷达看到候选后问「全面分析这几个有哪一个有机会的」时的标准回应流程。

## 核心原则

- **全部输出用真实Markdown管道表**，禁止文字对齐替代
- **x_search 优先验证**：每个候选必须有基本面搜索，不自说自话
- **结论明确**：每个品种给出 ✅有机会 / ⚠ 高风险 / ❌陷阱 / ❌禁做 / ➖无信号 之一

## 流程概览

```
Step 1  读取完整候选列表（99-120个）
Step 2  硬过滤：OI≥$2M + |OI%|≥3% + 置信度≥5.0
Step 3  x_search 深度验证 Top 3-5 候选
Step 4  交叉分析：OI/价格方向 + Funding 极端度 + Taker 买卖 + 多空比
Step 5  输出恰好3张≤3列表 verdict
```

## Step 1 — 读取完整数据

Orion 雷达输出到 Telegram 的只有 Top N 个，但 `data/orion_radar.json` 包含全部候选（通常 99-120 个）。**不要只看简报，必须读完整文件。**

```python
import json
with open("data/orion_radar.json", "r") as f:
    data = json.load(f)
candidates = data.get("candidates", [])
```

## Step 2 — 硬过滤

| 条件 | 阈值 | 目的 |
|:----|:----:|:----|
| OI 最小值 | ≥ $2M | 排除流动性太差的 |
| OI 变化 | ≥ ±3% | 排除噪声级波动 |
| 置信度 | ≥ 5.0 | 至少有外部验证 |
| 价格异常 | 1h≥±3% 或 OI趋势明确 | 确保有意义 |

经过过滤后，99 个通常只剩下 3-6 个。

## Step 3 — x_search 深度验证

对每个过滤后的候选做 **2 层 x_search**：

**第 1 层**：项目搜索
```
x_search("{COIN} crypto token price analysis news 2026")
```
获取：基本面、近期事件、叙事、社区情绪。

**第 2 层**：敏感信号（如需要）
```
x_search("{COIN} funding rate liquidation short squeeze")
```
获取：衍生品具体数据、轧空/清算情况。

## Step 4 — 交叉分析

对每个候选评估以下维度：

| 维度 | 信号 | 解读 |
|:----|:----|:-----|
| OI×价 | OI↑+价↑=真资金进场 | ✅ 可跟 |
|  | OI↑+价↓=空头加仓/出货 | ❌ 不碰 |
|  | OI↑+价平=多空分歧 | ⚠ 等方向 |
|  | OI↓+价↑=轧空 | ⚠ 短命行情 |
| 资金费率 | 极负(<−0.1%)+价跌 | 空头重仓，可能挤压 |
|  | 极负+价横/涨 | 轧空高概率 |
|  | 正费+价跌 | 多头套牢，续跌 |
| Taker | Taker卖(0.3-0.7)+OI↑ | 真出货，不碰 |
|  | Taker买(1.2-1.5)+价涨 | 真买入，可跟 |
| 多空比 | >2x偏多+价跌 | 多头踩踏风险极高 |
|  | >2x偏多+价涨 | 拥挤多，警惕反转 |
| 基本面 | 有明确催化剂 | 加分 |
|  | 诉讼/黑客/负面 | 减分或禁做 |

## Step 5 — 输出格式（恰好3张≤3列表）

Telegram RichMarkdown 下不要在表格前紧贴 standalone `表1 · xxx` 标题行，直接从管道表开始。

| 品种 | 数据 | 信号 |
|:----|:----|:----|
| TAIKO | 价/OI/费率/Taker/置信度压缩 | ✅有机会/⚠高风险/❌陷阱 |

| 品种 | x_search验证 | 结论 |
|:----|:------------|:----|
| TAIKO | 具体叙事/事件/基本面 | 不是空话 |

| 品种 | 操作 | 风控 |
|:----|:----|:----|
| TAIKO | 入场区/触发/目标 | 止损/R:R/禁做条件 |

最后一张表必须承载综合推荐，不再追加第4张表或表后总结。

## 实战注意事项

- **不要只看 1-2 个维度**：OI 暴增+价跌=陷阱，单看 OI 涨幅会被骗进去
- **小市值陷阱**：OI<$2M 的品种滑点大，即使信号完美也不建议碰
- **资金费率极端值优先**：费率极负(−0.5% 以上)往往是比 OI 更强的反转信号
- **叙事比技术重要**：有明确催化剂的项目（如 TAIKO 桥修复）博弈价值高于纯技术异动
- **结论必须明确**：每个品种给出 ✅可做 / ⚠高风险 / ❌陷阱 / ❌禁做 / ➖无信号 之一
- **表格格式优先**：每轮输出先展示表1数据，再展示表2验证，最后表3操作，逻辑递进
