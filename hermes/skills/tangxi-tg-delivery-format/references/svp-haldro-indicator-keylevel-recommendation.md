## 双指标分工（铁律）

| **主指标** SVP+ICT+VWAP+CVD | 方向/结构/执行引擎 | 关键位体系 + 磁吸位 + 方向计划 + A/B/C/X | ✅ 唯一执行授权 |

## 磁吸位评分公式（自动推荐关键位的核心）

主指标磁吸位（L2460-2475）本身就是一套筛选"哪些位最值得盯"的打分引擎：

```
distScore    = max(0, 100 - (距离/ATR) × 20)       # 越近越强
freshnessScore = max(0, 100 - 年龄/(30min))        # 越新越强
prioScore    = priority × 20                        # 优先级
totalScore   = distScore×0.4 + freshnessScore×0.3 + prioScore×0.3
             + 20（该位落 HTF FVG 内 → mHtfConf）   # 高周期共振加分
score        = min(round(totalScore), 100)
```

**这就是答案**：用户不报价格时，我读主指标行动格的**磁吸↑/磁吸↓**，即为指标已打分、值得盯的候选位。磁吸位行形如：

```
磁吸↑ | 周五 亚 高 81500·6.1A·分33·66%
磁吸↓ | ↓nPOC 78390.1·2.1A·分52
```

含义：位名 + 距现价(ATR倍数) + 分数 + HTF共振命中%。分数是 dist+freshness+prio+HTF 综合，越高越值得盯。**只挑分数高、距离近（≤几个ATR）、且有多源确认的分水岭位**（上/下各1个最值得盯——本会话就是 79,633 反抽位 与 78,400 买回位）。

## 正确工作流（用户确认）

```
[主指标磁吸位] ──→ 安禾分析推荐关键位清单 ──→ 用户确认 ──→ 写 keylevels.json ──→ 守护实时盯
```

- **用户不说价格**：我出分析卡时，从磁吸↑/磁吸↓ 读出指标打分最高的候选位，给一张清单（含分数/距离/理由），用户点头写配置。
- **不是所有位都值得盯**：只盯距离现价不太远、磁吸分高、有 HTF 共振/失效线明确的分水岭位。过滤噪音。
- 配置驱动（`keylevels.json` 多品种热读 > 硬编码到代码），加位/删位/加品种 = 改配置即生效，守护不用重启。
