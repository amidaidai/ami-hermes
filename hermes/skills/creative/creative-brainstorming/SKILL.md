# Creative Brainstorming (Obra/Superpowers Methodology)

A structured approach to creative ideation before committing to implementation. Use this skill when you need to generate, evaluate, and refine creative ideas systematically.

## Methodology

The Obra/Superpowers methodology follows a structured 5-phase process:

### Phase 1: Divergent Exploration
Generate as many ideas as possible without judgment:
- **Quantity over quality** — aim for 20+ raw ideas
- **Wild/extreme ideas welcome** — constraints come later
- **Build on others** — combine, mutate, remix
- Timebox: 10-15 minutes

### Phase 2: Convergent Filtering
Apply lightweight filters to surface promising ideas:
- **Feasibility** — can we build/do this?
- **Desirability** — does the user/audience want this?
- **Viability** — does it make sense for the project?
- Pick 3-5 candidates for deeper exploration

### Phase 3: Structured Ideation
For each candidate, expand using the **Superpowers Canvas**:
1. **Core hook** — one-sentence elevator pitch
2. **Why now?** — timing and context
3. **Key differentiator** — what makes it unique
4. **Riskiest assumption** — what must be true for this to work?
5. **Minimal expression** — smallest version that proves the idea

### Phase 4: Rapid Prototyping Plan
Define the minimal investment to test viability:
- What's the cheapest way to validate?
- What does "good enough" look like?
- Success criteria for moving forward

### Phase 5: Commit or Kill
Make a clear decision:
- **Commit** — proceed to implementation with a concrete next step
- **Kill** — discard consciously (document why for future reference)
- **Parking lot** — save for later

## Usage

When the user says "I need ideas for X" or "Let's brainstorm":

1. Ask clarifying questions about scope, audience, constraints
2. Execute Divergent Exploration (Phase 1)
3. Guide through Convergent Filtering (Phase 2)
4. Run Structured Ideation for top candidates (Phase 3)
5. Propose a Rapid Prototyping Plan (Phase 4)
6. Help them make a Commit-or-Kill decision (Phase 5)

## Tips

- **Defer judgment** — the goal is exploration, not perfection
- **Write everything down** — even "bad" ideas can spark good ones
- **Use constraints creatively** — limitations breed innovation
- **Default to action** — ideation without execution is daydreaming
