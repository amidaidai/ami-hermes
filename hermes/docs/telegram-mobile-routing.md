## 全渠道格式铁律

| 规则 | 要求 |
|---|---|
| 首行 | 方向/状态 + 关键数据 + 中文时间 |
| 表数量 | 恰好3张表 |
| 表宽 | 每表≤3列 |
| 表格 | 必须是真Markdown管道表；Telegram 走 Bot API 10.1 RichMarkdown/sendRichMessage，表格前不要紧贴 `表1 · xxx` 标题行 |
| 数据 | 每行必须有价格/百分比/流量/状态等具体数据 |
| 禁止 | 假表格、文字对齐、4列以上宽表、表格外长段落、尾注总结 |
| 时间 | 中文格式：`2026年7月3日12：07` |

## LLM手机表格模板

| 场景 | 模板 |

| Orion/X情绪/市场概况 | 首行结论 + 表1行情全景 + 表2多源交叉验证 + 表3关键位预案 |
| 表1 | `品种 / 数据 / 状态` |
| 表2 | `来源或品种 / 方向 / 证据` |
| 表3 | `方向 / 触发 / 动作` |

## 禁止项

| 禁止 | 原因 |
|---|---|
| 4张表以上 | 手机太长、刷屏 |
| 4列以上宽表 | Telegram/飞书/Discord手机阅读困难 |
| 表格外长段落 | 不利于快速扫读 |
| 假表格 | 必须是真Markdown管道表 |
| BJT/UTC | 统一中文时间格式 |
| 文字对齐伪表格 | 不同客户端字体会错乱 |
